La **Skill de Pilot Status** enseña a un agente de IA a usar la API pública `/v1` mediante una herramienta de línea de comandos incluida, `pilot-status`. Funciona en Claude Code, Claude Desktop / claude.ai (con ejecución de código), Codex y cualquier agente compatible con [Agent Skills](https://agentskills.io). También puedes usar el CLI directamente.

- **Inicio de sesión OAuth** en el navegador, con el mismo servidor de autorización que el [MCP alojado](/es/integrations/mcp-server). Ninguna clave que copiar; el token se queda en tu máquina y se renueva solo.
- **Clave de API** para CI y servidores (`PILOT_STATUS_API_KEY`).
- **Un comando por capacidad de la API pública**: los mismos nombres y argumentos que las herramientas del MCP.
- **Las acciones destructivas o de pago nunca se ejecutan sin confirmación**: muestran una vista previa y se detienen hasta que repitas el comando con `--yes`.

Requiere **Node.js 18+**. Sin dependencias: el CLI es un único archivo.

## Inicio de sesión

```bash
node pilot-status/scripts/pilot-status.mjs login
```

El navegador abre la pantalla de consentimiento de Pilot Status (aparece como **Pilot Status CLI**). Apruébala para el workspace que quieras.

- **Sin navegador en esta máquina** (SSH, contenedor): `login --no-browser`, abre la URL impresa en cualquier lugar y pega de vuelta la URL en la que terminó el navegador.
- **Varios workspaces**: un inicio de sesión por workspace con `login --profile <nombre>`; después `--profile <nombre>` en cualquier comando, o `use <nombre>`. `profiles` los lista.
- **CI / servidores**: define `PILOT_STATUS_API_KEY` (tiene prioridad sobre cualquier perfil) o usa `login --api-key` leyendo la clave de la entrada estándar.
- **Cerrar sesión**: `logout` revoca el inicio de sesión. Un token de acceso ya emitido sigue siendo válido como máximo una hora.

Las credenciales se guardan en el Secret Service de Linux cuando está disponible; si no, en `~/.config/pilot-status/credentials.json` con permisos `0600`. En macOS el Keychain es opcional: `PILOT_STATUS_CREDENTIALS=keychain`.

## Uso

```bash
pilot-status tools --group messages          # lista los comandos
pilot-status describe <comando>              # descripción + JSON Schema de los argumentos
pilot-status run <comando> --json '{"...":"..."}' [--number <id-del-numero>]
pilot-status api GET /v1/...                 # cualquier endpoint, directo
```

Todos los comandos imprimen JSON. `--json @archivo.json` y `--json -` (entrada estándar) también funcionan.

### Confirmación antes de acciones destructivas o de pago

Borrar, sobrescribir, desconectar o cobrar **nunca ocurre en la primera llamada**. El comando muestra `"status": "CONFIRMATION_REQUIRED"` con una vista previa (teléfonos enmascarados en los últimos 4 dígitos) y sale con código `3`. Repite el mismo comando con `--yes` para aplicarlo. La Skill indica al agente que te muestre la vista previa y espere tu sí explícito.

### Códigos de salida

| Código | Significado |
|---|---|
| `0` | OK |
| `1` | Error de la API (ver `error` / `code`) |
| `2` | Uso incorrecto |
| `3` | Confirmación necesaria |
| `4` | Vuelve a iniciar sesión |
