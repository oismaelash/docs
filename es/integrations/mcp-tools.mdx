Las 151 herramientas del [servidor MCP alojado](/es/integrations/mcp-server), agrupadas por los mismos temas que usa el `describe` de [Code Mode](/es/integrations/mcp-code-mode). Cada fila da el propósito en una línea y los argumentos **sin los que la herramienta no puede ejecutarse**; todo lo demás es opcional. Tu cliente MCP muestra la descripción completa y el esquema de cada herramienta, y en Code Mode `describe({ theme })` los devuelve como TypeScript.

## Lee esto primero

- **`whatsappNumberId`.** Todas las herramientas excepto `docs_search` también aceptan `whatsappNumberId`, el id del número sobre el que actuar (obtenido de `numbers_list`). Con una conexión OAuth o una clave de todo el workspace es **obligatorio para las herramientas con alcance de número** (mensajes, conversaciones, grupos, plantillas, webhooks, llamadas, Chatwoot…); se ignora cuando la API key ya está vinculada a un número. No aparece en las tablas de abajo.
- **Quién puede llamar.** "ADMIN or OWNER", "OWNER only" y "OAuth only" son los roles del workspace y los tipos de credencial que exige la API; los demás llamadores reciben `403`. Con una conexión OAuth, el rol se lee en vivo en cada llamada.
- **Token de confirmación.** `templates_delete`, `workspace_archive`, `workspace_transfer_ownership` y `workspace_members_remove` se ejecutan en dos llamadas: la primera devuelve una vista previa y un `confirm_token`, la segunda (los mismos argumentos más `confirm_token`) ejecuta la acción. [Cómo funciona](/es/integrations/mcp-server#confirmación-para-herramientas-destructivas)
- **`confirm: true`.** `flows_publish`, `flows_endpoint_key_rotate` (cuando ya hay una clave registrada) y `subscription_extra_numbers_add` (en un plan FREE) se niegan a ejecutarse sin el booleano `confirm: true`. Envíalo solo después de que el usuario haya dicho que sí.
- **Anotaciones.** Cada herramienta declara las pistas MCP `readOnlyHint`, `destructiveHint`, `idempotentHint` y `openWorldHint`, para que los clientes puedan omitir la solicitud de aprobación en las lecturas y avisar antes de las llamadas destructivas. Toda herramienta con token de confirmación está marcada como destructiva.
- **Autorización por número.** Una conexión OAuth que autorizó solo algunos números no puede usar herramientas de nivel de cuenta como `billing_checkout`, `api_keys_*` y `numbers_create`.
