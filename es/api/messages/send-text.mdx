# Enviar un mensaje de texto

El texto libre es uno de los tres modos mutuamente excluyentes del endpoint **único** de envío (no existe un endpoint `/messages/text` separado):

```text
POST https://pilotstatus.com.br/v1/messages/send
```

## Solicitud

Autentícate con tu API key **asociada al número** en el header `x-api-key`.

<ParamField body="destinationNumber" type="string" required>
  Teléfono de destino en **E.164** (el `+` inicial es opcional, por ejemplo, `+5511999999999`) o el BSUID del contacto. Consulta [Enviar un mensaje](/es/api/messages/send#destino-exactamente-uno).
</ParamField>

<ParamField body="text" type="string" required>
  Cuerpo del mensaje de texto libre. Mutuamente excluyente con `templateId` y con multimedia directa (`media` \+ `mediaType`).
</ParamField>

<ParamField body="deliverAt" type="string">
  Fecha y hora ISO 8601 opcional para programar el envío.
</ParamField>

```bash
curl -X POST "https://pilotstatus.com.br/v1/messages/send" \
  -H "Content-Type: application/json" \
  -H "x-api-key: ps_your_key_here" \
  -d '{
    "destinationNumber": "+5511999999999",
    "text": "Hi! Your delivery has been confirmed for tomorrow."
  }'
```

## Respuesta (202)

```json
{
  "id": "msg_abc",
  "correlationId": "corr_123",
  "status": "QUEUED"
}
```

El **`id`** del `202` es el mismo valor que **`data.id`** en los webhooks de entrega (`message.sent`, `message.delivered`, `message.read`, `message.failed`); consulta [Eventos de webhook](/es/api/webhooks/events). `correlationId` lo genera la plataforma y se repite en los eventos correlacionados.

## Notas

- El texto libre **no usa plantilla**: no hace falta aprobar nada antes.
- En números de **Meta Cloud API**, el texto libre solo funciona dentro de la **ventana de conversación de 24 h** de WhatsApp; fuera de ella, el envío falla de forma asíncrona con `META_OUTSIDE_24H_WINDOW` en el webhook `message.failed`. En ese caso, usa una plantilla aprobada.
- Para la **lista completa de parámetros** (destinos, programación, etiquetas, botones, encabezado/pie), consulta [Enviar un mensaje](/es/api/messages/send).
