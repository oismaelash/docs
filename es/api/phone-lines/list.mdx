# Listar e inspeccionar líneas telefónicas

<Tip>
  Pruébalo con tu clave en el Playground: [`GET /v1/phone-lines`](/es/playground/phone-lines/list-phone-lines), [`GET /v1/phone-lines/{id}`](/es/playground/phone-lines/get-phone-line).
</Tip>

Lista todas las líneas telefónicas de tu workspace, u obtén una por su `id`. Ambos devuelven el mismo objeto de línea.

<Note>
  Requiere una clave con **alcance de tenant**. Con un token OAuth / MCP, el usuario debe ser **Owner o Admin** (`phone_lines:read`); de lo contrario, `403 PERMISSION_DENIED`.
</Note>

## GET /v1/phone-lines: listar tus líneas

Devuelve las líneas del workspace de la clave, **la compra más reciente primero**. Por defecto, solo las líneas que todavía tienes (`ACTIVE`, `PAYMENT_PENDING`, `SUSPENDED`); agrega `includeClosed=true` para incluir las finalizadas (`RETURNED`, `CANCELED`).

<ParamField query="includeClosed" default="false" type="boolean">
  `true` o `1` incluye las líneas finalizadas; `false`, `0` o ausente las deja fuera. Cualquier otro valor (distingue mayúsculas: `TRUE` se rechaza) → **400 `INVALID_QUERY`**.
</ParamField>

La lista **no está paginada**: siempre devuelve todas las líneas que coinciden.

<CodeGroup>

```bash cURL
curl "https://pilotstatus.com.br/v1/phone-lines?includeClosed=true" \
  -H "x-api-key: ps_your_tenant_scoped_key"
```

```json Response (200)
{
  "lines": [
    {
      "id": "cmg5k2l1n0001pl8example9x",
      "name": "Support SP",
      "number": "551148637200",
      "display": "(11) 4863-7200",
      "ddd": "11",
      "status": "ACTIVE",
      "price": 33.9,
      "currency": "BRL",
      "purchasedAt": "2026-10-01T14:03:11.000Z",
      "currentPeriodEnd": "2026-11-01T14:03:11.000Z",
      "cancelAtPeriodEnd": false,
      "paymentPendingSince": null,
      "suspendedAt": null,
      "returnedAt": null,
      "canceledAt": null,
      "activationCount": 1,
      "amountDue": null
    }
  ]
}
```

</CodeGroup>

## Obtener una línea

`GET /v1/phone-lines/{id}` devuelve `{ "line": { … } }` para una línea de tu workspace, incluidas las finalizadas.

`{id}` es el `id` de la línea (de la lista, o `lineId` en el resultado de la compra), **no** el número de teléfono. Una línea de otro workspace responde **404 `LINE_NOT_FOUND`**, igual que una que no existe.

<CodeGroup>

```bash cURL
curl "https://pilotstatus.com.br/v1/phone-lines/cmg5k2l1n0001pl8example9x" \
  -H "x-api-key: ps_your_tenant_scoped_key"
```

```json Response (200)
{
  "line": {
    "id": "cmg5k2l1n0001pl8example9x",
    "name": "Support SP",
    "number": "551148637200",
    "display": "(11) 4863-7200",
    "ddd": "11",
    "status": "PAYMENT_PENDING",
    "price": 33.9,
    "currency": "BRL",
    "purchasedAt": "2026-10-01T14:03:11.000Z",
    "currentPeriodEnd": "2026-11-01T14:03:11.000Z",
    "cancelAtPeriodEnd": false,
    "paymentPendingSince": "2026-11-01T14:17:02.000Z",
    "suspendedAt": null,
    "returnedAt": null,
    "canceledAt": null,
    "activationCount": 1,
    "amountDue": 33.9
  }
}
```

</CodeGroup>

## Campos del objeto de línea

<ResponseField name="id" type="string">
  El id de la línea. Úsalo en todas las rutas `/v1/phone-lines/{id}`.
</ResponseField>

<ResponseField name="name" type="string">
  El nombre que tu equipo le dio a la línea en el dashboard (**Edit name**, el lápiz junto al nombre de la línea en su página), hasta 60 caracteres, como el `name` de un número de WhatsApp en [`GET /v1/numbers`](/es/api/numbers/list). **Nunca está vacío:** una línea sin nombre devuelve su número formateado, igual que `display`, y toda línea se compra sin nombre. No se puede definir ni cambiar por la API. Es una etiqueta: identifica la línea por su `id`.
</ResponseField>

<ResponseField name="number" type="string">
  Dígitos E.164 **sin** `+`, por ejemplo `551148637200`.
</ResponseField>

<ResponseField name="display" type="string">
  El número formateado para personas: `(11) 4863-7200`.
</ResponseField>

<ResponseField name="ddd" type="string">
  El código de área de dos dígitos.
</ResponseField>

<ResponseField name="status" type="string">
  `ACTIVE`, `PAYMENT_PENDING`, `SUSPENDED`, `RETURNED` o `CANCELED`. Consulta el [ciclo de vida de la línea](/es/api/phone-lines/overview#ciclo-de-vida-de-la-línea).
</ResponseField>

<ResponseField name="price" type="number">
  Lo que cuesta **esta** línea por mes: el precio de su **próxima renovación** (por ejemplo `33.9`). Es el precio al que se compró la línea, salvo que tu workspace tenga [su propio precio de línea telefónica](/es/phone-lines-pricing#precio-propio-del-workspace): en ese caso es ese precio, también en las líneas compradas antes.
</ResponseField>

<ResponseField name="currency" type="string">
  `BRL` o `USD`: la moneda en la que se cobra `price`.
</ResponseField>

<ResponseField name="purchasedAt" type="string">
  ISO 8601: cuándo se compró la línea. Las renovaciones cuentan desde ahí: el mismo día de cada mes, o el último día del mes cuando ese día no existe, y ese día más corto se mantiene a partir de entonces.
</ResponseField>

<ResponseField name="currentPeriodEnd" type="string">
  ISO 8601: fin del período pagado. La próxima renovación se intenta en la primera ejecución horaria de cobro posterior. Para una línea cancelada al final del período, cuándo pasa a `CANCELED`.
</ResponseField>

<ResponseField name="cancelAtPeriodEnd" type="boolean">
  `true` después de un `DELETE` sobre una línea `ACTIVE`: no se renovará y pasará a `CANCELED` en `currentPeriodEnd`.
</ResponseField>

<ResponseField name="paymentPendingSince" type="string | null">
  ISO 8601: cuándo falló el cobro de la renovación. La línea se suspende 2 días después. `null` una vez que una renovación se cobra con éxito.
</ResponseField>

<ResponseField name="suspendedAt" type="string | null">
  ISO 8601: cuándo se suspendió la línea. Se devuelve 1 día después. `null` una vez que una renovación se cobra con éxito.
</ResponseField>

<ResponseField name="returnedAt" type="string | null">
  ISO 8601: cuándo se devolvió el número a la operadora (`RETURNED`).
</ResponseField>

<ResponseField name="canceledAt" type="string | null">
  ISO 8601: cuándo una línea cancelada al final del período pasó a `CANCELED`.
</ResponseField>

<ResponseField name="activationCount" type="integer">
  Cuántas solicitudes de código se abrieron en esta línea hasta ahora. Un `POST …/activations` que respondió `503` no se cuenta.
</ResponseField>

<ResponseField name="amountDue" type="number | null">
  En una línea `PAYMENT_PENDING` o `SUSPENDED`, lo que cobra pagarla **ahora**: el monto de su período vencido, fijado cuando ese período se cobró por primera vez. Puede diferir de `price` cuando el precio propio de línea telefónica del workspace cambió después de que falló la renovación. `null` en cualquier otra línea: no debe nada ahora.
</ResponseField>

<Note>
  `status` es el campo sobre el que debes decidir. Las marcas de tiempo explican cómo llegó una línea ahí; `currentPeriodEnd` no se mueve mientras una renovación está impaga, así que en una línea `PAYMENT_PENDING` o `SUSPENDED` ya está en el pasado. `returnedAt` y `canceledAt` pueden aparecer un momento antes de que cambie `status`, mientras la operadora confirma la devolución o la cancelación.
</Note>

## Errores

| Status | `code` | Significado |
| --- | --- | --- |
| `400` | `INVALID_QUERY` | `includeClosed` no es `true`, `false`, `1` ni `0`. |
| `401` | — | Credencial ausente o inválida. |
| `403` | `NUMBER_SCOPE_NOT_ALLOWED` | Clave con alcance de número (o concesión OAuth por número). Usa la clave con alcance de tenant. |
| `403` | `TENANT_REQUIRED` | La credencial no está vinculada a ningún workspace (`error` solo en inglés). |
| `403` | `WORKSPACE_ARCHIVED` | El workspace fue archivado y su API está cerrada. |
| `403` | `WORKSPACE_MEMBERSHIP_REQUIRED` | Token OAuth / MCP de un usuario que ya no es miembro activo. |
| `403` | `PERMISSION_DENIED` | Token OAuth / MCP de un usuario que no es Owner ni Admin. |
| `404` | `LINE_NOT_FOUND` | Solo `GET /v1/phone-lines/{id}`: no existe esa línea en tu workspace. |
| `500` | `INTERNAL_ERROR` | Falla inesperada. |
