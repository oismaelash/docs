# Bloquear contacto

`POST` bloquea el contacto, `DELETE` lo desbloquea. Ninguno recibe cuerpo.

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wn_abc/contacts/%2B5511999990000/block" \
  -H "x-api-key: ps_tu_token"
```

```json
{
  "success": true,
  "numberId": "wn_abc",
  "provider": "qrcode",
  "phone": "+5511999990000",
  "jid": "5511999990000@s.whatsapp.net",
  "blocked": true,
  "occurredAt": "2026-11-24T10:00:00.000Z"
}
```

## Qué números

| Número | Bloquear / desbloquear |
| --- | --- |
| Número QR code | Sí |
| Número oficial (Meta) | Sí — solo a quien escribió al número en las últimas 24 horas (si no, `422 CONTACT_NOT_ELIGIBLE`) |
| Otros tipos de conexión | `422 FEATURE_NOT_SUPPORTED` |

## Webhook

Si tiene éxito, tus webhooks reciben `contact.blocked` (o `contact.unblocked`) con `data.source: "api"`. En un número QR code el mismo cambio también vuelve del teléfono; se entrega **una sola vez**.

## Permiso y límites

- Requiere `contacts:manage` (Agente o superior). Una clave de número solo actúa sobre su número.
- 30 llamadas de bloqueo/archivado por minuto por número → `429 RATE_LIMITED`.

## Errores

Todo error es `{ "error": "<English> | <Português>", "code": "..." }`.

| Estado | Código | Significado |
| --- | --- | --- |
| 400 | `INVALID_PHONE` | `{phone}` no es un número E.164. |
| 400 | `CANNOT_BLOCK_SELF` | Un número no puede bloquearse a sí mismo. |
| 401 | — | API key ausente o inválida. |
| 403 | `PERMISSION_DENIED` | Tu rol no tiene `contacts:manage`. |
| 404 | `NUMBER_NOT_FOUND` | Número no encontrado para esta credencial. |
| 409 | `WHATSAPP_INSTANCE_NOT_CONNECTED` | El número no está conectado. |
| 409 | `BLOCKLIST_FULL` | La lista de bloqueo está llena (64.000 usuarios). |
| 422 | `CONTACT_NOT_ELIGIBLE` | Número oficial: el usuario no escribió en las últimas 24 horas. |
| 422 | `FEATURE_NOT_SUPPORTED` | No soportado para este tipo de conexión. |
| 429 | `RATE_LIMITED` | Demasiadas llamadas, o límite de WhatsApp. |
| 502 | `PROVIDER_REJECTED` / `WHATSAPP_UPSTREAM_ERROR` | WhatsApp rechazó o falló; `details` trae su respuesta. |
