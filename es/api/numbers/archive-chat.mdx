# Archivar chat

`POST` archiva el chat, `DELETE` lo desarchiva. Ninguno recibe cuerpo. `{jid}` es un teléfono E.164 o un jid codificado en la URL (`@s.whatsapp.net`, `@g.us`, `@lid`).

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wn_abc/chats/120363000000000000%40g.us/archive" \
  -H "x-api-key: ps_tu_token"
```

```json
{
  "success": true,
  "numberId": "wn_abc",
  "provider": "qrcode",
  "jid": "120363000000000000@g.us",
  "phone": null,
  "isGroup": true,
  "archived": true,
  "occurredAt": "2026-11-24T10:00:00.000Z"
}
```

## Qué números

| Número | Archivar / desarchivar |
| --- | --- |
| Número QR code | Sí |
| Número oficial (Meta) | `422 NOT_AVAILABLE_FOR_OFFICIAL_NUMBERS` |
| Otros tipos de conexión | `422 FEATURE_NOT_SUPPORTED` |

## Webhook

Si tiene éxito, tus webhooks reciben `chat.archived` (o `chat.unarchived`) con `data.source: "api"`. El eco del mismo cambio desde el teléfono se entrega una sola vez.

## Permiso y límites

- Requiere `contacts:manage` (Agente o superior).
- 30 llamadas de bloqueo/archivado por minuto por número → `429 RATE_LIMITED`.

## Errores

| Estado | Código | Significado |
| --- | --- | --- |
| 400 | `INVALID_JID` | `{jid}` no es un teléfono ni un jid soportado. |
| 401 | — | API key ausente o inválida. |
| 403 | `PERMISSION_DENIED` | Tu rol no tiene `contacts:manage`. |
| 404 | `NUMBER_NOT_FOUND` | Número no encontrado para esta credencial. |
| 409 | `WHATSAPP_INSTANCE_NOT_CONNECTED` | El número no está conectado. |
| 422 | `NOT_AVAILABLE_FOR_OFFICIAL_NUMBERS` | Los números oficiales no archivan por la API. |
| 422 | `FEATURE_NOT_SUPPORTED` | No soportado para este tipo de conexión. |
| 429 | `RATE_LIMITED` | Demasiadas llamadas. |
| 502 | `PROVIDER_REJECTED` / `WHATSAPP_UPSTREAM_ERROR` | WhatsApp rechazó o falló. |
