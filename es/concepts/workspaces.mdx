Un **workspace** es la cuenta en sí: los números conectados a ella, las conversaciones que llegan a ellos, las plantillas, las API keys y la factura a fin de mes. Todo en Pilot Status pertenece exactamente a un workspace.

Antes de los workspaces, una cuenta era una persona. Ahora una cuenta es un **lugar**, y las personas son invitadas a él.

## Una persona, varios workspaces

El mismo inicio de sesión puede pertenecer a más de un workspace: el tuyo, más cada workspace que te haya invitado. Un selector de workspace en el encabezado te indica cuál estás viendo, y cada página debajo sigue esa elección: números, chat, logs, facturación.

Conviene saber dos cosas desde el principio:

- **Tu rol puede variar según el workspace.** Puedes ser dueño del tuyo y agente en el de un cliente. Pilot Status recalcula lo que puedes hacer en cada solicitud, a partir del workspace que tienes abierto en ese momento.
- **Nada pasa de un workspace a otro.** Un número pertenece a un workspace y no se puede mover a otro. Tampoco las conversaciones, las plantillas ni las API keys. Si necesitas el mismo número en otro lugar, conéctalo allí.

<Note>
Tu cuenta original no cambió. Se convirtió en tu **workspace principal**: los mismos números, el mismo historial, la misma factura. Lo que cambió es que ahora puede tener a otras personas dentro.
</Note>

## Qué vive en un workspace

| Pertenece al workspace | Te pertenece a ti |
|---|---|
| Números de WhatsApp y sus conexiones | Tu inicio de sesión, nombre y contraseña |
| Conversaciones, mensajes y medios | Qué workspace tenías abierto por última vez |
| Plantillas, etiquetas y webhooks | Tus preferencias de notificación |
| API keys e integraciones | Tus [claves de cuenta](/es/api/key-types#claves-de-cuenta) (`ps_account_`) |
| El plan, la billetera y la factura | |

Como las API keys pertenecen al workspace, una clave creada por un compañero sigue funcionando después de que se va, a menos que alguien decida lo contrario. Consulta [Miembros](/es/dashboard/members) para saber qué pasa con las credenciales durante la salida de una persona.

## Miembros ilimitados

Todos los planes, incluido el Free, tienen **miembros ilimitados**. No hay asientos que comprar ni tope de miembros: los miembros activos y las invitaciones pendientes nunca cuentan para un límite. Los planes se diferencian en cuántos números puedes conectar, no en cuántas personas puedes invitar.

Una invitación que no se acepta en 7 días expira y deja de funcionar por sí sola. No hay nada que limpiar.

## Quién es el dueño

Cada workspace tiene exactamente un **dueño**: la persona que paga. El dueño es el único que puede mover dinero, revelar credenciales en texto plano, destruir números o cambiar quién está dentro. La propiedad se transfiere de forma deliberada (en el panel o con [`POST /v1/workspace/transfer-ownership`](/es/api/workspace#transferir-la-propiedad)) y nunca se otorga mediante una invitación.

Consulta [Roles y permisos](/es/concepts/roles-and-permissions) para saber qué puede hacer cada rol, y [Miembros](/es/dashboard/members) para saber cómo invitar personas.
