**Profile** es donde te gestionas a ti mismo (tu nombre, tu WhatsApp, los inicios de sesión vinculados a tu cuenta y tus API keys personales) y, para Owner y Admin, algunos ajustes del workspace actual: moneda, zona horaria, idioma, el branding de la página de conexión y los miembros.

## Cómo llegar

Haz clic en **Profile** en la barra lateral, justo debajo de **Plans** (atajo de teclado: `u`), o busca **Profile** en la paleta de comandos (`Ctrl+K`). La dirección es `/profile`; cada pestaña tiene su propio link con `?tab=`:

| Pestaña | Link | Quién la ve |
| --- | --- | --- |
| **Information** | `/profile` o `/profile?tab=info` | Todos |
| **General** | `/profile?tab=geral` | Owner y Admin |
| **Connections** | `/profile?tab=connections` | Todos |
| **API** | `/profile?tab=api` | Todos |
| **Membros** (Members) | `/profile?tab=membros` | Owner y Admin; consulta [Miembros](/es/dashboard/members) |
| **Branding** | `/profile?tab=branding` | Owner y Admin |

Un link a una pestaña que tu rol no cubre abre **Information** en su lugar. El antiguo link `/profile?tab=carteira` (billetera) ahora lleva a **Plans → Wallet** (`/plans?tab=wallet`).

## Information

Tus propios datos. Se trata de **ti**, no del workspace: te acompañan en todos los workspaces a los que perteneces.

- **Name**: hasta 100 caracteres.
- **Email**: el e-mail con el que inicias sesión. Se muestra en gris y no se puede cambiar aquí.
- **WhatsApp**: tu número de teléfono, con un selector de país. Debajo, una insignia dice **Verified: +55…** o **WhatsApp not verified**.
- **Save**: guarda el nombre y, cuando la edición del teléfono está disponible, el teléfono. Si el número que escribes no está en WhatsApp, el guardado se rechaza con un mensaje que lo indica (por ejemplo **This number is not on WhatsApp. Enter a valid WhatsApp number.**).

<Note>
  El campo WhatsApp es texto libre, y guardarlo no prueba que el número sea tuyo. El número **verificado** es otra cosa: es el que recibe los avisos de pago y de límite por WhatsApp.

  Es posible que la edición del teléfono del perfil no esté disponible en tu cuenta. En ese caso el campo WhatsApp aparece en gris, pero **Save** sigue funcionando y guarda tu nombre. El servidor también rechaza cualquier solicitud que cambie el teléfono mientras esto está desactivado, con *Changing the profile phone number is currently disabled.* (*A alteração do telefone do perfil está desativada no momento.*). Verificar un número (abajo) funciona de todos modos, y un número verificado completa el teléfono del perfil cuando está vacío.
</Note>

### Verifica tu WhatsApp

**Verify** (o **Verify another number**, cuando ya tienes uno verificado) abre el diálogo **Verify your WhatsApp**:

1. Confirma o escribe el número y haz clic en **Send code**. Pilot Status envía un **código de 6 dígitos** a ese número a través de su propio WhatsApp.
2. Escribe el código y haz clic en **Verify**. **Resend code** envía uno nuevo; **Change number** vuelve al primer paso.

Cuando funciona, el dashboard dice **WhatsApp verified! You will also get notices there from now on.** Errores que puedes ver: **Invalid phone number.**, **This number is already verified on your account.**, **Incorrect code.**, **There is no valid code for this number. Request a new one.**, **Too many incorrect attempts. Request a new code.**, **This WhatsApp number is already linked to another Pilot Status account. If it is yours, contact support.**, **Too many attempts right now. Wait a moment and try again.** y **WhatsApp verification is unavailable right now. Try again later.**

## General

La **moneda**, la **zona horaria** y el **idioma** del workspace: se aplican a todo el workspace actual, no solo a ti.

- **Currency**: **BRL** o **USD**. Solo el **Owner** puede cambiarla, y solo **hasta la primera transacción de la billetera**: después el campo queda bloqueado y dice **Currency was locked after the first wallet transaction and can no longer be changed.** (Guardar la moneda es la preferencia de facturación del workspace.)
- **Timezone**: `America/Sao_Paulo`, `America/New_York`, `America/Los_Angeles`, `America/Mexico_City`, `America/Buenos_Aires`, `Europe/Lisbon`, `Europe/London`, `Europe/Madrid`, `Europe/Paris` o `UTC`.
- **Language**: portugués, inglés o español.

**Save** guarda los tres. Owner y Admin pueden cambiar la zona horaria y el idioma; un Admin ve la moneda pero no puede cambiarla.

## Connections

**Connect your accounts**: vincula Google y/o GitHub para simplificar el inicio de sesión y la recuperación de la cuenta. Cada fila muestra **Linked** o **Not linked**:

- **WhatsApp**: el teléfono de tu perfil, marcado como **Always linked**. Sin teléfono en el perfil, muestra **Not linked**.
- **Google** y **GitHub**: **Link** (o **Relink**) te lleva al proveedor para autorizar y te devuelve a esta pestaña con **Google linked!** / **GitHub linked!**. **Unlink** pregunta *Are you sure you want to unlink your Google account?* (o GitHub) y elimina ese método de inicio de sesión.

Después de desvincular, ya no puedes iniciar sesión con ese proveedor; inicia sesión con otro método que todavía tengas (por ejemplo, el código por WhatsApp o e-mail en la [pantalla de inicio de sesión](/es/dashboard/account-access)).

## API: tus keys de cuenta

La pestaña **API** guarda tus **keys de cuenta** (**Account keys** en la pantalla). Una key de cuenta es **tuya, no de un workspace**: gestiona tus workspaces y actúa dentro de cualquier workspace del que seas miembro activo. Cada solicitud elige el workspace con el header `x-workspace-id` y se ejecuta con **tu rol en ese workspace**. La tarjeta muestra **Scope: Everything in every workspace**.

- **Key name** + **Create key**: dale un nombre a la key (hasta 60 caracteres, por ejemplo *CRM integration*). Cualquier usuario puede crear una, sea cual sea su rol, hasta **20** keys de cuenta activas por usuario. Pasado ese número, la creación se rechaza: **Limit of 20 keys reached. Revoke one you no longer use to create another.**
- La lista muestra el nombre de cada key, su valor enmascarado (`ps_account_…` más los últimos cuatro caracteres), **Created …** y **Last used …** (o **Never used**).
- **Revoke** abre **Revoke the key "…"?** (*Every integration using this key stops working immediately. This cannot be undone.*) con **Revoke key**.

<Warning>
  **La key de cuenta completa se muestra solo una vez.** Justo después de **Create key**, el diálogo **Key "…" created** muestra el valor completo `ps_account_…` con **Copy key** y la advertencia *the full key is shown only this once*. Pilot Status guarda solo un hash, así que ni el dashboard ni el soporte pueden mostrarla de nuevo. **¿La perdiste? Crea una key nueva, ponla en tu integración y revoca la anterior.** No existe la opción de "revelar" para las keys de cuenta.
</Warning>

Una key de cuenta es la credencial más poderosa que puedes tener: alcanza todos los workspaces a los que perteneces. Guárdala solo en tu servidor, nunca en un navegador ni en una app. Detalles, headers y errores: [Tipos de API key → Keys de cuenta](/es/api/key-types#claves-de-cuenta).

Debajo, Owner y Admin también ven **Workspace keys** (*The primary key and the named keys of the current workspace live on their own screen.*) con **Open workspace keys**, que lleva a `/workspace-api-keys` (consulta [API keys](/es/dashboard/api-keys)).

## Branding

**Branding** personaliza la **página de conexión** que ven tus clientes cuando conectan un número mediante un link que les envías (código QR o registro de Meta). Owner y Admin pueden editarla.

| Campo | Qué hace |
| --- | --- |
| **Logo** | **Upload logo**: PNG, JPG o WebP, hasta 2 MB. El archivo se sube al hacer clic en **Save** (hasta entonces la pantalla dice *New logo selected — it will be uploaded on save.*). **Remove** lo borra. |
| **Primary color** / **Background color** | Selectores de color; **Clear** vuelve a **Default**. |
| **Title** | Hasta 60 caracteres (por ejemplo *My Company*). |
| **Subtitle** | Hasta 120 caracteres (por ejemplo *Connect your WhatsApp*). |
| **Support link (optional)** | Un link que la página muestra para pedir ayuda. |
| **Redirect after connecting (optional)** | A dónde va el cliente una vez conectado el número. |
| **Hide Pilot Status branding** | Quita el pie "Pilot Status" de la página (white-label). |

A la derecha, **Preview** muestra la página de conexión con tus cambios mientras escribes. **Open preview** la abre en pantalla completa en una pestaña nueva (`/connect-preview`), incluso antes de guardar. **Save** la aplica: **Branding saved.**

Más información (personalizaciones por link y parámetros de URL) en [Branding de la página de conexión](/es/api/branding).

## Hazlo vía API / MCP

| En esta pantalla | API | Herramienta MCP |
| --- | --- | --- |
| Nombre, teléfono, verificación de WhatsApp | Solo en el dashboard | — |
| Vincular / desvincular Google y GitHub | Solo en el dashboard | — |
| Moneda, zona horaria, idioma | Lectura: [`GET /v1/workspace/settings`](/es/api/workspace#configuración-del-workspace). Zona horaria e idioma: `PATCH /v1/workspace/settings`. Moneda: solo en el dashboard | `workspace_settings_get`, `workspace_settings_update` |
| Keys de cuenta (crear, listar, revocar) | Solo en el dashboard: una key de cuenta no se puede crear por la API | — |
| Branding | [`GET` / `PUT /v1/branding`](/es/api/branding) (logo como URL `https`; sin subida de archivo) | `branding_get`, `branding_upsert` |
| Miembros | [`/v1/workspace/members`](/es/api/workspace) | `workspace_members_*`; consulta [Miembros](/es/dashboard/members#hazlo-por-api--mcp) |
| Keys de workspace | [`/v1/workspaces/{id}/api-keys`](/es/api/workspaces#claves-de-workspace) (key de cuenta) | `workspaces_api_keys_list`, `workspaces_api_keys_create`, `workspaces_api_keys_revoke` |
