Esta página cubre lo que rodea a las pantallas del panel: cómo entras, cómo te unes a un workspace, cómo apruebas una app externa y las partes de la estructura (encabezado, paleta, chat, banners) que aparecen en todas las pantallas.

## Iniciar sesión (`/login`)

**Sign in** (Iniciar sesión): **Choose a method to continue** (Elige un método para continuar). Hay tres métodos, cada uno con un atajo de teclado cuando ningún campo tiene el foco:

| Método | Atajo | Qué ocurre |
| --- | --- | --- |
| **Continue with WhatsApp** | `1` | Solo aparece mientras el inicio de sesión con WhatsApp de la plataforma está disponible. Escribe tu número y haz clic en **Send code**: **You'll receive a 6-digit code that expires in 5 minutes.** (Recibirás un código de 6 dígitos que expira en 5 minutos.) Escríbelo y haz clic en **Sign in** (o `Ctrl`/`⌘` + `Enter`). |
| **Continue with Google** | `2` | Redirige a Google y de vuelta. |
| **Continue with GitHub** | `3` | Redirige a GitHub y de vuelta. |

`Esc` vuelve a la página de inicio. El método que usaste la última vez lleva la etiqueta **Last used** (Usado por última vez).

En el paso del código de WhatsApp también tienes **Resend code** (con una cuenta regresiva, **Resend code in …s**) y **Change number**. Mensajes que puedes ver:

- **This number is not on WhatsApp.**: el número no puede recibir el código.
- **We already sent the code, check your WhatsApp.**: se envió un código hace un momento; úsalo en lugar de pedir otro.
- **We could not deliver the code to this number. Check that it has WhatsApp.**: no se pudo entregar el código.
- **Too many code requests right now. Wait a few minutes and try again.**: se pidieron demasiados códigos en poco tiempo.
- **WhatsApp sign-in is unavailable right now. Use another sign-in method.**: inicia sesión con Google o GitHub.
- **Invalid or expired code.**: escribe el código más reciente, o reenvíalo después de 5 minutos.
- **Social login configuration error. Please try again later.**: el regreso desde Google/GitHub falló de nuestro lado.

No hay contraseña. La cuenta es la persona: WhatsApp, Google y GitHub son solo formas de iniciar sesión en ella, y las adicionales se vinculan o desvinculan en [Profile](/es/dashboard/profile). Después de iniciar sesión llegas a la pantalla que intentabas abrir, o al Dashboard.

### Enlace de acceso de un solo uso de los avisos de facturación (`/a`)

Los avisos de facturación y de límite del plan pueden incluir un enlace de acceso. Abre una página que dice **Sign in as \{email\}** (o **Sign in as the account with WhatsApp \{phone\}**), **You will open the workspace \{workspace\}.** y **This link works only once.** (Este enlace funciona una sola vez.) Haz clic en **Continue** para iniciar sesión, o en **Not you? Sign in with another account**.

Si el enlace no inicia tu sesión, llegas a `/login` con el motivo:

| Mensaje | Significado |
| --- | --- |
| **This link has already been used. Sign in to continue.** | Cada enlace inicia sesión una sola vez. |
| **This link has expired. Sign in to continue.** | El enlace superó su validez. |
| **We don't recognize this access link. Open the most recent link we sent or sign in to continue.** | El enlace está mal formado o fue reemplazado por uno más reciente. |
| **We couldn't sign you in with this link. Sign in to continue.** | El enlace no pudo usarse en este momento. |

**Too many attempts in a short time.** o **We couldn't open the link right now.** te mantienen en la página con **Try again**.

## Onboarding (`/onboarding`)

Cuando el onboarding está habilitado en la plataforma, un workspace que no lo terminó se envía aquí después de iniciar sesión. La pantalla dice **Welcome to Pilot Status**: **Set up your WhatsApp to start sending messages.** (o **Update your WhatsApp** cuando vienes del perfil después de un cambio de número).

- **Enter your WhatsApp number**: se guarda en tu perfil como un campo de perfil simple. **No** verifica el número: la verificación (con un código) se hace en [Profile](/es/dashboard/profile) y es lo que permite que los avisos de facturación te lleguen por WhatsApp.
- **Link your account**: vincula Google o GitHub (**Link** / **Relink**, estado **Linked** / **Not linked**). **Link Google or GitHub to your WhatsApp before continuing.**
- **Go to Dashboard**: se habilita cuando hay un número y al menos un inicio de sesión social vinculado.

## Aceptar una invitación (`/invite/{token}`)

El e-mail de invitación (o el enlace que copió un Owner/Admin, consulta [Members](/es/dashboard/members)) abre esta página. Si no has iniciado sesión, primero se te envía a iniciar sesión y luego vuelves con la invitación intacta.

La página (hoy solo con textos en portugués) muestra **Você foi convidado para \{workspace\}** (Fuiste invitado a \{workspace\}), el rol (por su nombre interno, como **AGENT** o **ANALYST**) con una explicación de una línea, **Convite enviado para \{e-mail\}** (Invitación enviada a \{e-mail\}) y la fecha de vencimiento. Botones:

- **Aceitar convite** (Aceptar invitación): te unes, el panel cambia a ese workspace y muestra **Você entrou no workspace** (Entraste al workspace) con tu rol.
- **Recusar** (Rechazar) → confirmación **Recusar apaga este convite. Para entrar depois, alguém do workspace precisa te convidar de novo.** (Rechazar elimina esta invitación. Para entrar después, alguien del workspace tiene que invitarte de nuevo.) → **Sim, recusar** (Sí, rechazar) (o **Voltar**, Volver). Rechazar inutiliza el enlace para siempre: la página muestra **Convite recusado** (Invitación rechazada): *Não avisamos ninguém automaticamente. Se foi engano, peça um novo convite a quem te chamou.* (No avisamos a nadie automáticamente. Si fue un error, pide una nueva invitación a quien te invitó.), y quien te invitó ve la invitación como rechazada.

| Error | Qué hacer |
| --- | --- |
| **Convite não encontrado** (Invitación no encontrada) | El enlace no existe, fue reemplazado por uno más reciente (cada **Resend** invalida el enlace anterior), fue revocado o ya fue rechazado. Pide una nueva invitación. |
| **Convite expirado** (Invitación vencida) | Las invitaciones duran **7 días**. Pide a quien te invitó que la reenvíe. |
| **Convite já usado** (Invitación ya usada) | Ya fue aceptada. Si eres miembro, solo inicia sesión. |
| **Convite é de outro e-mail** (La invitación es de otro e-mail) | Una invitación solo funciona para el e-mail invitado. Cierra sesión e inicia sesión con esa cuenta. |
| **Link incompleto** (Enlace incompleto) | Abre el enlace completo desde el e-mail. |
| **Não foi possível abrir o convite** (No se pudo abrir la invitación) | Algo más salió mal (por ejemplo, demasiados intentos). Vuelve a intentarlo en un momento o pide una nueva invitación. |

## Aprobar una app (`/oauth/consent`)

Cuando una app externa se conecta a tu cuenta mediante OAuth (por ejemplo, el servidor MCP de Pilot Status agregado como **Custom Connector** en Claude), llegas a **Access authorization**: **Connect to your Pilot Status account**: *An app (e.g. Claude) is requesting access. Choose what it can access.* (Una app, por ejemplo Claude, está solicitando acceso. Elige a qué puede acceder.) Si no has iniciado sesión, primero inicias sesión y vuelves a esta pantalla. Si la app envió una solicitud incompleta, la pantalla dice **Invalid connection request**: *The authorization parameters are missing or invalid. Go back to the app and try connecting again.*

| Opción | Qué obtiene la app |
| --- | --- |
| **Entire account** (Toda la cuenta) | *Access to all numbers and account operations, including billing. API keys only while you own the workspace.* (Acceso a todos los números y operaciones de la cuenta, incluida la facturación; API keys solo mientras seas dueño del workspace.) Solo un **Owner** o un **Admin** puede elegirla. Para un **Agent** o un **Analyst** la opción aparece deshabilitada con *Only the workspace owner or an admin can grant access to the entire account. Choose specific numbers.*, y el servidor también la rechaza. |
| **Specific numbers only** (Solo números específicos) | *Access only to the selected numbers. Account-level operations are blocked.* (Acceso solo a los números seleccionados; las operaciones a nivel de cuenta quedan bloqueadas.) Marca los números en la lista (**… selected**); debes marcar al menos uno (**Select at least one number.**). Solo puedes marcar números a los que tú mismo tienes acceso, y el número de prueba compartido no aparece en la lista. |

**Specific numbers only** está seleccionada por defecto. Cuando el workspace no tiene números, un Owner o Admin empieza en **Entire account**; un Agent o Analyst ve **No numbers available in this account.** *Ask the owner or an admin to connect a number or to authorize this app.* y no puede autorizar.

### Secretos y API keys

Debajo de las opciones, la pantalla indica a qué podrá acceder la app más allá de los mensajes y los números. Depende de tu rol:

| Tu rol | Qué muestra la pantalla |
| --- | --- |
| **Owner** | Advertencia **This app will be able to view secrets and create API keys**: *Because you own this workspace, the app will be able to reveal and create API keys (ps_…), view and rotate webhook secrets and view the Meta verify token on your behalf. Keys and secrets it obtains stay valid even if you revoke this access later — regenerate them to cut them off. Every creation or reveal is recorded in the audit log.* (Como eres dueño de este workspace, la app podrá revelar y crear API keys (ps_…), ver y rotar secretos de webhook y ver el verify token de Meta en tu nombre. Las claves y secretos que obtenga siguen siendo válidos aunque revoques este acceso después: regenéralos para cortarlos. Cada creación o revelación queda registrada en el log de auditoría.) |
| **Admin** | Advertencia **This app will be able to view secrets**: *Because you are an admin of this workspace, the app will be able to view and rotate webhook secrets and view the Meta verify token on your behalf. API keys are only available to the workspace owner. Secrets it obtains stay valid even if you revoke this access later — rotate them to cut them off. Every creation or reveal is recorded in the audit log.* (Como eres admin de este workspace, la app podrá ver y rotar secretos de webhook y ver el verify token de Meta en tu nombre. Las API keys solo están disponibles para el dueño del workspace. Los secretos que obtenga siguen siendo válidos aunque revoques este acceso después: rótalos para cortarlos. Cada creación o revelación queda registrada en el log de auditoría.) |
| **Agent**, **Analyst** | Nota *Secrets are only available to this app for workspace admins and owners; API keys, only for the owner.* (Los secretos solo están disponibles para esta app en el caso de admins y dueños del workspace; las API keys, solo para el dueño.) |

El acceso a las API keys se verifica en cada llamada, no solo en el momento del consentimiento: si el Owner deja de ser el dueño más adelante, la app lo pierde.

**Authorize** completa la conexión y te devuelve a la app; **Cancel** le devuelve a la app un `access_denied`. El token nunca otorga más de lo que permite tu propio rol: el conector de un Analyst no puede leer conversaciones ni enviar mensajes, por ejemplo, y un permiso solicitado que tu rol no tiene se descarta.

La pantalla termina con *You can revoke this access anytime in settings.* (Puedes revocar este acceso en cualquier momento en la configuración.), pero hoy el panel no tiene una lista de apps conectadas. Para cortar el acceso de una app, elimina el conector en la app (su token también puede revocarse mediante el endpoint de revocación de OAuth) y regenera cualquier clave o secreto que haya obtenido. Detalles: [Servidor MCP](/es/integrations/mcp-server).

## El encabezado

- **Selector de workspace**: solo aparece cuando perteneces a **más de un** workspace. Cada entrada muestra el nombre del workspace, tu rol y el e-mail del dueño. Elegir uno recarga el panel en ese workspace. Si pierdes el acceso al workspace activo, el panel dice **You no longer have access to that workspace. We switched you back to your main workspace.** Para crear otro workspace, usa **Criar outro workspace** (Crear otro workspace) en [Profile → Members](/es/dashboard/members), o una clave de cuenta personal (`ps_account_…`) con [`POST /v1/workspaces`](/es/api/workspaces) / la herramienta MCP `workspaces_create`.
- **Número activo**: el desplegable **Active number:** elige qué número muestran las pantallas con alcance de número. El número de prueba compartido lleva la etiqueta **Test**.
- **Search…** (`Ctrl+K` / `⌘K`): abre la paleta de comandos.
- **Theme** (`M`), **Feedback** (`F`), **Logout** (`Q`) y el selector de idioma. **Logout** pregunta **Are you sure you want to log out of your account?**: **You will be disconnected.**

La barra lateral muestra un atajo de una sola letra junto a cada ítem (por ejemplo `p` para Plans, `u` para Profile).

## Paleta de comandos (`Ctrl+K`)

**Search or ask AI...**: escribe para filtrar, `↑`/`↓` y `Enter` para abrir, `1`–`9`/`0` para elegir un resultado, `Esc` para cerrar. Grupos:

- **Pages**: Dashboard, Analytics, Ads, Templates, Logs, API Keys (dos veces: las claves de número y las claves del workspace), Numbers, Labels, Webhooks, Plans, Documentation y Profile, filtradas según lo que tu rol puede abrir. Phone lines, Chat, Messages, Flows y Chatwoot se abren desde la barra lateral.
- **Quick Actions**: **Create Template** (`Ctrl+Shift+1`), **Regenerate API Key** (`Ctrl+Shift+3`), **Create Webhook** (`Ctrl+Shift+4`), **Connect Number** (`Ctrl+Shift+5`) y el cambio entre modo oscuro y claro. Cada una aparece solo para los roles que pueden realizarla.
- **Numbers**, **Templates**, **API Keys**, **Webhooks**: tus propios ítems, para ir directamente a ellos.

**Ask AI** envía lo que escribiste a la IA y transmite la respuesta dentro de la paleta, con **Copy AI answer**. Esta respuesta es solo de conocimiento: no actúa sobre tu cuenta.

## Chat del agente de IA

El botón redondo **Ask AI** en la esquina inferior derecha (en todas las pantallas excepto una conversación de chat abierta) abre el chat lateral. Con la sesión iniciada, es el **Pilot Status agent**, **Agent — acts on your account** (Agente: actúa sobre tu cuenta): responde sobre la API y el producto y puede listar tus números, leer métricas, enviar mensajes y más, mediante las mismas herramientas que el [servidor MCP](/es/integrations/mcp-server), limitado por tu rol. Las herramientas exclusivas del Owner (como la verificación del titular de líneas telefónicas) nunca se ofrecen.

Todo lo que cambia algo (enviar, crear, eliminar) se detiene primero con **The AI will run this on your account. Nothing runs before you confirm.** (La IA ejecutará esto en tu cuenta. Nada se ejecuta antes de que confirmes.), listando cada acción y sus argumentos, con **Confirm & run** y **Cancel**. **Clear** inicia una conversación nueva. A su lado, el botón de WhatsApp (**WhatsApp Support**) abre un chat con el equipo de soporte.

## Feedback

**Feedback** (en el encabezado, o `F`) abre **Feedback**: **Ideas to improve this page...** y **Send**. Registra el mensaje junto con la pantalla en la que estabas y confirma **Feedback sent successfully.** Si buscas ayuda en lugar de hacer sugerencias, el mismo modal te dirige a la documentación (**Need help? see docs**).

## Banners de la parte superior

| Banner | Quién lo ve | Acción |
| --- | --- | --- |
| **New version available**: **Reload the page to use the latest version of Pilot Status.** | Todos, después de un deploy. | **Reload** |
| **Your renewal is due in … days** | Cuando el plan se renueva en 2 días o menos (no en Free, ni cuando ya está suspendido). La facturación por billetera muestra el saldo actual; la facturación con tarjeta indica que se cobrará a la tarjeta. | **Go to Plans** |
| **Get billing notices on WhatsApp** (Owner) / **Verify your WhatsApp number** (los demás) | Cualquier persona cuyo propio WhatsApp no esté verificado. No se puede cerrar. | **Verify WhatsApp**: envía un código a tu número |
| **Meta payment pending: templates blocked** | Owner y Admin, cuando Meta bloqueó una cuenta de WhatsApp Business tuya por un problema de pago. El envío mediante Pilot Status **no** se pausa. | **Open in Meta**, **Show numbers**, **Hide notice** (durante la sesión del navegador) |
| **No connected numbers**: **Connect a WhatsApp number to start sending messages.** | Pantallas con alcance de número, cuando el workspace no tiene ningún número. Esas pantallas muestran **Connect a number to continue**. | **Add Number** (solo para roles que pueden conectar números) |

Ninguno de estos banners aparece en el chat a pantalla completa.

## Hazlo vía API / MCP

| Acción | API / MCP |
| --- | --- |
| Inicio de sesión, onboarding, enlace de un solo uso de los avisos | Solo en el panel. La API se autentica con claves, no con sesiones: consulta [Autenticación](/es/api/authentication). |
| Aceptar o rechazar una invitación | Solo en el panel. Enviar, reenviar y revocar invitaciones: `POST /v1/workspace/members`, `workspace_members_invite`, `workspace_members_resend`, `workspace_members_remove`; consulta [Workspace](/es/api/workspace). |
| Aprobar una app (consentimiento OAuth) | Paso interactivo en el navegador por diseño; no se puede automatizar con scripts. |
| Listar o crear workspaces | `GET`/`POST /v1/workspaces` con una clave de cuenta; MCP `workspaces_list`, `workspaces_create`. Consulta [Workspaces](/es/api/workspaces). |
| Consultar la documentación | MCP `docs_search`. |
| Paleta de comandos, feedback, banners | Solo en el panel. |
