La pantalla **Chatwoot** conecta **un número de WhatsApp a la vez** a una cuenta de Chatwoot. Una vez conectado, las conversaciones de WhatsApp aparecen en una bandeja de Chatwoot y las respuestas de los agentes salen de vuelta por WhatsApp. El subtítulo de la pantalla dice *Connect this number to a Chatwoot instance for bidirectional support.* (conecta este número a una instancia de Chatwoot para atención bidireccional).

Esta página describe la pantalla: qué hace cada botón y cada ventana. Para la integración en sí (requisitos previos como `FRONTEND_URL` y `WHATSAPP_CLOUD_BASE_URL`, cómo se comportan las plantillas y las respuestas de Flow en Chatwoot, qué ven los agentes), lee [Integración con Chatwoot](/es/integrations/chatwoot). Para las llamadas de voz nativas, lee [Llamadas de voz en Chatwoot](/es/integrations/chatwoot-voice).

## Cómo llegar

Barra lateral → **Chatwoot** (ruta `/chatwoot`; atajo de teclado `g`).

La pantalla trabaja sobre el número elegido en el **selector de número** del encabezado. Necesitas un número conectado para usarla. Para configurar Chatwoot para otro número, cambia de número en el encabezado. Cada número tiene su propia integración.

Si la pantalla no puede cargar la integración, muestra *Failed to load the Chatwoot integration.*

## Quién puede usarla

| Rol | Qué obtiene |
| --- | --- |
| **Owner** | Todo. En el kit de configuración nativa, la clave de API `ps_` del número se muestra enmascarada (`••••••••` más los últimos 4 caracteres) con botones para **revelar** y **copiar**. |
| **Admin** | Todo excepto la clave completa: en el kit de configuración nativa, el campo **API key** la muestra enmascarada (`••••••••` más los últimos 4 caracteres), sin botón para revelar ni copiar, y con la nota *Only the workspace owner can reveal the full key.* (solo el propietario del workspace puede revelar la clave completa). |
| **Agent**, **Analyst** | La pantalla está oculta en la barra lateral y la ruta está bloqueada. Cada acción en ella (incluida la lectura del estado) requiere el permiso `integrations:manage`, y el servidor rechaza las llamadas de estos roles. |

## Antes de conectar: el formulario de configuración

Cuando el número todavía no tiene integración, la pantalla muestra **Connect this number to your Chatwoot**. La página indica que toma unos 2 minutos y que necesita tres cosas de tu cuenta de Chatwoot: **Chatwoot address**, **Account ID** y **Access token**. Cada paso recibe una marca de verificación cuando se completa.

| Campo | Qué escribir |
| --- | --- |
| **Your Chatwoot address** | La dirección que ves en el navegador cuando usas Chatwoot, sin nada después del dominio (por ejemplo `https://chatwoot.your-domain.com` o `https://app.chatwoot.com`). Debe ser una URL completa, con `https://`. La barra final se elimina. |
| **Your account ID** | El número de la URL de Chatwoot justo después de `/accounts/` (la pantalla muestra el ejemplo `…/app/accounts/1/dashboard`). |
| **Access token** | En Chatwoot: tu avatar → **Profile** → **Access Tokens**. El botón del ojo muestra u oculta lo que escribiste. Después de escribir la dirección y el ID de la cuenta, el enlace **Open the tokens page in my Chatwoot** abre directamente `<address>/app/accounts/<id>/profile/settings`. |

Si la dirección **no** es `app.chatwoot.com`, un aviso indica que parece un Chatwoot autoalojado. Te pide confirmar la variable `FRONTEND_URL` en tu instancia antes de conectar, porque sin ella la bandeja se rechaza. Consulta [el requisito previo](/es/integrations/chatwoot).

Botones:

- **Test credentials**: una prueba en seco. Verifica los valores contra tu Chatwoot **sin crear ni cambiar nada**. Recibes una lista de verificación con dos líneas, verdes o rojas: si la cuenta aceptó las credenciales y si el token puede acceder a la cuenta. Las etiquetas de las dos líneas se muestran en portugués (*Credenciais aceitas pela conta*, *Permissão de acesso à conta*). Cuando todo pasa: **All good — you can connect.** Editar cualquier campo borra el resultado. Si dejas el token en blanco y el número ya tiene un token guardado, la prueba usa el guardado.
- **Connect Chatwoot**: crea la bandeja en tu Chatwoot y el webhook de vuelta a Pilot Status. Nunca pegas una URL de webhook a mano. El botón se resalta después de una prueba exitosa, pero puedes hacer clic en él sin probar primero.
- **Advanced options** (*channel mode, native voice (most people don't need to touch this)*, modo de canal y voz nativa; la mayoría no necesita tocarlo): abre el selector **Channel mode** (ver abajo).

Mensajes que puedes ver:

- **Instance URL and Account ID are required** o **Access token is required**: un campo está vacío. El token solo es obligatorio cuando el número no tiene un token guardado. Si hay uno guardado, un campo de token en blanco lo conserva.
- *Enter the Chatwoot access token — there is no saved token for this number.*: la versión del servidor del mensaje anterior.
- *Invalid Chatwoot credentials. Check instance URL, account ID and access token.*: Chatwoot rechazó el token, el ID de la cuenta es incorrecto o la dirección no respondió.
- *Invalid request body* (en **Test credentials**): la dirección no es una URL completa (por ejemplo, le falta `https://`). En **Connect Chatwoot**, es el propio navegador el que marca el campo.
- *Chatwoot instance URL refused*: la dirección apunta, o redirige, a una dirección de red interna o privada. Usa la dirección pública de tu Chatwoot. Este mensaje viene en inglés y portugués, separados por `|`.
- *Couldn't create the inbox in Chatwoot. Check the token permissions and Account ID.* (no se pudo crear la bandeja en Chatwoot; revisa los permisos del token y el Account ID).
- *Your Chatwoot rejected the WhatsApp Cloud channel …*: solo en modo nativo. Configura `WHATSAPP_CLOUD_BASE_URL` en tu Chatwoot con la dirección de la capa de Pilot Status y vuelve a conectar.
- *We couldn't reach your Chatwoot to check the existing inbox. Nothing was changed — try again in a moment.* (no pudimos llegar a tu Chatwoot para verificar la bandeja existente; no se cambió nada, inténtalo de nuevo en un momento).

<Note>
  El token de acceso **nunca se vuelve a mostrar**, ni en esta pantalla ni en ninguna respuesta de la API. Pilot Status solo te dice si hay un token guardado. Para cambiarlo, escribe uno nuevo en **Update credentials**.
</Note>

## Modo de canal

El selector **Channel mode** (con una guía **Which one to choose?** de escenarios y advertencias) tiene tres opciones:

- **Automatic (recommended)**: elegimos el modo según el número. Los oficiales van a nativo, los no oficiales van a la réplica.
- **API mirror (Model A)**: Pilot Status replica los mensajes y los medios en Chatwoot. Solo chat. Funciona en un Chatwoot compartido.
- **Native WhatsApp Cloud (Model B)**: Chatwoot habla con Meta directamente a través de la capa de Pilot Status. Habilita voz y llamadas. Requiere un Chatwoot dedicado. Esta opción solo se ofrece cuando el número es elegible para una bandeja nativa: números oficiales de Meta, o números Pilot Status web en el proveedor Evolution GO (solo voz).

En un número web de Evolution GO, **Automatic** siempre usa la réplica por API: la bandeja de voz nativa solo se crea cuando eliges **Native WhatsApp Cloud** tú mismo. Si la bandeja nativa no se puede preparar (por ejemplo, el número no tiene clave de API `ps_`), la conexión vuelve a una bandeja de réplica por API.

Las ventajas y desventajas se explican en [Modo de canal: réplica por API frente a Cloud nativo](/es/integrations/chatwoot#modo-de-canal-espejo-api-vs-cloud-nativo).

## Después de conectar

### Encabezado de estado

El encabezado de la pantalla muestra una insignia con el estado de la integración: **Connected**, **Error** o **Disconnected**. Una tarjeta verde dice *All set — your conversations are mirroring to inbox #…*, seguida de *New WhatsApp messages show up in Chatwoot; agent replies go back to WhatsApp.* (todo listo: tus conversaciones se replican en la bandeja; los mensajes nuevos de WhatsApp aparecen en Chatwoot y las respuestas de los agentes vuelven a WhatsApp). El enlace **Open inbox in Chatwoot** abre el panel de tu cuenta de Chatwoot.

### Cuando la integración entra en estado de error

Si una conexión, una actualización de credenciales o una reconexión falla en tu Chatwoot (credenciales rechazadas, bandeja no creada, Chatwoot inalcanzable), o si Chatwoot empieza a rechazar el token guardado durante la replicación, la integración entra en un estado de error. La insignia del encabezado dice **Error**, y un panel rojo reemplaza la vista de conectado:

- *The Chatwoot connection failed — nothing is being mirrored right now.* (la conexión con Chatwoot falló y no se está replicando nada en este momento), seguido del motivo en palabras simples y del error sin procesar debajo. Sin un motivo de Chatwoot: *Chatwoot did not report a reason.*
- **Try again**: vuelve a ejecutar la conexión con las credenciales guardadas y conserva la bandeja actual, como **Reconnect**.
- **Disconnect**: abre el mismo diálogo **Disconnect Chatwoot?** que la vista de conectado.

Debajo del panel, la tarjeta **Sync history to Chatwoot** sigue disponible mientras la replicación está activa, para que puedas seguir, cancelar o reintentar una sincronización. Luego viene el formulario de configuración, con la dirección y el ID de la cuenta ya completados, para corregir las credenciales. Deja el token en blanco para conservar el guardado, o escribe uno nuevo, y haz clic en **Connect Chatwoot**.

### Actualizar credenciales

Una sección desplegable **Update credentials** contiene los mismos campos (**Instance URL**, **Account ID**, **Access token (agent)**) con la dirección y el ID de la cuenta actuales completados, más el selector **Channel mode**. El campo del token dice **•••••••• (leave blank to keep)** (déjalo en blanco para conservarlo). Déjalo en blanco para conservar el token guardado. Haz clic en **Update** para guardar. Guardar vuelve a ejecutar la conexión con los nuevos valores y el modo seleccionado en el formulario. Cuando la bandeja existente todavía existe en Chatwoot y el modo mantiene el mismo tipo de bandeja, esa bandeja se reutiliza. De lo contrario, se crea una bandeja nueva y se reinician las asociaciones de conversaciones del número, como con **Reconnect**: los mensajes nuevos abren conversaciones nuevas en la nueva bandeja.

### Replicación

El interruptor **Mirroring** (**Active** / **Paused**) pausa o reanuda la integración. *Paused = we stop sending to Chatwoot; no message is lost.* (en pausa dejamos de enviar a Chatwoot; no se pierde ningún mensaje). No se elimina nada.

Si el último intento de replicación falló mientras la integración sigue conectada, un cuadro **Last error** muestra una explicación legible y el error sin procesar debajo. Casos comunes:

- La conversación o la bandeja se eliminó en Chatwoot (se recrea automáticamente; si persiste, usa **Reconnect**).
- Falló la sincronización con Chatwoot (inténtalo de nuevo o usa **Reconnect**).

Un token que pierde el acceso a la cuenta no aparece aquí: pone la integración en el estado de error descrito arriba.

### Detalles de la conexión

Un bloque de solo lectura:

- **Inbox**: el ID de la bandeja de Chatwoot.
- **Account**: el ID de la cuenta.
- **Instance URL**.
- **Token**: **Stored** o **Missing**. El valor en sí nunca se muestra.
- **Last sync**: tiempo relativo; pasa el cursor para ver la hora exacta.

### Mantenimiento: reconectar y desconectar

- **Reconnect** vuelve a ejecutar la conexión con las credenciales guardadas, sin volver a ingresarlas. *Reconnect re-tests the saved credentials and keeps the current inbox — it only creates another one if it was deleted in Chatwoot.* (reconectar vuelve a probar las credenciales guardadas y conserva la bandeja actual; solo crea otra si se eliminó en Chatwoot). También se crea una bandeja nueva cuando el modo guardado ahora necesita otro tipo de bandeja.
- **Disconnect** abre el diálogo **Disconnect Chatwoot?**: *This deletes the inbox in Chatwoot. Open conversations don't migrate.* (esto elimina la bandeja en Chatwoot; las conversaciones abiertas no se migran). Confirma con **Disconnect**. El panel le pide a Chatwoot que elimine la bandeja, quita el webhook nativo si existe y borra las credenciales guardadas. Si Chatwoot no acepta la eliminación de la bandeja (por ejemplo, el token ya no tiene acceso), la integración se elimina de todos modos y la bandeja queda en Chatwoot para que la elimines allí.

### Cambiar el modo de canal

**Change channel mode — now: …** muestra el modo guardado y el mismo selector. Después de elegir un modo distinto, el botón **Switch mode → …** lo aplica. *Applies the new mode and reconnects. If the channel type changes (API mirror ↔ native WhatsApp Cloud), Chatwoot gets a new inbox and the old one stops receiving messages; open conversations don't migrate and history isn't copied on its own. If the channel type stays the same, the current inbox is kept.* (aplica el nuevo modo y reconecta; si cambia el tipo de canal, Chatwoot recibe una bandeja nueva y la anterior deja de recibir mensajes, las conversaciones abiertas no se migran y el historial no se copia solo; si el tipo de canal es el mismo, se conserva la bandeja actual). Por ejemplo, **Automatic** → **API mirror** en un número no oficial conserva la bandeja existente. Para traer mensajes anteriores a una bandeja nueva, usa **Sync history to Chatwoot**. Elige el modo antes de conectar cuando puedas.

### Sincronizar el historial con Chatwoot

Esta tarjeta se muestra mientras la replicación está **Active**, también cuando la integración está en estado de error. *Replays this number's already-stored messages into the Chatwoot inbox so agents can see the recent history.* (vuelve a enviar los mensajes ya guardados de este número a la bandeja de Chatwoot para que los agentes vean el historial reciente). Su uso principal son los números de Meta en coexistencia, cuyo historial importado aparece en **/chat** pero no se replica por sí solo.

El servidor rechaza la sincronización, y el motivo aparece en la tarjeta, cuando:

- el número no es un número de Meta (*Only Meta numbers have importable history.*);
- el número no es un número en coexistencia (*This number is not a coexistence number, so there is no stored history to send.*);
- Chatwoot no está conectado y habilitado para el número (*Connect Chatwoot for this number before sending history.*);
- el número no guarda el contenido de los mensajes (*This number does not store content (RELAY_ONLY), so there is no history to send.*).

Estos rechazos vienen en portugués e inglés, separados por `/`.

Haz clic en **Sync** para abrir el diálogo **Sync history to Chatwoot?**. Enumera tres cosas a tener en cuenta:

- Los mensajes se insertan en el momento de la importación, y la fecha y hora originales se anteponen al cuerpo de cada mensaje.
- Los medios antiguos pueden no importarse (las referencias de Meta caducan) y se muestran como "[mídia]".
- Los agentes pueden recibir una ráfaga de notificaciones, y las conversaciones pueden reabrirse.

Opciones del diálogo:

- **Window**: **30 days** o **90 days**.
- **Mark read when done**: activado por defecto.

Confirma con **Sync**. Solo se ejecuta una sincronización por número a la vez: si ya hay una en curso, la tarjeta simplemente la sigue. Mientras se ejecuta, la tarjeta muestra **Queued…** o **Syncing…**, un contador `done / total`, una barra de progreso y un botón **Cancel**. Cuando termina, ves uno de estos:

- **N messages synced**, y de nuevo el botón **Sync**.
- Un resumen como `N sent · N failed · N media expired`, más el error y un botón **Try again**.
- **Canceled**, más un botón **Try again**. Una ejecución cancelada no muestra línea de error, incluso si se canceló antes de empezar.

**Try again** inicia una nueva ejecución de inmediato, sin el diálogo. Reutiliza la **ventana** de la ejecución que terminó (una ejecución de 90 días se reintenta como de 90 días, incluso después de recargar la página). **Mark read when done** sigue la opción actual del diálogo (activada, después de recargar). Volver a ejecutarla es seguro: solo se vuelven a publicar los mensajes que nunca llegaron.

Con una bandeja **WhatsApp Cloud nativa**, la sincronización solo vuelve a enviar los mensajes que **recibiste** (no los que enviaste), **Mark read when done** no tiene efecto, y los mensajes de audio y sticker llegan sin el prefijo de fecha.

Detalles: [Enviar el historial a Chatwoot](/es/integrations/chatwoot#enviar-historial-a-chatwoot).

### Chatwoot nativo / Voz: el kit de configuración nativa

Para los números elegibles, mientras la integración está conectada, aparece una tarjeta **Native Chatwoot / Voice**. En números oficiales dice *native messages + voice via Chatwoot*. En números web de Evolution GO dice *native voice via Chatwoot (messages go through mirroring)* (voz nativa por Chatwoot; los mensajes pasan por la replicación). Una insignia muestra si la bandeja es actualmente **Native** o **Legacy (API)**.

*The native inbox is created automatically on connect. The values below are informational.* (la bandeja nativa se crea automáticamente al conectar; los valores de abajo son informativos). Cada valor tiene un botón para copiar:

| Valor | Qué es |
| --- | --- |
| **Phone** | El número en formato E.164 con `+`. |
| **Phone number ID** | El ID del número de teléfono en Meta. Los números de Evolution GO reciben un ID sintético que solo se usa para voz. |
| **WhatsApp Business Account ID** | El WABA ID (sintético para números de Evolution GO). |
| **API key** | La **clave de API `ps_`** del número, que una bandeja nativa `whatsapp_cloud` usa como clave de API de su canal. El **Owner** la ve enmascarada (`••••••••` más los últimos 4 caracteres) y puede **revelarla** y copiarla. Todos los demás ven el mismo valor enmascarado, sin botones, y la nota *Only the workspace owner can reveal the full key.* Solo dice **unavailable** cuando el número no tiene clave `ps_`. Es la misma clave que se gestiona en la [pantalla API Keys](/es/dashboard/api-keys). Regenerarla allí rompe la bandeja nativa hasta que pegues la nueva clave en Chatwoot. |
| **Base URL** | La dirección de la capa de Meta de Pilot Status (`https://<your Pilot Status host>/api/layer/meta`). Es el valor para `WHATSAPP_CLOUD_BASE_URL` en tu Chatwoot. |
| **Webhook URL** | `<your Chatwoot address>/webhooks/whatsapp/+<number>`. Muestra *connect to generate* hasta que existe la integración. |

Acciones de la tarjeta:

- **Test configuration**: una autoverificación en el servidor. Usa la clave `ps_` del número para llamar a los endpoints `/{phoneId}/settings` y `/{phoneId}/call_permissions` de la capa (los mismos que llama Chatwoot) y lista cada verificación (`settings`, `call_permissions`) en verde o rojo. Si el número no tiene clave `ps_`, la prueba falla con *Native voice is not available for this number*.
- **View documentation**: abre [Llamadas de voz en Chatwoot](/es/integrations/chatwoot-voice).
- **Manual setup (fallback)**: un cuadro desplegable con un fragmento para la consola de Rails que puedes copiar. Solo lo necesitas si la bandeja se creó a mano en Chatwoot. Activa las llamadas para ese canal:

  ```ruby
  ch = Channel::Whatsapp.find_by(phone_number: "+<number>")
  ch.update!(provider_config: ch.provider_config.merge("calling_enabled" => true))
  ch.inbox.reauthorized!
  ```

## Hazlo por API / MCP

| Acción en la pantalla | API pública | Herramienta MCP |
| --- | --- | --- |
| Ver el estado | [`GET /v1/chatwoot`](/es/playground/chatwoot/chatwoot-status) | `chatwoot_get` |
| Conectar | [`POST /v1/chatwoot`](/es/playground/chatwoot/connect-chatwoot) | `chatwoot_connect` |
| Actualizar credenciales, pausar o reanudar la replicación, reconectar, cambiar de modo | [`PATCH /v1/chatwoot`](/es/playground/chatwoot/update-chatwoot) | `chatwoot_update` |
| Desconectar | [`DELETE /v1/chatwoot`](/es/playground/chatwoot/disconnect-chatwoot). Pasa `?deleteInbox=true` para eliminar también la bandeja, como hace el panel. | `chatwoot_disconnect` |
| Probar credenciales | [`POST /v1/chatwoot/test`](/es/playground/chatwoot/test-chatwoot-credentials) | `chatwoot_test` |
| Sincronizar historial (iniciar, progreso, cancelar) | `POST`, `GET`, `DELETE` en `/v1/chatwoot/history-sync` | `chatwoot_history_replay`, `chatwoot_history_replay_get`, `chatwoot_history_replay_cancel` |
| Kit de configuración nativa y **Test configuration** (autoverificación de voz) | Solo en el panel. La API pública no devuelve el kit, porque expondría la clave `ps_`. Para obtener la clave, consulta [Claves de API](/es/api/api-keys). | — |

Con una clave de API por número, el número viene de la clave. Con una clave de workspace u OAuth, envía el número en el encabezado `x-whatsapp-number-id`. La API nunca devuelve el token de acceso de Chatwoot, solo `hasToken`.
