Te damos la bienvenida a Pilot Status, la plataforma de infraestructura de WhatsApp creada para desarrolladores y productos SaaS. Conecta números de WhatsApp oficiales o no oficiales, envía y recibe mensajes mediante una API REST clara y reacciona a los eventos de entrega mediante webhooks, todo sin tocar un servidor, un proxy ni un gestor de conexiones.

## Empieza en tres pasos

Ya sea que integres WhatsApp en tu producto SaaS o construyas un agente de IA, Pilot Status te lleva de cero a mensajes en vivo en minutos.

<Steps>
  <Step title="Conecta tu número">
    Agrega un número de WhatsApp a tu proyecto: escanea un código QR para una conexión no oficial, o ingresa tus credenciales de Meta Business para la Cloud API oficial o el modo Coexistence. No necesitas configurar un VPS ni un proxy.
  </Step>
  <Step title="Envía mensajes">
    Llama a la API REST con tu clave de API y el ID del número para enviar mensajes de texto, multimedia, botones o plantillas a cualquier usuario de WhatsApp. Cada solicitud devuelve un ID de mensaje que puedes rastrear.
  </Step>
  <Step title="Recibe eventos">
    Configura una URL de webhook en tu panel y empieza a recibir en tiempo real confirmaciones de entrega, notificaciones de lectura y mensajes entrantes, disparados en milisegundos.
  </Step>
</Steps>
