A tela **Chatwoot** conecta **um número de WhatsApp por vez** a uma conta do Chatwoot. Depois de conectado, as conversas do WhatsApp aparecem numa inbox do Chatwoot e as respostas dos atendentes saem pelo WhatsApp. O subtítulo da tela diz *Conecte este número a uma instância Chatwoot para atendimento bidirecional.*

Esta página descreve a tela: o que cada botão e cada modal faz. Para a integração em si (pré-requisitos como `FRONTEND_URL` e `WHATSAPP_CLOUD_BASE_URL`, como templates e respostas de Flow se comportam no Chatwoot, o que o atendente vê), leia [Integração com o Chatwoot](/pt-BR/integrations/chatwoot). Para chamadas de voz nativas, leia [Chamadas de voz no Chatwoot](/pt-BR/integrations/chatwoot-voice).

## Como chegar

Menu lateral → **Chatwoot** (caminho `/chatwoot`; atalho de teclado `g`).

A tela trabalha sobre o número escolhido no **seletor de número** do cabeçalho. É preciso ter um número conectado para usá-la. Para configurar o Chatwoot de outro número, troque o número no cabeçalho. Cada número tem a sua própria integração.

Se a tela não consegue carregar a integração, ela mostra *Falha ao carregar a integração Chatwoot.*

## Quem pode usar

| Papel | O que vê e faz |
| --- | --- |
| **Proprietário** | Tudo. No kit nativo, a chave de API `ps_` do número aparece mascarada (`••••••••` mais os 4 últimos caracteres), com os botões **revelar** e **copiar**. |
| **Administrador** | Tudo, menos a chave completa: no kit nativo o campo **API key** mostra a chave mascarada (`••••••••` mais os 4 últimos caracteres), sem botão de revelar nem de copiar, e o aviso *Só o proprietário do workspace pode revelar a chave completa.* |
| **Atendente**, **Analista** | A tela some do menu e a rota fica bloqueada. Toda ação nela (inclusive ler o status) exige a permissão `integrations:manage`, e o servidor recusa as chamadas desses papéis. |

## Antes de conectar: o formulário

Quando o número ainda não tem integração, a tela mostra **Conecte este número ao seu Chatwoot**. A página avisa que leva cerca de 2 minutos e pede três informações da sua conta no Chatwoot: **Endereço do Chatwoot**, **ID da conta** e **Token de acesso**. Cada passo ganha um sinal de concluído quando é preenchido.

| Campo | O que digitar |
| --- | --- |
| **Endereço do seu Chatwoot** | O endereço que aparece no navegador ao usar o Chatwoot, sem nada depois do domínio (por exemplo `https://chatwoot.seu-dominio.com` ou `https://app.chatwoot.com`). Precisa ser uma URL completa, com `https://`. A barra final é removida. |
| **ID da sua conta** | O número na URL do Chatwoot, logo depois de `/accounts/` (a tela mostra o exemplo `…/app/accounts/1/dashboard`). |
| **Token de acesso** | No Chatwoot: seu avatar → **Perfil** → **Tokens de Acesso**. O botão de olho mostra ou esconde o que você digitou. Depois de preencher o endereço e o ID da conta, o link **Abrir a página de tokens no meu Chatwoot** abre `<endereço>/app/accounts/<id>/profile/settings` direto. |

Se o endereço **não** for `app.chatwoot.com`, um aviso diz que parece um Chatwoot próprio (self-hosted). Ele pede para você confirmar a variável `FRONTEND_URL` na sua instância antes de conectar, porque sem ela a inbox é recusada. Veja [o pré-requisito](/pt-BR/integrations/chatwoot).

Botões:

- **Testar credenciais**: um teste a seco. Confere os valores no seu Chatwoot **sem criar nem alterar nada**. Você recebe uma lista com duas linhas, verdes ou vermelhas: *Credenciais aceitas pela conta* e *Permissão de acesso à conta*. Se tudo passar: **Tudo certo — pode conectar.** Mudar qualquer campo apaga o resultado. Se você deixar o token em branco e o número já tiver um token salvo, o teste usa o token salvo.
- **Conectar Chatwoot**: cria a inbox no seu Chatwoot e o webhook de volta para a Pilot Status. Você nunca cola URL de webhook à mão. O botão fica em destaque depois de um teste aprovado, mas dá para clicar nele sem testar antes.
- **Opções avançadas** — *modo do canal, voz nativa (a maioria não precisa mexer)*: abre o seletor **Modo do canal** (veja abaixo).

Mensagens que podem aparecer:

- **URL da instância e Account ID são obrigatórios** ou **Token de acesso é obrigatório**: há um campo vazio. O token só é obrigatório quando o número não tem um token salvo. Com um salvo, deixar o campo em branco mantém o token.
- *Informe o token de acesso do Chatwoot — não há um token salvo para este número.*: a versão do servidor da mensagem acima.
- *Invalid Chatwoot credentials. Check instance URL, account ID and access token.* (em inglês): o Chatwoot recusou o token, o ID da conta está errado ou o endereço não respondeu.
- *Invalid request body* (em inglês, ao **Testar credenciais**): o endereço não é uma URL completa (por exemplo, falta o `https://`). Ao **Conectar Chatwoot**, o próprio navegador aponta o campo.
- *URL da instância do Chatwoot recusada*: o endereço aponta, ou redireciona, para um endereço interno ou de rede privada. Use o endereço público do seu Chatwoot. Essa mensagem vem em inglês e em português, separados por `|`.
- *Não foi possível criar a inbox no Chatwoot. Verifique as permissões do token e o Account ID.*
- *Seu Chatwoot recusou o canal WhatsApp Cloud …*: só no modo nativo. Defina `WHATSAPP_CLOUD_BASE_URL` no seu Chatwoot com o endereço do layer da Pilot Status e conecte de novo.
- *Não conseguimos falar com o seu Chatwoot para conferir a inbox existente. Nada foi alterado — tente novamente em instantes.*

<Note>
  O token de acesso **nunca é mostrado de volta**, nem nesta tela nem em resposta de API. A Pilot Status só informa se há um token salvo. Para trocá-lo, digite um novo em **Atualizar credenciais**.
</Note>

## Modo do canal

O seletor **Modo do canal** (com o guia **Qual escolher?**, de cenários e avisos) tem três opções:

- **Automático (recomendado)**: escolhemos o modo pelo número. Oficial vai para o nativo, não-oficial vai para o espelho.
- **Espelho via API (Modelo A)**: a Pilot Status espelha mensagens e mídia para o Chatwoot. Só chat. Funciona em Chatwoot compartilhado.
- **Nativo WhatsApp Cloud (Modelo B)**: o Chatwoot fala direto com a Meta pelo layer da Pilot Status. Habilita voz e chamada. Exige Chatwoot dedicado. Essa opção só aparece quando o número pode ter inbox nativa: números oficiais da Meta, ou números web da Pilot Status no provedor Evolution GO (só voz).

Num número web Evolution GO, **Automático** sempre usa o espelho via API: a inbox nativa de voz só é criada quando você mesmo escolhe **Nativo WhatsApp Cloud**. Se a inbox nativa não pode ser montada (por exemplo, o número não tem chave de API `ps_`), a conexão cai para uma inbox de espelho via API.

As vantagens e os riscos de cada um estão em [Modo de canal: espelho via API vs nativo Cloud](/pt-BR/integrations/chatwoot).

## Depois de conectar

### Cabeçalho de status

O cabeçalho da tela mostra um selo com o estado da integração: **Conectado**, **Erro** ou **Desconectado**. Um cartão verde diz *Tudo certo — suas conversas já espelham para a inbox #…*, seguido de *As mensagens novas do WhatsApp aparecem no Chatwoot; as respostas dos agentes voltam pro WhatsApp.* O link **Abrir inbox no Chatwoot** abre o painel da sua conta no Chatwoot.

### Quando a integração cai em estado de erro

Se uma conexão, uma atualização de credenciais ou uma reconexão falha no seu Chatwoot (credenciais recusadas, inbox não criada, Chatwoot fora do ar), ou se o Chatwoot passa a recusar o token salvo durante o espelhamento, a integração entra em estado de erro. O selo do cabeçalho mostra **Erro**, e um painel vermelho substitui a visão de conectado:

- *A conexão com o Chatwoot falhou — nada está sendo espelhado agora.*, seguido do motivo em linguagem simples e, abaixo, o erro cru. Sem motivo informado pelo Chatwoot: *O Chatwoot não informou o motivo.*
- **Tentar novamente**: refaz a conexão com as credenciais salvas e mantém a inbox atual, como o **Reconectar**.
- **Desconectar**: abre o mesmo diálogo **Desconectar Chatwoot?** da visão de conectado.

Abaixo do painel, o cartão **Sincronizar histórico p/ Chatwoot** continua disponível enquanto o espelhamento está ligado, para você acompanhar, cancelar ou repetir uma sincronização. Em seguida vem o formulário de configuração, com o endereço e o ID da conta preenchidos, para corrigir as credenciais. Deixe o token em branco para manter o salvo, ou digite um novo, e clique em **Conectar Chatwoot**.

### Atualizar credenciais

A seção recolhível **Atualizar credenciais** traz os mesmos campos (**URL da instância**, **Account ID**, **Token de acesso (agente)**) com o endereço e o ID da conta atuais já preenchidos, mais o seletor **Modo do canal**. O campo do token diz **•••••••• (deixe em branco para manter)**. Deixe em branco para manter o token salvo. Clique em **Atualizar** para salvar. Salvar refaz a conexão com os valores novos e com o modo escolhido no formulário. Quando a inbox atual ainda existe no Chatwoot e o modo mantém o mesmo tipo de inbox, ela é reaproveitada. Caso contrário, uma inbox nova é criada e os mapeamentos de conversa do número são resetados, como no **Reconectar**: as mensagens novas abrem conversas novas na inbox nova.

### Espelhamento

O interruptor **Espelhamento** (**Ativo** / **Pausado**) pausa ou retoma a integração. *Pausado = paramos de enviar ao Chatwoot; nenhuma mensagem se perde.* Nada é apagado.

Se a última tentativa de espelhamento falhou e a integração continua conectada, a caixa **Último erro** mostra uma explicação legível e, abaixo, o erro cru. Casos comuns:

- A conversa ou a inbox foi apagada no Chatwoot (ela é recriada automaticamente; se persistir, use **Reconectar**).
- Falha ao sincronizar com o Chatwoot (tente de novo ou use **Reconectar**).

Um token que perde o acesso à conta não aparece aqui: ele leva a integração ao estado de erro descrito acima.

### Detalhes da conexão

Um bloco só de leitura:

- **Inbox**: o ID da inbox no Chatwoot.
- **Account**: o ID da conta.
- **URL da instância**.
- **Token**: **Salvo** ou **Ausente**. O valor em si nunca aparece.
- **Última sincronização**: tempo relativo; passe o mouse para ver a hora exata.

### Manutenção: reconectar e desconectar

- **Reconectar** refaz a conexão com as credenciais salvas, sem redigitá-las. *Reconectar testa de novo as credenciais salvas e mantém a inbox atual — só cria outra se ela tiver sido apagada no Chatwoot.* Uma inbox nova também é criada quando o modo salvo passa a exigir outro tipo de inbox.
- **Desconectar** abre o diálogo **Desconectar Chatwoot?**: *Isso apaga a inbox no Chatwoot. As conversas abertas não migram.* Confirme em **Desconectar**. O painel pede ao Chatwoot que apague a inbox, remove o webhook nativo se houver um e limpa as credenciais salvas. Se o Chatwoot não aceitar apagar a inbox (por exemplo, o token não tem mais acesso), a integração é removida mesmo assim e a inbox fica no Chatwoot para você apagar lá.

### Alterar modo do canal

**Alterar modo do canal — agora: …** mostra o modo salvo e o mesmo seletor. Depois de escolher outro modo, o botão **Trocar modo → …** aplica a troca. *Aplica o novo modo e reconecta. Se o tipo de canal muda (espelho via API ↔ nativo WhatsApp Cloud), o Chatwoot ganha uma inbox nova e a antiga para de receber mensagens; as conversas abertas não migram e o histórico não é copiado sozinho. Se o tipo de canal continua o mesmo, a inbox atual é mantida.* Por exemplo, **Automático** → **Espelho via API** num número não-oficial mantém a inbox atual. Para levar mensagens antigas a uma inbox nova, use **Sincronizar histórico p/ Chatwoot**. Sempre que puder, escolha o modo antes de conectar.

### Sincronizar histórico p/ Chatwoot

Este cartão aparece com o espelhamento **Ativo**, inclusive quando a integração está em estado de erro. *Reenvia as mensagens já armazenadas deste número para a inbox do Chatwoot, para os atendentes verem o histórico recente.* O uso principal é em números Meta de coexistência, cujo histórico importado aparece em **/chat** mas não é espelhado sozinho.

O servidor recusa a sincronização, e o motivo aparece no próprio cartão, quando:

- o número não é Meta (*Somente números Meta possuem histórico importável.*);
- o número não é de coexistência (*Este número não é de coexistência, então não há histórico salvo para enviar.*);
- o Chatwoot não está conectado e ativo para o número (*Conecte o Chatwoot deste número antes de enviar o histórico.*);
- o número não armazena o conteúdo das mensagens (*Este número não armazena conteúdo (RELAY_ONLY), então não há histórico para enviar.*).

Essas recusas vêm em português e em inglês, separados por `/`.

Clique em **Sincronizar** para abrir o diálogo **Sincronizar histórico p/ Chatwoot?**. Ele lista três coisas para esperar:

- As mensagens entram com a data e hora do import, e a data original vai no início do texto de cada mensagem.
- Mídia antiga pode não importar (as referências da Meta expiram) e aparecer como "[mídia]".
- Os atendentes podem receber uma rajada de notificações, e conversas podem ser reabertas.

Opções do diálogo:

- **Período**: **30 dias** ou **90 dias**.
- **Marcar como lidas ao final**: ligado por padrão.

Confirme em **Sincronizar**. Só roda uma sincronização por número de cada vez: se já houver uma em andamento, o cartão simplesmente passa a acompanhá-la. Enquanto roda, o cartão mostra **Na fila…** ou **Sincronizando…**, um contador `feitas / total`, uma barra de progresso e o botão **Cancelar**. Ao terminar, você vê uma destas:

- **N mensagens sincronizadas**, e o botão **Sincronizar** de novo.
- Um resumo como `N enviadas · N falharam · N mídias expiradas`, mais o erro e o botão **Tentar novamente**.
- **Cancelado**, mais o botão **Tentar novamente**. Uma execução cancelada não mostra linha de erro, nem quando foi cancelada antes de começar.

**Tentar novamente** inicia uma nova execução na hora, sem o diálogo. Ela reaproveita o **período** da execução que terminou (uma execução de 90 dias é repetida com 90 dias, mesmo depois de recarregar a página). **Marcar como lidas ao final** segue a opção atual do diálogo (ligado, depois de recarregar). Rodar de novo é seguro: só as mensagens que nunca chegaram são reenviadas.

Com uma inbox **nativa WhatsApp Cloud**, a sincronização só reenvia as mensagens **recebidas** (não as enviadas), **Marcar como lidas ao final** não tem efeito, e áudios e figurinhas chegam sem o prefixo de data.

Detalhes: [Enviar histórico para o Chatwoot](/pt-BR/integrations/chatwoot).

### Chatwoot nativo / Voz: o kit de configuração nativa

Para números elegíveis, enquanto a integração está conectada, aparece o cartão **Chatwoot nativo / Voz**. Em números oficiais ele diz *mensagens + voz nativas via Chatwoot*. Em números web Evolution GO ele diz *voz nativa via Chatwoot (mensagens seguem pelo espelhamento)*. Um selo mostra se a inbox hoje está **Nativo** ou **Legado (API)**.

*A inbox nativa é criada automaticamente ao conectar. Os valores abaixo são informativos.* Cada valor tem botão de copiar:

| Valor | O que é |
| --- | --- |
| **Telefone** | O número em formato E.164, com `+`. |
| **Phone number ID** | O ID do telefone na Meta. Números Evolution GO recebem um ID sintético, usado só para voz. |
| **WhatsApp Business Account ID** | O ID da WABA (sintético para números Evolution GO). |
| **API key** | A **chave de API `ps_` do número**, que a inbox nativa `whatsapp_cloud` usa como chave do canal. O **Proprietário** a vê mascarada (`••••••••` mais os 4 últimos caracteres) e pode **revelar** e copiar. Os demais veem o mesmo valor mascarado, sem botões, e o aviso *Só o proprietário do workspace pode revelar a chave completa.* O campo só mostra **indisponível** quando o número não tem chave `ps_`. É a mesma chave gerenciada na [tela API Keys](/pt-BR/dashboard/api-keys). Se você regenerá-la lá, a inbox nativa para de funcionar até você colar a chave nova no Chatwoot. |
| **Base URL** | O endereço do layer Meta da Pilot Status (`https://<seu host Pilot Status>/api/layer/meta`). É o valor de `WHATSAPP_CLOUD_BASE_URL` no seu Chatwoot. |
| **Webhook URL** | `<endereço do seu Chatwoot>/webhooks/whatsapp/+<número>`. Mostra *conecte para gerar* enquanto a integração não existe. |

Ações do cartão:

- **Testar configuração**: uma autoverificação feita no servidor. Ela usa a chave `ps_` do número para chamar os endpoints `/{phoneId}/settings` e `/{phoneId}/call_permissions` do layer (os mesmos que o Chatwoot chama) e lista cada verificação (`settings`, `call_permissions`) em verde ou vermelho. Se o número não tem chave `ps_`, o teste falha com *Native voice is not available for this number* (em inglês).
- **Ver documentação**: abre [Chamadas de voz no Chatwoot](/pt-BR/integrations/chatwoot-voice).
- **Configuração manual (fallback)**: uma caixa recolhível com um trecho para o console Rails, pronto para copiar. Só é necessário se a inbox foi criada à mão no Chatwoot. Ele liga as chamadas nesse canal:

  ```ruby
  ch = Channel::Whatsapp.find_by(phone_number: "+<número>")
  ch.update!(provider_config: ch.provider_config.merge("calling_enabled" => true))
  ch.inbox.reauthorized!
  ```

## Fazer pela API / MCP

| Ação na tela | API pública | Ferramenta MCP |
| --- | --- | --- |
| Ver o status | [`GET /v1/chatwoot`](/pt-BR/playground/chatwoot/chatwoot-status) | `chatwoot_get` |
| Conectar | [`POST /v1/chatwoot`](/pt-BR/playground/chatwoot/connect-chatwoot) | `chatwoot_connect` |
| Atualizar credenciais, pausar ou retomar o espelhamento, reconectar, trocar o modo | [`PATCH /v1/chatwoot`](/pt-BR/playground/chatwoot/update-chatwoot) | `chatwoot_update` |
| Desconectar | [`DELETE /v1/chatwoot`](/pt-BR/playground/chatwoot/disconnect-chatwoot). Use `?deleteInbox=true` para apagar a inbox também, como o painel faz. | `chatwoot_disconnect` |
| Testar credenciais | [`POST /v1/chatwoot/test`](/pt-BR/playground/chatwoot/test-chatwoot-credentials) | `chatwoot_test` |
| Sincronizar histórico (iniciar, acompanhar, cancelar) | `POST`, `GET`, `DELETE` em `/v1/chatwoot/history-sync` | `chatwoot_history_replay`, `chatwoot_history_replay_get`, `chatwoot_history_replay_cancel` |
| Kit nativo e **Testar configuração** (autoverificação de voz) | Só pelo painel. A API pública não devolve o kit, porque isso exporia a chave `ps_`. Para obter a chave, veja [Chaves de API](/pt-BR/api/api-keys). | — |

Com uma chave de API de número, o número vem da própria chave. Com chave de workspace ou OAuth, informe o número no cabeçalho `x-whatsapp-number-id`. A API nunca devolve o token de acesso do Chatwoot, só `hasToken`.
