A tela **Chatwoot** conecta **um número de WhatsApp por vez** a uma conta do Chatwoot. Depois de conectado, as conversas do WhatsApp aparecem numa inbox do Chatwoot e as respostas dos atendentes saem pelo WhatsApp.

Esta página descreve a tela: o que cada botão e cada modal faz. Para a integração em si (pré-requisitos como `FRONTEND_URL` e `WHATSAPP_CLOUD_BASE_URL`, como templates e respostas de Flow se comportam no Chatwoot, o que o atendente vê), leia [Integração com o Chatwoot](/pt-BR/integrations/chatwoot). Para chamadas de voz nativas, leia [Chamadas de voz no Chatwoot](/pt-BR/integrations/chatwoot-voice).

## Como chegar

Menu lateral → **Chatwoot** (caminho `/chatwoot`; atalho de teclado `g`).

A tela trabalha sobre o número escolhido no **seletor de número** do cabeçalho. É preciso ter um número conectado para usá-la. Para configurar o Chatwoot de outro número, troque o número no cabeçalho. Cada número tem a sua própria integração.

## Quem pode usar

| Papel | O que vê e faz |
| --- | --- |
| **Proprietário** | Tudo, inclusive **revelar** e **copiar** a chave de API `ps_` do número no kit nativo. |
| **Administrador** | Tudo, menos revelar a chave. O kit mostra a chave mascarada (`••••••••` mais os 4 últimos caracteres), sem botão de revelar nem de copiar. |
| **Atendente**, **Analista** | A tela some do menu e a rota fica bloqueada. Tudo nela exige a permissão `integrations:manage`. |

## Antes de conectar: o formulário

Quando o número ainda não tem integração, a tela mostra **Conecte este número ao seu Chatwoot**. A página avisa que leva cerca de 2 minutos e pede três informações da sua conta no Chatwoot: **Endereço do Chatwoot**, **ID da conta** e **Token de acesso**.

| Campo | O que digitar |
| --- | --- |
| **Endereço do seu Chatwoot** | O endereço que aparece no navegador ao usar o Chatwoot, sem nada depois do domínio (por exemplo `https://chatwoot.seu-dominio.com` ou `https://app.chatwoot.com`). A barra final é removida. |
| **ID da sua conta** | O número na URL do Chatwoot, logo depois de `/app/accounts/`. |
| **Token de acesso** | No Chatwoot: seu avatar → **Perfil** → **Tokens de Acesso**. O botão **Revelar token** / **Ocultar token** mostra ou esconde o que você digitou. Depois de preencher o endereço e o ID da conta, o link **Abrir a página de tokens no meu Chatwoot** abre `<endereço>/app/accounts/<id>/profile/settings` direto. |

Se o endereço **não** for `app.chatwoot.com`, um aviso diz que parece um Chatwoot próprio (self-hosted). Ele pede para você confirmar a variável `FRONTEND_URL` na sua instância antes, porque sem ela a inbox é recusada. Veja [o pré-requisito](/pt-BR/integrations/chatwoot).

Botões:

- **Testar credenciais**: um teste a seco. Confere os três valores no seu Chatwoot **sem criar nem alterar nada**. Você recebe uma lista com uma linha por verificação (verde ou vermelha). Se tudo passar: **Tudo certo — pode conectar.** Mudar qualquer campo apaga o resultado.
- **Conectar Chatwoot**: cria a inbox no seu Chatwoot e o webhook de volta para a Pilot Status. Você nunca cola URL de webhook à mão.
- **Opções avançadas** — *modo do canal, voz nativa (a maioria não precisa mexer)*: abre o seletor **Modo do canal** (veja abaixo).

<Note>
  O token de acesso **nunca é mostrado de volta**, nem nesta tela nem em resposta de API. A Pilot Status só informa se há um token salvo. Para trocá-lo, digite um novo em **Atualizar credenciais**.
</Note>

## Modo do canal

O seletor **Modo do canal** (com o guia **Qual escolher?**) tem três opções:

- **Automático (recomendado)**: escolhemos o modo pelo número. Oficial vai para o nativo, não-oficial vai para o espelho.
- **Espelho via API (Modelo A)**: a Pilot Status espelha mensagens e mídia para o Chatwoot. Só chat. Funciona em Chatwoot compartilhado.
- **Nativo WhatsApp Cloud (Modelo B)**: o Chatwoot fala direto com a Meta pelo layer da Pilot Status. Habilita voz e chamada. Exige Chatwoot dedicado. Essa opção só aparece quando o número pode ter inbox nativa: números oficiais da Meta, ou números web da Pilot Status no provedor Evolution GO (só voz).

As vantagens e os riscos de cada um estão em [Modo de canal: espelho via API vs nativo Cloud](/pt-BR/integrations/chatwoot).

## Depois de conectar

### Cabeçalho de status

O cabeçalho da tela mostra um selo de status: **Conectado**, **Erro**, **Pendente**, **Desabilitado** ou **Desconectado**. Um cartão verde diz *Tudo certo — suas conversas já espelham para a inbox …*. O botão **Abrir inbox no Chatwoot** abre o painel da sua conta no Chatwoot.

### Atualizar credenciais

A seção recolhível **Atualizar credenciais** traz o mesmo formulário com o endereço e o ID da conta atuais já preenchidos. O campo do token diz **•••••••• (deixe em branco para manter)**. Deixe em branco para manter o token salvo. Clique em **Atualizar** para salvar. Salvar refaz a conexão com os valores novos.

### Espelhamento

O interruptor **Espelhamento** (**Ativo** / **Pausado**) pausa ou retoma a integração. *Pausado = paramos de enviar ao Chatwoot; nenhuma mensagem se perde.* Nada é apagado.

Se a última sincronização falhou, a caixa **Último erro** mostra uma explicação legível e, abaixo, o erro cru. Casos comuns:

- O token não tem acesso à conta.
- A inbox ou a conversa foi apagada no Chatwoot (ela é recriada automaticamente).
- Seu Chatwoot recusou o canal WhatsApp Cloud porque `WHATSAPP_CLOUD_BASE_URL` não aponta para o layer da Pilot Status.
- Não foi possível criar a inbox (confira as permissões do token e o ID da conta).

### Detalhes da conexão

Um bloco só de leitura:

- **Inbox**: o ID da inbox no Chatwoot.
- **Account**: o ID da conta.
- **URL da instância**.
- **Token**: **Salvo** ou **Ausente**. O valor em si nunca aparece.
- **Última sincronização**: tempo relativo; passe o mouse para ver a hora exata.

### Manutenção: reconectar e desconectar

- **Reconectar** recria a inbox sem redigitar as credenciais.
- **Desconectar** abre o diálogo **Desconectar Chatwoot?**: *Isso apaga a inbox no Chatwoot. As conversas abertas não migram.* Confirme em **Desconectar**. Pelo painel, desconectar sempre apaga a inbox no Chatwoot e limpa as credenciais salvas.

### Alterar modo do canal

**Alterar modo do canal — agora: …** mostra o modo salvo e o mesmo seletor. Depois de escolher outro modo, o botão **Trocar modo → …** aplica a troca. *Ele reconecta e cria uma inbox nova no Chatwoot. O histórico re-espelha; conversas abertas não migram.* Sempre que puder, escolha o modo antes de conectar.

### Sincronizar histórico p/ Chatwoot

Este cartão só aparece com o espelhamento **Ativo**. *Ele reenvia as mensagens já armazenadas deste número para a inbox do Chatwoot, para os atendentes verem o histórico recente.* O uso principal é em números Meta de coexistência, cujo histórico importado aparece em **/chat** mas não é espelhado sozinho. Quando o número não se qualifica, o servidor recusa e o motivo aparece no próprio cartão.

Clique em **Sincronizar** para abrir o diálogo **Sincronizar histórico p/ Chatwoot?**. Ele lista três coisas para esperar:

- As mensagens entram com a data e hora do import, e a data original vai no início do texto de cada mensagem.
- Mídia antiga pode não importar (as referências da Meta expiram) e aparecer como "[mídia]".
- Os atendentes podem receber uma rajada de notificações, e conversas podem ser reabertas.

Opções do diálogo:

- **Período**: **30 dias** ou **90 dias**.
- **Marcar como lidas ao final**: ligado por padrão.

Confirme em **Sincronizar**. Enquanto roda, o cartão mostra **Na fila…** ou **Sincronizando…**, um contador `feitas / total`, uma barra de progresso e o botão **Cancelar**. Ao terminar, você vê uma destas:

- **N mensagens sincronizadas**.
- Um resumo como `N enviadas · N falharam · N mídias expiradas`, mais o erro e o botão **Tentar novamente**.
- **Cancelado**.

Rodar de novo é seguro: só as mensagens que nunca chegaram são reenviadas. Detalhes: [Enviar histórico para o Chatwoot](/pt-BR/integrations/chatwoot).

### Chatwoot nativo / Voz: o kit de configuração nativa

Para números elegíveis aparece o cartão **Chatwoot nativo / Voz**. Em números oficiais ele diz *mensagens + voz nativas via Chatwoot*. Em números web Evolution GO ele diz *voz nativa via Chatwoot (mensagens seguem pelo espelhamento)*. Um selo mostra se a inbox hoje está **Nativo** ou **Legado (API)**.

*A inbox nativa é criada automaticamente ao conectar. Os valores abaixo são informativos.* Cada valor tem botão de copiar:

| Valor | O que é |
| --- | --- |
| **Telefone** | O número em formato E.164, com `+`. |
| **Phone number ID** | O ID do telefone na Meta. Números Evolution GO recebem um ID sintético, usado só para voz. |
| **WhatsApp Business Account ID** | O ID da WABA (sintético para números Evolution GO). |
| **API key** | A **chave de API `ps_` do número**, que a inbox nativa `whatsapp_cloud` usa como chave do canal. O **Proprietário** pode **revelar** e copiar. Os demais veem `••••••••` mais os 4 últimos caracteres. É a mesma chave gerenciada na [tela API Keys](/pt-BR/dashboard/api-keys). Se você regenerá-la lá, a inbox nativa para de funcionar até você colar a chave nova no Chatwoot. |
| **Base URL** | O endereço do layer Meta da Pilot Status (`https://<seu host Pilot Status>/api/layer/meta`). É o valor de `WHATSAPP_CLOUD_BASE_URL` no seu Chatwoot. |
| **Webhook URL** | `<endereço do seu Chatwoot>/webhooks/whatsapp/+<número>`. Mostra *conecte para gerar* enquanto a integração não existe. |

Ações do cartão:

- **Testar configuração**: uma autoverificação feita no servidor. Ela usa a chave `ps_` do número para chamar os endpoints `/{phoneId}/settings` e `/{phoneId}/call_permissions` do layer (os mesmos que o Chatwoot chama) e lista cada verificação em verde ou vermelho.
- **Ver documentação**: abre [Chamadas de voz no Chatwoot](/pt-BR/integrations/chatwoot-voice).
- **Configuração manual (fallback)**: uma caixa recolhível com um trecho para o console Rails, pronto para copiar. Só é necessário se a inbox foi criada à mão no Chatwoot. Ele liga as chamadas nesse canal:

  ```ruby
  ch = Channel::Whatsapp.find_by(phone_number: "+<número>")
  ch.update!(provider_config: ch.provider_config.merge("calling_enabled" => true))
  ch.inbox.reauthorized!
  ```

## Fazer pela API / MCP

| Ação na tela | API pública | Ferramenta MCP |
| --- | --- | --- |
| Ver o status | [`GET /v1/chatwoot`](/pt-BR/playground/chatwoot/chatwoot-status) | `chatwoot_get` |
| Conectar | [`POST /v1/chatwoot`](/pt-BR/playground/chatwoot/connect-chatwoot) | `chatwoot_connect` |
| Atualizar credenciais, pausar ou retomar o espelhamento, reconectar, trocar o modo | [`PATCH /v1/chatwoot`](/pt-BR/playground/chatwoot/update-chatwoot) | `chatwoot_update` |
| Desconectar | [`DELETE /v1/chatwoot`](/pt-BR/playground/chatwoot/disconnect-chatwoot). Use `?deleteInbox=true` para apagar a inbox também, como o painel faz. | `chatwoot_disconnect` |
| Testar credenciais | [`POST /v1/chatwoot/test`](/pt-BR/playground/chatwoot/test-chatwoot-credentials) | `chatwoot_test` |
| Sincronizar histórico (iniciar, acompanhar, cancelar) | `POST`, `GET`, `DELETE` em `/v1/chatwoot/history-sync` | `chatwoot_history_replay`, `chatwoot_history_replay_get`, `chatwoot_history_replay_cancel` |
| Kit nativo e **Testar configuração** (autoverificação de voz) | Só pelo painel. A API pública não devolve o kit, porque isso exporia a chave `ps_`. Para obter a chave, veja [Chaves de API](/pt-BR/api/api-keys). | — |

Com uma chave de API de número, o número vem da própria chave. Com chave de workspace ou OAuth, informe o número no cabeçalho `x-whatsapp-number-id`. A API nunca devolve o token de acesso do Chatwoot, só `hasToken`.
