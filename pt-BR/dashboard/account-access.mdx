Esta página cobre o que fica em volta das telas do dashboard: como você entra, como entra num workspace, como autoriza um app externo e as partes da moldura (cabeçalho, paleta, chat, avisos) que aparecem em todas as telas.

## Entrar (`/login`)

**Entrar** — **Escolha um método para continuar**. Três métodos, cada um com um atalho de teclado quando nenhum campo está com o foco:

| Método | Atalho | O que acontece |
| --- | --- | --- |
| **Continuar com WhatsApp** | `1` | Só aparece enquanto o login por WhatsApp da plataforma está disponível. Digite seu número e clique em **Enviar código**: **Você receberá um código de 6 dígitos que expira em 5 minutos.** Digite-o e clique em **Entrar** (ou `Ctrl`/`⌘` + `Enter`). |
| **Continuar com Google** | `2` | Vai ao Google e volta. |
| **Continuar com GitHub** | `3` | Vai ao GitHub e volta. |

`Esc` volta para a página inicial. O método usado da última vez leva a etiqueta **Último**.

Na etapa do código do WhatsApp você também tem **Reenviar código** (com contagem regressiva, **Reenviar código em …s**) e **Trocar número**. Mensagens que podem aparecer:

- **Este número não está no WhatsApp.** — o número não pode receber o código.
- **Já enviamos o código, confira seu WhatsApp.** — um código acabou de sair; use-o em vez de pedir outro.
- **Não foi possível entregar o código neste número. Confira se ele tem WhatsApp.** — o código não pôde ser entregue.
- **Muitos envios de código agora. Aguarde alguns minutos e tente novamente.** — muitos códigos foram pedidos em pouco tempo.
- **Login via WhatsApp indisponível no momento. Use outro método de acesso.** — entre com Google ou GitHub.
- **Código inválido ou expirado.** — digite o código mais recente, ou reenvie depois de 5 minutos.
- **Erro de configuração do login social. Tente novamente mais tarde.** — a volta do Google/GitHub falhou do nosso lado.

Não há senha. A conta é a pessoa: WhatsApp, Google e GitHub são só formas de entrar nela, e as extras são vinculadas ou desvinculadas no [Perfil](/pt-BR/dashboard/profile). Depois de entrar, você cai na tela que tentava abrir, ou no Dashboard.

### Link de acesso único dos avisos de cobrança (`/a`)

Os avisos de cobrança e de limite do plano podem trazer um link de acesso. Ele abre uma página que diz **Entrar como \{email\}** (ou **Entrar como a conta do WhatsApp \{phone\}**), **Você vai acessar o workspace \{workspace\}.** e **Este link funciona uma única vez.** Clique em **Continuar** para entrar, ou em **Não é você? Entrar com outra conta**.

Se o link não fizer o login, você cai em `/login` com o motivo:

| Mensagem | Significado |
| --- | --- |
| **Este link já foi usado. Entre para continuar.** | Cada link entra uma vez só. |
| **Este link expirou. Entre para continuar.** | O link passou da validade. |
| **Não reconhecemos este link de acesso. Abra o link mais recente que enviamos ou entre para continuar.** | O link está quebrado ou foi substituído por um mais novo. |
| **Não foi possível entrar com este link. Entre para continuar.** | O link não pôde ser usado agora. |

**Muitas tentativas em pouco tempo.** ou **Não conseguimos abrir o link agora.** mantêm você na página com **Tentar de novo**.

## Onboarding (`/onboarding`)

Quando o onboarding está ligado na plataforma, um workspace que ainda não o concluiu é mandado para cá depois do login. A tela diz **Bem-vindo ao Pilot Status** — **Configure seu WhatsApp para começar a enviar mensagens.** (ou **Atualize seu WhatsApp** quando você vem do perfil depois de trocar de número).

- **Informe seu número de WhatsApp** — é salvo no seu perfil como um campo comum. Ele **não** verifica o número: a verificação (com código) é feita no [Perfil](/pt-BR/dashboard/profile) e é o que faz os avisos de cobrança chegarem pelo WhatsApp.
- **Vincule sua conta** — vincule Google ou GitHub (**Vincular** / **Re-vincular**, situação **Vinculado** / **Não vinculado**). **Vincule Google ou GitHub ao seu WhatsApp antes de continuar.**
- **Ir para o Dashboard** — fica habilitado quando há um número e pelo menos um login social vinculado.

## Aceitar um convite (`/invite/{token}`)

O e-mail do convite (ou o link que um Proprietário/Administrador copiou — veja [Membros](/pt-BR/dashboard/members)) abre esta página. Se você não estiver logado, é levado para entrar primeiro e volta com o convite intacto.

A página mostra **Você foi convidado para \{workspace\}**, o papel (pelo nome interno, como **AGENT** ou **ANALYST**) com uma linha explicando, **Convite enviado para \{e-mail\}** e a data de expiração. Botões:

- **Aceitar convite** — você entra, o dashboard troca para aquele workspace e mostra **Você entrou no workspace** com o seu papel.
- **Recusar** → confirmação **Recusar apaga este convite. Para entrar depois, alguém do workspace precisa te convidar de novo.** → **Sim, recusar** (ou **Voltar**). Recusar queima o link de vez: a página mostra **Convite recusado** — *Não avisamos ninguém automaticamente. Se foi engano, peça um novo convite a quem te chamou.* — e quem convidou vê o convite como recusado.

| Erro | O que fazer |
| --- | --- |
| **Convite não encontrado** | O link não existe, foi substituído por um mais novo (cada **Reenviar** mata o link anterior), foi revogado ou já foi recusado. Peça um convite novo. |
| **Convite expirado** | Convites valem **7 dias**. Peça a quem te convidou para reenviar. |
| **Convite já usado** | Já foi aceito. Se você já é membro, é só entrar. |
| **Convite é de outro e-mail** | O convite só vale para o e-mail convidado. Saia e entre com essa conta. |
| **Link incompleto** | Abra o link do e-mail inteiro. |
| **Não foi possível abrir o convite** | Outro problema (por exemplo, tentativas demais). Tente de novo em instantes ou peça um convite novo. |

## Autorizar um app (`/oauth/consent`)

Quando um app externo se conecta à sua conta por OAuth — por exemplo o servidor MCP do Pilot Status adicionado como **conector personalizado** no Claude — você cai em **Autorização de acesso** — **Conectar à sua conta Pilot Status**: *Um aplicativo (ex.: Claude) está solicitando acesso. Escolha o que ele pode acessar.* Se você não estiver logado, entra primeiro e volta para esta tela. Se o app enviou um pedido incompleto, a tela diz **Solicitação de conexão inválida** — *Os parâmetros de autorização estão ausentes ou incorretos. Volte ao aplicativo e tente conectar novamente.*

| Opção | O que o app recebe |
| --- | --- |
| **Toda a conta** | *Acesso a todos os números e operações da conta, incluindo cobrança. Chaves de API só enquanto você for proprietário(a) do workspace.* Só **Proprietário** ou **Administrador** pode escolher. Para **Atendente** ou **Analista** a opção aparece desabilitada, com *Só o proprietário ou um administrador do workspace pode conceder acesso à conta inteira. Escolha números específicos.*, e o servidor também recusa. |
| **Apenas números específicos** | *Acesso somente aos números selecionados. Operações da conta ficam bloqueadas.* Marque os números na lista (**… selecionado(s)**); é preciso marcar pelo menos um (**Selecione ao menos um número.**). Você só pode marcar números que você mesmo alcança, e o número de teste compartilhado não aparece na lista. |

**Apenas números específicos** vem selecionado. Quando o workspace não tem números, Proprietário ou Administrador começa em **Toda a conta**; Atendente ou Analista vê **Nenhum número disponível nesta conta.** *Peça ao proprietário ou a um administrador para conectar um número ou autorizar este aplicativo.* e não consegue autorizar.

### Segredos e chaves de API

Abaixo das opções, a tela diz o que o app vai alcançar além de mensagens e números. Depende do seu papel:

| Seu papel | O que a tela mostra |
| --- | --- |
| **Proprietário** | Aviso **Este aplicativo poderá ver segredos e criar chaves de API** — *Como você é proprietário(a) deste workspace, o aplicativo poderá revelar e criar chaves de API (ps_…), ver e rotacionar segredos de webhook e ver o token de verificação da Meta em seu nome. Chaves e segredos obtidos continuam válidos mesmo se você revogar este acesso depois — regenere-os para cortá-los. Cada criação ou revelação fica registrada na auditoria.* |
| **Administrador** | Aviso **Este aplicativo poderá ver segredos** — *Como você é administrador(a) deste workspace, o aplicativo poderá ver e rotacionar segredos de webhook e ver o token de verificação da Meta em seu nome. Chaves de API só ficam disponíveis ao proprietário do workspace. Segredos obtidos continuam válidos mesmo se você revogar este acesso depois — rotacione-os para cortá-los. Cada criação ou revelação fica registrada na auditoria.* |
| **Atendente**, **Analista** | Nota *Segredos ficam disponíveis a este aplicativo só para administradores e proprietários do workspace; chaves de API, só para o proprietário.* |

O acesso a chaves de API é conferido a cada chamada, não só no consentimento: se o Proprietário deixar de ser o dono depois, o app perde esse acesso.

**Autorizar** conclui a conexão e devolve você ao app; **Cancelar** devolve ao app um `access_denied`. O token nunca dá mais do que o seu próprio papel permite: o conector de um Analista não lê conversas nem envia mensagens, por exemplo, e uma permissão pedida que o seu papel não tem é descartada.

A tela termina com *Você pode revogar este acesso a qualquer momento nas configurações.*, mas o dashboard ainda não tem uma lista de apps conectados. Para cortar o acesso de um app, remova o conector no próprio app (o token dele também pode ser revogado pelo endpoint de revogação do OAuth) e regenere qualquer chave ou segredo que ele tenha obtido. Detalhes: [Servidor MCP](/pt-BR/integrations/mcp-server).

## O cabeçalho

- **Seletor de workspace** — só aparece quando você faz parte de **mais de um** workspace. Cada item mostra o nome do workspace, o seu papel e o e-mail do dono. Escolher um recarrega o dashboard naquele workspace. Se você perder o acesso ao workspace ativo, o dashboard avisa **Você não tem mais acesso àquele workspace. Voltamos para o seu workspace principal.** Para criar outro workspace, use **Criar outro workspace** em [Perfil → Membros](/pt-BR/dashboard/members), ou uma chave pessoal da conta (`ps_account_…`) com [`POST /v1/workspaces`](/pt-BR/api/workspaces) / a tool MCP `workspaces_create`.
- **Número ativo** — o menu **Número ativo:** escolhe qual número as telas por número mostram. O número de teste compartilhado leva a etiqueta **Teste**.
- **Buscar...** (`Ctrl+K` / `⌘K`) — abre a paleta de comandos.
- **Tema** (`M`), **Feedback** (`F`), **Sair** (`Q`) e o seletor de idioma. **Sair** pergunta **Tem certeza que deseja sair da sua conta?** — **Você será desconectado.**

A barra lateral mostra um atalho de uma letra ao lado de cada item (por exemplo `p` para Planos, `u` para Perfil).

## Paleta de comandos (`Ctrl+K`)

**Buscar ou perguntar à I.A...** — digite para filtrar, `↑`/`↓` e `Enter` para abrir, `1`–`9`/`0` para escolher um resultado, `Esc` para fechar. Grupos:

- **Páginas** — Painel, Analytics, Anúncios, Templates, Logs, API Keys (duas vezes: as chaves dos números e as do workspace), Números, Labels, Webhooks, Planos, Documentação e Perfil, filtradas pelo que o seu papel pode abrir. Linhas, Chat, Mensagens, Flows e Chatwoot ficam na barra lateral.
- **Ações Rápidas** — **Criar Template** (`Ctrl+Shift+1`), **Regenerar API Key** (`Ctrl+Shift+3`), **Criar Webhook** (`Ctrl+Shift+4`), **Conectar Número** (`Ctrl+Shift+5`) e a troca de modo claro/escuro. Cada uma só aparece para os papéis que podem fazê-la.
- **Números**, **Templates**, **Chaves de API**, **Webhooks** — os seus próprios itens, para ir direto a eles.

**Perguntar à I.A.** manda o que você digitou para a I.A. e mostra a resposta dentro da paleta, com **Copiar resposta da I.A.**. Essa resposta é só conhecimento: ela não age na sua conta.

## Chat do agente de I.A.

O botão redondo **Perguntar à I.A.** no canto inferior direito (em todas as telas, menos com uma conversa do chat aberta) abre o chat lateral. Logado, ele é o **agente do Pilot Status** — **Agente — age na sua conta**: responde sobre a API e o produto e pode listar seus números, ler métricas, enviar mensagens e mais, com as mesmas tools do [servidor MCP](/pt-BR/integrations/mcp-server), limitado pelo seu papel. Tools só do Proprietário (como a verificação do titular das linhas) nunca são oferecidas.

Tudo o que altera algo (enviar, criar, apagar) para antes com **A I.A. vai executar isto na sua conta. Nada roda antes da sua confirmação.**, listando cada ação e os argumentos dela, com **Confirmar e executar** e **Cancelar**. **Limpar** começa uma conversa nova. Ao lado, o botão do WhatsApp (**Suporte WhatsApp**) abre uma conversa com o time de suporte.

## Feedback

**Feedback** (cabeçalho, ou `F`) abre **Feedback** — **Ideias para melhorar esta página...** e **Enviar**. A mensagem é registrada com a tela em que você estava, e a confirmação é **Feedback enviado com sucesso.** Para ajuda em vez de sugestão, o mesmo modal aponta para a documentação (**Precisa de ajuda? ver docs**).

## Avisos no topo

| Aviso | Quem vê | Ação |
| --- | --- | --- |
| **Nova versão disponível** — **Recarregue a página para usar a versão mais recente do Pilot Status.** | Todos, depois de um deploy. | **Recarregar** |
| **Sua renovação vence em … dias** | Quando o plano renova em até 2 dias (não no Free, não se já estiver suspenso). Cobrança pela carteira mostra o saldo atual; cobrança no cartão avisa que o cartão será cobrado. | **Ir para Planos** |
| **Receba os avisos de cobrança no WhatsApp** (Proprietário) / **Verifique seu número de WhatsApp** (demais) | Quem ainda não verificou o próprio WhatsApp. Não dá para dispensar. | **Verificar WhatsApp** — envia um código para o seu número |
| **Pagamento pendente na Meta: templates bloqueados** | Proprietário e Administrador, quando a Meta bloqueou uma conta do WhatsApp Business sua por problema de pagamento. O envio pela Pilot Status **não** é pausado. | **Abrir na Meta**, **Ver números**, **Ocultar aviso** (pela sessão do navegador) |
| **Nenhum número conectado** — **Conecte um número do WhatsApp para começar a enviar mensagens.** | Telas por número, quando o workspace não tem número. Essas telas mostram **Conecte um número para continuar**. | **Adicionar Número** (só para papéis que podem conectar números) |

Nenhum desses avisos aparece no chat em tela cheia.

## Pela API / MCP

| Ação | API / MCP |
| --- | --- |
| Login, onboarding, link único dos avisos | Só no dashboard. A API autentica por chave, não por sessão — veja [Autenticação](/pt-BR/api/authentication). |
| Aceitar ou recusar um convite | Só no dashboard. Enviar, reenviar e revogar convites: `POST /v1/workspace/members`, `workspace_members_invite`, `workspace_members_resend`, `workspace_members_remove` — veja [Workspace](/pt-BR/api/workspace). |
| Autorizar um app (consentimento OAuth) | Etapa interativa no navegador por desenho; não dá para automatizar. |
| Listar ou criar workspaces | `GET`/`POST /v1/workspaces` com chave da conta; MCP `workspaces_list`, `workspaces_create`. Veja [Workspaces](/pt-BR/api/workspaces). |
| Perguntar à documentação | MCP `docs_search`. |
| Paleta, feedback, avisos | Só no dashboard. |
