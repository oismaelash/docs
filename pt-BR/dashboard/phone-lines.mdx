As linhas telefônicas ficam em **Linhas telefônicas**, na barra lateral, logo abaixo de **Números** (atalho de teclado: `i`), com o selo **beta**. O item aparece para **Proprietário e Administrador**; Atendente e Analista não veem as linhas, porque a página de uma linha mostra o código de ativação do WhatsApp, e esse código é uma credencial. Para os mesmos papéis, a página **Números** também tem um card **Linhas telefônicas**, com **Ir para Linhas**.

O passo a passo completo, da verificação do titular até digitar o código no WhatsApp, está no guia [Linhas telefônicas: comprar e usar no WhatsApp](/pt-BR/guides/phone-lines).

## Quem pode fazer o quê

| Ação | Proprietário | Administrador | Atendente / Analista |
| --- | --- | --- | --- |
| Ver as linhas, abrir uma linha, ler o código de ativação e o histórico, ouvir os áudios | Sim | Sim | Não |
| **Esperar novo código**, **Cancelar espera**, **Editar nome** | Sim | Sim | Não |
| Verificação do titular e **Comprar linha** | Sim | Não — a lista vazia diz **Só o dono do workspace pode comprar linhas.** | Não |
| **Adicionar saldo**, **Pagar … agora**, **Pagar tudo**, **Escolher quais manter** | Sim | Não — vê **Só o dono do workspace pode pagar ou escolher quais linhas manter.** | Não |
| **Cancelar linha**, **Devolver número**, **Desistir do cancelamento** | Sim | Não | Não |
| **Webhooks das linhas** (criar, editar, pausar, excluir, ver entregas) | Sim | Sim | Não |

As permissões por trás disso: `phone_lines:read` e `phone_lines:webhooks` (Administrador para cima), `phone_lines:purchase`, `phone_lines:cancel` e `billing:wallet:topup` (só Proprietário).

## Lista de linhas

A página **Linhas** (`/linhas`) lista as linhas que ainda são suas — ativas, com pagamento pendente ou suspensas. Uma linha devolvida ou cancelada sai da lista. Sem nenhuma linha, a página mostra **Nenhuma linha ainda** e, para o Proprietário, o botão **Comprar linha · …/mês** com **Cobrança mensal · cancele quando quiser**; os outros papéis veem **Só o dono do workspace pode comprar linhas.** Se a lista não carregar, a página diz **Não foi possível carregar. Tente de novo.**, com **Tentar de novo**.

No topo ficam **Webhooks das linhas** e, quando já há linhas, **Comprar linha**, e um resumo como **3 linhas · 1 precisa de atenção**. A lista começa pelo que pede ação: primeiro as suspensas, depois as com pagamento pendente, depois as com cancelamento agendado, e o resto pela data de renovação. Cada linha tem um botão que copia o número com o código do país (`+55…`).

Cada linha mostra o nome (ou o número, se ela não tiver nome), o DDD e uma destas situações:

| Situação | O que a linha mostra |
| --- | --- |
| **Ativa** | A data da próxima renovação e quantos códigos a linha já pediu. |
| **Pagamento pendente** | A data em que a renovação falhou. A linha continua recebendo códigos. |
| **Suspensa** | A data da suspensão. A linha não recebe códigos novos. |
| **Cancelamento agendado** | Até quando a linha fica ativa. |

Na página da linha aparecem também **Devolvida** e **Cancelada**, as duas situações finais.

### Avisos no topo da lista

- **Linhas sem pagamento** — um aviso vermelho (**Uma linha precisa de pagamento**, ou **… linhas estão suspensas ou sem pagamento**) diz até quando regularizar. Para o Proprietário, traz **Adicionar saldo**, **Pagar tudo** e, quando há mais de uma linha em atraso, **Escolher quais manter**; um Administrador vê o aviso com **Só o dono do workspace pode pagar ou escolher quais linhas manter.** Veja [Preço e cobrança das linhas](/pt-BR/phone-lines-pricing#linhas-em-atraso).
- **Sua verificação está em análise** — você já pode usar as linhas normalmente enquanto a Pilot Status confere o documento. Se a conferência não passar, as linhas compradas durante a análise voltam para a operadora e o valor pago por elas volta como saldo na carteira.
- **Pedimos outro documento para concluir a verificação do titular.** — **Enviar documento** leva de volta à verificação.
- **A verificação do titular foi recusada.** — as linhas compradas durante a análise voltam para a operadora 3 dias após a recusa, e o que você pagou por elas volta como saldo na carteira; até lá, seguem ativas e não renovam. Não é possível comprar novas linhas — **Comprar linha** avisa e indica o suporte (**Falar com o suporte**). Veja o [guia](/pt-BR/guides/phone-lines#passo-a-passo).

Os avisos de verificação aparecem só para o Proprietário.

### Pagar tudo (tentar a cobrança de novo)

**Pagar tudo** cobra de novo, na hora, todas as linhas em atraso: primeiro pelo saldo da carteira, depois pelo cartão salvo, para o que faltar. O resultado aparece numa mensagem — **… linhas pagas. Elas seguem ativas.** ou **… linhas não puderam ser cobradas. Adicione saldo ou confira seu cartão.** Não abre janela. Além disso, a mesma nova tentativa existe por linha, na página dela (**Pagar … agora**).

## Comprar linhas

**Comprar linha** abre **Comprar linhas** (`/linhas/comprar`), em três etapas mostradas no topo: **Verificação**, **Números**, **Confirmar**. Só o Proprietário compra.

### Etapa 1 — Verificação

**Confirme quem é o titular.** Esta etapa só aparece na primeira compra, enquanto o titular não estiver verificado. Linha telefônica é serviço regulado, e o titular é verificado uma vez.

1. **Você está comprando como** — **Empresa · CNPJ** ou **Pessoa física · CPF**.
   - **CNPJ**: consultado na Receita. O CNPJ pode ser alfanumérico (o novo formato da Receita, por exemplo `12.ABC.345/01DE-35`); digite como está no cartão CNPJ. A tela mostra **Consultando a Receita…** e depois **Ativa · consultado na Receita**. Um CNPJ inativo é recusado (**Este CNPJ não está ativo na Receita.**); um desconhecido recebe **CNPJ não encontrado na Receita.** Se a Receita não responder, a compra segue e o documento é conferido à mão.
   - **CPF**: a conferência é feita pelo documento. O resumo diz então **Pessoa física: a conferência é feita pelo documento.** ou, quando o CPF também foi consultado na Receita, **Pessoa física: conferimos o documento e o CPF na Receita.**
2. **WhatsApp do titular** — com seletor de país (o Brasil já selecionado). Para o Brasil, digite o DDD e o número. Ele recebe um código de 6 dígitos.

   **Continuar** fica desativado até o número do documento e o WhatsApp estarem completos. Um documento ou telefone malformado recebe **O número do documento ou do WhatsApp não é válido.**
3. **Documento** — arraste o arquivo ou clique para escolher: para CNPJ, **Cartão CNPJ, contrato social ou comprovante de inscrição**; para CPF, **RG, CNH ou comprovante de inscrição no CPF**. **PDF, JPG, PNG ou WEBP, até 10 MB.** Qualquer outro tipo é recusado antes do envio (**Envie um arquivo PDF, JPG, PNG ou WEBP.**), assim como um arquivo maior (**O arquivo tem mais de 10 MB.**). O painel lê o número no documento (**Lendo o documento… Não feche esta página.**). Se não encontrar nenhum número, ou não conseguir lê-lo com segurança, ele avisa e mostra de novo a área de envio para você mandar um arquivo mais nítido. Depois de recebido, o documento aparece como **Documento recebido**, com **Trocar**.
4. **Contatos** — um código de 6 dígitos vai para o **WhatsApp** do titular, enviado pelo WhatsApp da Pilot Status (**Mandamos um código de 6 dígitos para …, pelo WhatsApp da Pilot Status.**). Um código vai também para o **e-mail da sua conta** (o usuário logado) quando esse e-mail ainda não foi verificado; um e-mail já verificado só mostra **Confirmado**. Digite cada código e clique em **Confirmar**. **Não recebeu? Reenviar código** manda um novo; depois de cada envio há uma contagem de 60 segundos (**Reenviar em …**). Os códigos valem **10 minutos**; depois de 5 tentativas erradas, é preciso um código novo. Se não houver remetente de WhatsApp disponível, o código vai por e-mail e o WhatsApp fica registrado sem confirmação (**O código foi por e-mail porque ainda não temos um remetente de WhatsApp. Seu WhatsApp fica registrado, sem confirmação.**).

   As mensagens do código: **Código incorreto. Confira os 6 dígitos.**, **Este código expirou — ele vale 10 minutos. Peça um novo.** (o reenvio é oferecido na hora), **Tentativas erradas demais. Peça um novo código.** e **Aguarde um pouco antes de pedir outro código.**

<Note>
  O código de contato só confirma quem você é. Ele **não** é o código de ativação do WhatsApp, que chega por ligação na própria linha.
</Note>

Com os contatos confirmados, a verificação é aprovada ou fica em **Verificação em análise — você já pode comprar**: você compra e usa as linhas enquanto o documento é conferido à mão. Uma verificação recusada mostra **A verificação do titular foi recusada** — **Não é possível comprar novas linhas com esta verificação. Fale com o suporte para entender o motivo.** —, com **Falar com o suporte**, e bloqueia novas compras. Enquanto os códigos de contato estão pendentes, **Corrigir dados** reabre o formulário para você trocar o documento ou o WhatsApp.

### Etapa 2 — Números

**Escolha os números.** Escolha o **DDD** (o 11 já vem selecionado; digite um DDD, a sigla ou o nome de um estado para filtrar a lista, que mostra o nome do estado de cada DDD), clique em **Buscar números** e marque até **10** números (**… de 10 escolhidos**). A busca só roda quando você clica no botão. São linhas fixas: recebem a ligação com o código do WhatsApp, não fazem chamadas nem recebem SMS. Se um DDD estiver sem estoque, a tela diz **Nenhum número disponível no DDD … agora. Tente outro DDD.**

Os números escolhidos aparecem como etiquetas que você pode remover. Ao chegar a 10, os outros números ficam desativados e a tela diz **Limite de 10 números por compra. Para mais, faça outra compra depois desta.** Uma barra com **Continuar** fica no topo do quadro enquanto você rola, com o total (**Continuar · …**).

### Etapa 3 — Confirmar

**Confirme a compra.** Mostra o preço por linha (**…/mês**, o mesmo em todo plano e para qualquer quantidade), **Total agora · … linhas** e **Comprar … linhas · …**. Cada linha renova todo mês no dia da compra; o primeiro mês é cobrado inteiro, sem proporcional. O valor sai do saldo da carteira, e o cartão salvo cobre o que faltar. **Voltar** retorna aos números.

Depois de clicar em **Comprar**, a tela mostra **Comprando: … de … concluídos** e o resultado de cada número à medida que ele se resolve (**Comprando…** enquanto roda). Cada número pode levar até 1 minuto e meio, e você pode sair da página: a compra continua e as linhas aparecem na lista. O endereço da página guarda a compra, então recarregar a página, ou voltar a ela, reabre os resultados. Se essa compra não for encontrada, o assistente volta aos números com **Não encontramos essa compra. Escolha os números de novo para continuar.**

No fim: **Pronto! Suas … linhas estão ativas** ou **… de … compras concluídas**, com **Ver linha** para cada linha comprada, **Ir para Linhas** e, quando algo falhou, **Escolher outros números** (mantém selecionados os números que falharam e valem nova tentativa, e tira os que não estão mais disponíveis). Um número que falhou mostra o motivo, por exemplo:

- **Este número não está mais disponível. Escolha outro.**
- **O pagamento não foi concluído. Adicione saldo ou confira seu cartão.**
- **As linhas estão temporariamente indisponíveis. Tente de novo em alguns minutos.**
- **A operadora do cartão não respondeu, então não sabemos se o cartão foi cobrado. Sua carteira não foi debitada; confira a fatura do cartão antes de tentar de novo.**
- **A compra não pôde ser concluída. O valor cobrado voltou para sua carteira como saldo.**
- **A compra deste número foi interrompida. Se houve cobrança, nossa equipe devolve o valor; confira suas linhas e o extrato da carteira.**

Quando um número falha porque não estava mais disponível ou porque as linhas estavam indisponíveis, os resultados acrescentam **Se o valor de um número que falhou chegou a ser cobrado, ele voltou como saldo na carteira.**

### Adicionar saldo para concluir a compra

Se um número falhar por falta de saldo, a janela **Adicionar saldo para concluir a compra** abre sozinha para o Proprietário; **Adicionar saldo e tentar de novo** a reabre. Ela mostra o **Total** dos números recusados, o **Saldo na carteira** e o **Valor a adicionar**: o que falta, elevado à recarga mínima de 1 (R$ 1,00 numa conta em BRL) quando for menor (**A recarga mínima é de …. O que sobrar fica na carteira.**). Se o saldo já cobre os números, ela diz **Seu saldo já cobre a compra. Tente de novo.** Em **Como pagar**:

- **Pix (na hora)** — só para contas em BRL; nas outras contas a opção não aparece e a janela diz **Pix está disponível apenas para contas em BRL.** **Gerar Pix de …** mostra o **QR Code do Pix** e **Copiar código Pix** (o copia e cola). Pague no app do banco. A janela fica conferindo o saldo; **Já paguei** confere na hora. Até a confirmação, ela diz **Ainda não recebemos a confirmação do Pix. Se você já pagou, aguarde alguns instantes.** A janela não mostra até quando o Pix vale.
- **Cartão de crédito** — **Pagar … com cartão**. Com um cartão salvo, escolha **Cartão salvo •••• 1234**, cobrado na hora, ou **Outro cartão**. **Outro cartão** (ou a falta de cartão salvo) leva à página de pagamento e volta para `/linhas/comprar`, onde a compra continua com os mesmos números. Se o cartão salvo pedir uma confirmação, a janela diz para escolher **Outro cartão**.

De volta à confirmação, a página diz **Saldo adicionado. Confirme para concluir a compra.** Depois da página de pagamento, ela pode dizer antes **Pagamento recebido. Aguardando o saldo entrar na carteira…** (o botão de compra mostra **Confirmando pagamento…**); se o saldo ainda não tiver chegado depois de cerca de dois minutos, ela diz **O pagamento ainda não apareceu no saldo. Se você já pagou, aguarde alguns minutos antes de tentar de novo — não pague outra vez.** Um pagamento cancelado naquela página traz você de volta com **O pagamento foi cancelado. Os números continuam selecionados.**

A recarga nunca compra a linha sozinha: você volta à confirmação e clica em **Comprar** de novo.

## Página da linha

Clique numa linha para abrir a página dela (`/linhas/{id}`). Uma linha que não existe neste workspace mostra **Linha não encontrada.**, com **Ir para Linhas**.

### Cabeçalho

- **O nome da linha**, com o **lápis** (**Editar nome**) ao lado. Ele abre **Editar nome da linha**: **Nome** (opcional, até 60 caracteres) e **Salvar**. Em branco, a linha aparece pelo número; com nome, o número aparece logo abaixo. Proprietário e Administrador podem renomear; **Nome atualizado** confirma, e uma falha diz **Falha ao atualizar nome**. Ao lado do nome, um botão copia o número com o código do país (`+55…`).
- **DDD · ativa desde … · renova …** — a data da compra e a da próxima renovação. Uma linha que não é mais sua mostra **Devolvida em …** ou **Cancelada em …** no lugar.
- **A situação** e, para o Proprietário, **Cancelar linha** (linha em dia) ou **Devolver número** (linha em atraso). Veja [Cancelar ou devolver](#cancelar-ou-devolver).

### Pagamento pendente ou suspensa

Uma linha com pagamento pendente mostra **Não conseguimos cobrar … em …**, com as datas exatas em que ela será suspensa e em que o número será devolvido, e os botões **Adicionar saldo** e **Pagar … agora**. Uma linha suspensa mostra **Linha suspensa por falta de pagamento**, com a data em que o número será devolvido, e os botões **Adicionar saldo** e **Pagar … e reativar**. Os dois botões tentam a cobrança na hora (carteira primeiro, depois o cartão salvo) e respondem **Pagamento feito. A linha segue ativa.** ou **Não foi possível cobrar. Adicione saldo ou confira seu cartão.**

<Note>
  **Pagar … agora** e **Pagar … e reativar** cobram **só esta linha**. Se houver outras linhas em atraso, a página avisa (**Outra linha também está sem pagamento** ou **Outras … linhas também estão sem pagamento**), com **Ver e pagar todas**, que leva à lista — lá, **Pagar tudo** cobra todas de uma vez.
</Note>

### Código de ativação

O quadro do código tem o botão **Esperar novo código**, que prepara a linha para receber a ligação do WhatsApp (**Preparando a linha…** enquanto isso). Ele fica desativado enquanto um pedido está aguardando ou sendo lido, e numa linha suspensa (**Linha suspensa não recebe códigos novos. O histórico continua disponível.**); uma linha com pagamento pendente continua recebendo códigos. No WhatsApp, escolha **Me ligue** — número fixo não recebe SMS, e esperar o SMS só gasta a janela de verificação. Antes do primeiro pedido, o quadro diz **Nenhum código ainda. Toque em Esperar novo código e, no WhatsApp, escolha Me ligue.** Depois de clicar, o quadro passa por estes estados:

| O que o painel mostra | O que significa |
| --- | --- |
| **Aguardando** — **Esperando a ligação da Meta** | A linha espera a ligação por 5 minutos (**A linha espera a ligação até …**), com o **Tempo restante**; no zero, mostra **Conferindo uma última vez…**. No WhatsApp, toque em **Me ligue**; a ligação pode levar 1 minuto ou mais, e não precisa cancelar e pedir de novo. **Cancelar espera** encerra o pedido. |
| **Lendo** — **A ligação chegou — lendo o código…** | O áudio está sendo transcrito; costuma levar alguns segundos, mas pode chegar a um ou dois minutos. Dá para ouvir a gravação enquanto isso (**Enquanto isso, você pode ouvir a ligação:**). |
| O código, com **Copiar** | **Último código · …** e a hora em que chegou, com **Recebido**. Digite-o no WhatsApp. O player do áudio fica logo abaixo. |
| **Recebemos a ligação, mas não conseguimos ler o código. Ouça o áudio abaixo.** | Ouça a gravação logo abaixo e anote os dígitos de ouvido. |
| **Nenhuma ligação chegou** | A janela fechou sem ligação. O quadro lista os motivos mais comuns (tocou em **Reenviar SMS** em vez de **Me ligue**, o contador do WhatsApp, uma carência após tentativas seguidas) e oferece **Esperar de novo** e **Falar com o suporte**. |
| **Espera cancelada** | O pedido foi cancelado. Clique em **Esperar novo código** antes de pedir o código de novo no WhatsApp. |
| **Não conseguimos capturar a ligação** | A ligação chegou, mas o áudio não pôde ser guardado. Peça o código de novo no WhatsApp; **Esperar de novo** abre um pedido novo. |

Se outra pessoa (outra aba, um colega) já pediu um código na linha, clicar em **Esperar novo código** acompanha esse pedido em vez de abrir um segundo. Reabrir a página enquanto um pedido está aguardando ou sendo lido retoma esse pedido de onde ele está. Se você clicar em **Cancelar espera** bem na hora em que a ligação chega, o painel diz **A ligação acabou de chegar, ou o pedido já tinha terminado — veja o resultado na tela.**

O código de ativação **não aparece uma vez só**: ele fica no histórico de códigos, abaixo, enquanto a linha for sua.

### Áudio da ligação

Toda ligação capturada tem um player (**Áudio da ligação**). O áudio é a cópia da própria Pilot Status — a operadora o mantém só por 1 hora —, então dá para ouvi-lo de novo sempre que precisar, enquanto a linha for sua.

- Para o código do quadro, o player carrega sozinho. No histórico, clique em **Ouvir** para carregar o áudio daquela ligação.
- Enquanto carrega, o player diz **Carregando áudio…**.
- Se o áudio não carregar (ou levar mais de 30 segundos), ele diz **Não foi possível carregar o áudio.**, com **Tentar de novo**.
- Uma página deixada aberta por muito tempo continua tocando: o player busca o áudio de novo quando precisa.

### Histórico de códigos

Abaixo do quadro fica o **Histórico de códigos**: os 20 pedidos mais recentes, com **Quando**, **Código**, **Áudio** (**Ouvir**) e **Situação** — **Aguardando**, **Lendo o código**, **Recebido** (com o código, ou com "—" quando a ligação não trazia um código de 6 dígitos), **Áudio recebido** (a ligação chegou, mas a leitura falhou), **Não chegou**, **Cancelada** ou **Falhou**. Sem nenhum pedido ainda, ele diz **Nenhum código recebido ainda.** Numa linha suspensa, o histórico fica **somente leitura** (**Histórico de códigos · somente leitura**). Quando o número volta à operadora — devolvido ou cancelado —, os códigos e as gravações da linha são apagados, e a página dela não mostra mais o histórico.

### Cancelar ou devolver

**Cancelar linha** abre **Cancelar …?** e **Devolver número** abre **Devolver …?**. As duas explicam o que acontece e pedem para digitar o número da linha — DDD e número, sem o `+55` (**Digite o número para confirmar: …**); o botão fica desativado até o número bater. **Manter a linha** fecha a janela. As duas também avisam: **Se a conta WhatsApp deste número ainda estiver em uso, migre para outro número antes.**

- **Cancelar …?** — **A linha continua funcionando até …, que já está pago. Não há reembolso do período.** Nesse dia o número volta à operadora, sem garantia de que você consiga comprá-lo de volta, e com ele vão o histórico de códigos e o controle da conta WhatsApp ativada nele; até lá, dá para desistir do cancelamento.
- **Devolver …?** — **Não dá para desfazer. Você perde:** o número (ele volta ao estoque da operadora e pode ser adquirido por outra empresa), os códigos recebidos com os áudios das ligações e o controle da conta WhatsApp ativada nele — quem adquirir o número depois pode pedir um código de verificação e assumir a conta.

- **Cancelar linha** (linha em dia) agenda o cancelamento para o fim do mês já pago, sem reembolso (**Cancelamento agendado para ….**). A lista mostra a linha como **Cancelamento agendado**, e a página dela passa a mostrar **Cancelamento agendado: a linha fica ativa até … e depois o número é devolvido.**, com **Desistir do cancelamento** — que responde **Cancelamento desfeito. A linha renova normalmente.**
- **Devolver número** (linha em atraso) devolve o número à operadora na hora. Você volta para a lista, com o aviso **… foi devolvido**: **O histórico de códigos e os áudios foram apagados. Não há cobrança pendente para esta linha.**

Depois que o número volta à operadora, a página da linha só diz **Esta linha não pertence mais a você. O número voltou à operadora.**

## Escolher quais linhas manter

Com mais de uma linha em atraso, **Escolher quais manter** abre a janela **Escolher quais linhas manter** (um link num aviso de pagamento em atraso também pode abri-la; os links desses avisos só abrem a janela ou apontam para **Pagar tudo**, nunca pagam sozinhos). Ela lista as linhas sem pagamento, cada uma com os códigos, desde quando é sua e quanto custa mantê-la agora, e diz quanto há na carteira e quantas delas o saldo cobre. Marque as que quer manter e clique em **Manter … e devolver …**; o botão fica desativado até haver ao menos uma linha marcada (devolver todas as linhas se faz uma a uma, com **Devolver número**). **Adicionar saldo** leva à carteira.

Quando tudo saiu como pedido, uma mensagem diz quantas linhas foram mantidas e devolvidas e a janela fecha. Quando algo não saiu, a janela fica aberta e lista, por nome e número, **Estas … linhas NÃO foram devolvidas** (a devolução falhou na operadora: elas continuam existindo e seguem pendentes de pagamento — abra a janela de novo em alguns minutos e deixe-as desmarcadas, ou fale com o suporte) e **Estas … linhas mantidas não puderam ser cobradas** (seguem pendentes de pagamento — adicione saldo e tente de novo), com **Fechar**.

- as linhas marcadas são cobradas na hora (carteira primeiro, depois o cartão salvo);
- as **não marcadas são devolvidas na hora**, sem volta, com o histórico de códigos.

O resultado aparece numa mensagem: **… linhas mantidas e … devolvidas.** Se alguma linha marcada não puder ser cobrada, o painel diz **… linhas escolhidas não puderam ser cobradas. Adicione saldo e tente de novo.** As não marcadas são devolvidas de qualquer forma, mesmo quando uma linha marcada não foi cobrada.

## Webhooks das linhas

**Webhooks das linhas** (`/linhas/webhooks`, título **Webhooks das Linhas**), no topo da lista, é o cadastro de webhooks do produto Linhas — separado dos webhooks de números: um webhook de números nunca recebe eventos de linha. Proprietário e Administrador gerenciam.

- **Novo webhook** — um nome opcional (até 100 caracteres: o campo para no limite e mostra a contagem, ex. *14/100*; em branco, vira o host da URL), a URL `https` e os eventos: **Todos os eventos das Linhas** ou os que você escolher (**Linha comprada**, **Áudio da ligação recebido**, **Código recebido**, **Código não obtido**, **Linha renovada**, **Cobrança falhou**, **Linha suspensa**, **Número devolvido**, **Linha cancelada**, **Verificação atualizada**). **Criar webhook** salva. A URL e ao menos um evento são obrigatórios (**Webhook inválido: use uma URL https e escolha ao menos um evento.**); um nome mais longo é recusado ao salvar (**Nome inválido: use no máximo 100 caracteres.**), assim como uma URL que aponte para um endereço interno ou de rede privada (**URL recusada: ela aponta para um endereço interno ou de rede privada, que nunca chamamos. Use o endereço público do seu servidor.**).
- **Editar webhook** (**Salvar alterações**), **Inativar** / **Ativar** e **Deletar** (**Excluir este webhook?**) — um webhook inativo aparece como **Pausado** e não recebe entregas; deletar para as entregas para aquela URL na hora.
- **Entregas** — escolha um webhook para ver as entregas mais recentes (até 50, sem filtros): **Quando**, **Evento**, **Situação** (**Pendente**, **Entregue**, **Falhou**), **Resposta** e **Tentativas**. Clicar numa entrega abre os detalhes, com o corpo enviado, a resposta do endpoint e as tentativas. Não há reenvio nem entrega de teste.
- O resumo do webhook escolhido mostra o nome, a URL, **Ativo** ou **Pausado**, os eventos e **Última entrega … · HTTP …** (ou **Nenhuma entrega ainda**). Sem nenhum webhook, a página diz **Nenhum webhook das Linhas ainda.**
- Um webhook criado em **Chaves do workspace** que assina eventos do workspace (como `wallet.topup_paid`) também aparece aqui, mas aqui só pode ser excluído: **Este webhook assina eventos do workspace (como wallet.topup_paid), que esta tela não edita.**, com um link para **editar em Chaves do workspace**.

<Warning>
  **O segredo de assinatura aparece uma única vez.** Logo depois de **Criar webhook**, a janela **Segredo de assinatura** mostra o segredo (começa com `plwh_`), com **Copiar** e **Guardei**: **Mostrado uma única vez. Guarde-o agora — nenhuma leitura o devolve de novo.** Toda entrega leva o cabeçalho `x-pilot-status-signature` — o HMAC-SHA256 do corpo bruto, em hexadecimal, chaveado com este segredo. O painel, a API e o MCP nunca o mostram de novo, e o suporte da Pilot Status também não consegue lê-lo. Editar o webhook não o troca, e este cadastro não tem rotação: **se você o perdeu, crie um webhook novo (ele vem com um segredo novo), aponte o seu sistema para ele e exclua o antigo.**
</Warning>

Os contadores do topo mostram **Total de Webhooks**, **Ativos** e **Inativos** — ou, com um webhook escolhido, **Total de entregas**, **Entregues** e **Falhas** das entregas listadas.

Os eventos de uma linha trazem o nome dela, e **Áudio da ligação recebido**, **Código recebido** e **Código não obtido** trazem também `audioUrl`, o endereço da gravação da ligação, que o seu sistema baixa com a chave da API. Uma entrega de **Código recebido** traz o próprio código de ativação.

Endpoints, payloads, verificação da assinatura e retentativas: [Webhooks das linhas](/pt-BR/api/phone-lines/webhooks).

## As linhas em Planos

Em **Planos** (barra lateral), três abas mostram o dinheiro das linhas:

- **Financeiro → Cobranças das Linhas** — o saldo da carteira, se ele cobre as renovações dos próximos 7 dias, a próxima renovação de cada linha com quem vai pagá-la (**Carteira paga**, **Cartão salvo paga**, **Carteira + cartão** ou **Saldo insuficiente**) e o **Histórico de cobranças**, com período, situação (**Paga**, **Falhou**, **Pendente**, **Estornada**), tentativas e a próxima tentativa. Uma cobrança **Estornada** diz o motivo — por exemplo, **Verificação do titular recusada; o valor voltou para a carteira.** Na mesma aba, **Gastos consolidados** separa o que foi gasto em **Linhas telefônicas**, e **Recibos e faturas** traz um **Comprovante** de cada cobrança paga.
- **Carteira** — o **Extrato** da carteira tem os botões **Todos**, **WhatsApp** e **Linhas**, para filtrar por produto. As linhas aparecem como **Compra** (primeiro mês) e **Mensalidade** (renovações).
- **Histórico** — a trilha de eventos de cobrança inclui os das linhas: **Linha comprada**, **Mensalidade da linha paga**, **Cobrança da linha falhou**, **Mensalidade da linha estornada**, **Linha suspensa por falta de pagamento**, **Linha reativada**, **Linha devolvida** e **Linha cancelada**, cada um com o nome e o número da linha.

Detalhes em [Preço e cobrança das linhas](/pt-BR/phone-lines-pricing).

## Quem recebe os avisos

Os avisos das linhas vão para os contatos do **titular** informados na verificação e para o **Proprietário** do workspace; os outros membros do workspace não recebem. Eles cobrem a compra, as renovações das próximas 48 horas, a renovação paga, a renovação que falhou, a véspera da suspensão, a suspensão, a reativação, a devolução, o cancelamento agendado que se concretizou, o saldo que não cobre as renovações dos próximos 7 dias e a verificação do titular (pedido de outro documento, aprovação, recusa).

Todos vão por e-mail. Alguns vão também por WhatsApp, e só para um número confirmado: o WhatsApp do titular confirmado na verificação e o telefone do Proprietário quando ele está verificado no perfil. O mesmo endereço nunca recebe o mesmo aviso duas vezes.

## Pela API / MCP

Toda rota `/v1/phone-lines` exige uma chave de API **do workspace** (chave de número é recusada). O servidor MCP cobre a verificação, o áudio da ligação e os webhooks; o resto é só pela API ou só pelo painel.

| Ação no painel | API (`/v1`) | Ferramenta MCP |
| --- | --- | --- |
| Listar linhas, abrir uma linha | [`GET /v1/phone-lines`, `GET /v1/phone-lines/{id}`](/pt-BR/api/phone-lines/list) | Nenhuma — só pela API |
| Verificação do titular (iniciar, confirmar códigos, reenviar código, novo documento) | [`/v1/phone-lines/verification`](/pt-BR/api/phone-lines/verification) | `phone_lines_verification_get`, `phone_lines_verification_start`, `phone_lines_verification_confirm_contact`, `phone_lines_verification_resend_contact`, `phone_lines_verification_resend_document` (só Proprietário) |
| Buscar números | [`GET /v1/phone-lines/available`](/pt-BR/api/phone-lines/available) | Nenhuma — só pela API |
| Comprar linhas | [`POST /v1/phone-lines`](/pt-BR/api/phone-lines/purchase) (`Idempotency-Key` obrigatório) | Nenhuma — só pela API |
| Esperar novo código, ler o código, cancelar a espera, histórico de códigos | [`POST /v1/phone-lines/{id}/activations` e relacionadas](/pt-BR/api/phone-lines/activation-codes) | Nenhuma — só pela API |
