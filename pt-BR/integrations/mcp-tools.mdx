As 148 ferramentas do [servidor MCP hospedado](/pt-BR/integrations/mcp-server), agrupadas pelos mesmos temas que o `describe` do [modo de código](/pt-BR/integrations/mcp-code-mode) usa. Cada linha traz o propósito em uma frase e os argumentos **sem os quais a ferramenta não roda**; todo o resto é opcional. O seu cliente MCP mostra a descrição e o schema completos de cada ferramenta, e no modo de código `describe({ theme })` os devolve em TypeScript.

## Leia antes

- **`whatsappNumberId`.** Toda ferramenta, exceto a `docs_search`, também aceita `whatsappNumberId`, o id do número em que agir (obtido em `numbers_list`). Com uma conexão OAuth ou uma chave do workspace inteiro, ele é **obrigatório nas ferramentas de número** (mensagens, conversas, grupos, templates, webhooks, chamadas, Chatwoot…); é ignorado quando a chave de API já está vinculada a um número. Ele não aparece nas tabelas abaixo.
- **Quem pode chamar.** "ADMIN ou OWNER", "Só OWNER" e "Só OAuth" são os papéis no workspace e os tipos de credencial que a API exige; os demais recebem `403`. Numa conexão OAuth o papel é lido de novo a cada chamada.
- **Token de confirmação.** `templates_delete`, `workspace_archive`, `workspace_transfer_ownership` e `workspace_members_remove` rodam em duas chamadas: a primeira devolve uma prévia e um `confirm_token`; a segunda (mesmos argumentos mais o `confirm_token`) executa. [Como funciona](/pt-BR/integrations/mcp-server#confirmação-para-ferramentas-destrutivas)
- **`confirm: true`.** `flows_publish`, `flows_endpoint_key_rotate` (quando já há uma chave registrada) e `subscription_extra_numbers_add` (no plano FREE) se recusam a rodar sem o booleano `confirm: true`. Só envie depois que o usuário disser sim.
- **Concessão por número.** Uma conexão OAuth que concedeu só alguns números não usa ferramentas da conta, como `billing_checkout`, `api_keys_*` e `numbers_create`.
