Este endpoint retorna os mesmos agregados exibidos na tela de Analytics do painel (KPIs, série diária, distribuição por status, templates mais usados e origens) para **um número de WhatsApp**.

## Endpoint

`GET https://pilotstatus.com.br/v1/analytics/dashboard`

<Note>
  Atua sobre **um número**: use uma **chave de número** (`ps_number_`), ou uma **chave de workspace** (`ps_workspace_`), uma **chave de conta** (`ps_account_`, com `x-workspace-id`) ou um token OAuth que indique o número no header [`x-whatsapp-number-id`](/pt-BR/api/authentication). Uma credencial do workspace inteiro sem esse header recebe `403 TENANT_SCOPE_NOT_ALLOWED`.

  Todos os papéis do workspace (OWNER, ADMIN, AGENT, ANALYST) têm a permissão `analytics:read`, então tokens OAuth e chaves de conta não são recusados por papel — mas o usuário por trás deles precisa ser membro ativo do workspace.
</Note>

## Parâmetros de query

<ParamField query="period" default="30d" type="string">
  Janela do relatório: `7d`, `30d` ou `90d`. Qualquer outro valor é **tratado como `30d` em silêncio** (sem erro). A janela começa no horário atual de N−1 dias atrás.
</ParamField>

<ParamField query="timezone" default="UTC" type="string">
  Fuso horário IANA usado para agrupar a série diária, por exemplo `America/Sao_Paulo`. `tz` é aceito como alias; se os dois forem enviados, vale `timezone`. O valor volta na resposta.
</ParamField>

## Campos da resposta

Todos os totais contam as mensagens **enviadas** pelo número criadas na janela (pela API, pelo chat do painel, por templates etc.); `totalReceived` é o único número de mensagens recebidas. Taxas e percentuais são números de 0 a 100, arredondados com 2 casas, e `0` quando o denominador é 0.

| Campo | Significado |
| --- | --- |
| `period` | A janela efetivamente usada (`7d`, `30d` ou `90d`). |
| `timezone` | O fuso horário pedido (padrão `UTC`). |
| `totalSent` | Toda mensagem despachada na janela: `totalDelivered + totalFailed + totalQueued`. |
| `totalDelivered` | Mensagens com status `SENT`, `DELIVERED` ou `READ`. |
| `totalRead` | Mensagens com status `READ`. |
| `totalFailed` | Mensagens com status `FAILED`. |
| `totalQueued` | Mensagens ainda `QUEUED`. |
| `deliveryRate` | `totalDelivered / totalSent`. |
| `readRate` | `totalRead / totalDelivered`. |
| `failureRate` | `totalFailed / totalSent`. |
| `responseRate` | Mesmo valor de `readRate`. |
| `avgDeliveryTime` | Média em segundos da criação até `deliveredAt` (o aparelho do destinatário confirmou a mensagem), só sobre as mensagens **entregues** do período; `0` quando nenhuma foi entregue. Até 09/11/2026 media da criação até `sentAt` (o provedor aceitar a mensagem), ou seja, o tempo de despacho, não o de entrega. |
| `avgReadTime` | Média em segundos de `sentAt` até `readAt`, entre as mensagens lidas. |
| `messagesOverTime` | Uma entrada por dia do calendário da janela em `timezone` (7, 30 ou 90 entradas, da mais antiga para a mais recente, dias sem tráfego com zeros): `date` (`YYYY-MM-DD`), `total`, `queued`, `sent` (tudo o que foi despachado no dia), `delivered` (`SENT`/`DELIVERED`/`READ`), `read`, `failed`. |
| `statusDistribution` | Contagens: `queued`, `delivered` (inclui as lidas), `read`, `failed`. |
| `statusPercentages` | Os mesmos quatro como percentual de `totalSent`. `delivered` inclui `read`, então a soma não dá 100. |
| `totalReceived` | Mensagens recebidas pelo número na janela. |
| `topTemplates` | Até 5 templates por envios entregues: `templateVersionId` (o id do template, ou o nome dele em envios antigos), `templateId` (ou `null`), `templateName`, `version` (sempre `null`), `count`. |
| `topOrigins` | Envios entregues agrupados por origem, do maior para o menor: `API`, `CHAT`, `DASHBOARD`, `CHATWOOT`, `SYSTEM` ou `APP` (enviada pelo celular, sem requisição da Pilot Status). |

O resultado fica em cache por até 60 segundos por número, período e fuso, então uma mensagem enviada há instantes pode levar até um minuto para aparecer.

## Erros

| Status | Código | Causa |
| --- | --- | --- |
| `400` | `WORKSPACE_ID_REQUIRED` | Chave de conta (`ps_account_`) sem o header `x-workspace-id`. |
| `401` | — | Credencial ausente ou inválida. |
| `403` | `TENANT_SCOPE_NOT_ALLOWED` | Credencial do workspace inteiro usada sem `x-whatsapp-number-id`. |
| `403` | `NUMBER_NOT_IN_GRANT` | Token OAuth ou chave de conta restrito a outros números. |
| `403` | `WORKSPACE_MEMBERSHIP_REQUIRED` | O usuário por trás do token ou da chave de conta não é membro ativo do workspace. |
| `404` | `NUMBER_NOT_FOUND` | `x-whatsapp-number-id` não indica um número deste workspace. |
| `409` | — | A credencial não está vinculada a um número de WhatsApp (`{"error": "API key is not linked to a WhatsApp number"}`). |
