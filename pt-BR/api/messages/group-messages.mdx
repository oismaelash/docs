Recupere mensagens de conversas de **GRUPO** para o número conectado.

## Endpoint

`GET https://pilotstatus.com.br/v1/messages/group`

<Note>
  Atua sobre **um número**: use uma API key **com escopo de número** (`ps_*`) no cabeçalho `x-api-key`, ou uma chave da conta que indique o número no header [`x-whatsapp-number-id`](/pt-BR/api/authentication). Uma chave da conta sem esse header recebe `403 TENANT_SCOPE_NOT_ALLOWED`.

  **Tokens OAuth / MCP e chaves de conta** (`ps_account_`) também precisam da permissão `chat:read` (papéis `AGENT`, `ADMIN`, `OWNER`); o papel `ANALYST` é recusado com `403 PERMISSION_DENIED`. Uma chave `ps_` clássica não é afetada por papéis.
</Note>

<Note>
  O endpoint lê as mensagens de grupo **armazenadas** para o número — ele nunca chama o provedor, então não falha para um número sem grupos: a lista simplesmente vem vazia. Num número oficial (Meta) só há mensagens de grupo se o número participa de grupos pela API de Grupos da Meta.
</Note>

## Parâmetros de query

<ParamField query="startDate" type="string">
  Data/hora ISO 8601. Filtra mensagens criadas **na data ou depois** desta data.
</ParamField>

<ParamField query="endDate" type="string">
  Data/hora ISO 8601. Filtra mensagens criadas **na data ou antes** desta data.
</ParamField>

<ParamField query="page" default="1" type="integer">
  Número da página (≥ 1).
</ParamField>

<ParamField query="pageSize" default="30" type="integer">
  Resultados por página (1–100).
</ParamField>

Tanto `startDate` quanto `endDate` são opcionais individualmente. Quando fornecidos, cada um deve ser uma string ISO 8601 válida e `startDate` não pode ser posterior a `endDate`; caso contrário, `400 INVALID_DATE_RANGE` é retornado.

Os resultados são ordenados por `createdAt` de forma decrescente (mais recentes primeiro).

## Efeito do modo PII

A resposta depende do **modo PII** configurado para o número — alterado no painel, na página API Keys (painel Privacidade & retenção) ou nas configurações do número em Números.

Os limites inferior e superior da consulta vêm **apenas** dos `startDate` / `endDate` informados pelo chamador — o modo PII nunca restringe o intervalo de datas consultado. Em vez disso, as linhas que ficam fora da janela de retenção de PII do número ainda são retornadas, mas **redigidas**: seus campos `text`, `media` e de participante são definidos como `null` e a linha carrega `redacted: true`.

| Modo PII | Efeito |
| --- | --- |
| `STORE_INDEFINITE` (padrão) | Todas as mensagens de grupo são retornadas por completo (sujeito a `startDate` / `endDate`). |
| `STORE_X_DAYS` | Todas as linhas correspondentes são retornadas. Linhas mais antigas que a janela de retenção são redigidas (campos `text`, `media` e de participante como `null`, `redacted: true`); linhas dentro da janela são retornadas por completo. |
| `RELAY_ONLY` | Todas as linhas correspondentes são retornadas, mas **todas** as linhas são redigidas (campos `text`, `media` e de participante como `null`, `redacted: true`), e a resposta inclui um campo `notice: "PII_RELAY_ONLY"`. |

## Campos do objeto de mensagem

<ResponseField name="id" type="string" required>
  ID interno da mensagem no Pilot Status.
</ResponseField>

<ResponseField name="conversationId" type="string" required>
  ID da conversa pai (direta ou em grupo).
</ResponseField>

<ResponseField name="direction" type="string" required>
  `"INBOUND"` (recebida) ou `"OUTBOUND"` (enviada).
</ResponseField>

<ResponseField name="providerKind" type="string" required>
  Motor do número que processou a mensagem: `META` em números oficiais; `EVO_GO` ou `EVO_V2` em números não oficiais (Pilot Status web). Diferente de `media.provider`, este campo traz a tag interna do motor.
</ResponseField>

<ResponseField name="externalMessageId" type="string | null">
  ID da mensagem no provedor (ex.: `wamid` da Meta) quando disponível.
</ResponseField>

<ResponseField name="status" type="string" required>
  Status da mensagem (`QUEUED`, `SENT`, `DELIVERED`, `READ`, `PLAYED`, `FAILED`, `CANCELED`). Mensagens recebidas costumam vir `DELIVERED` ou `READ`.
</ResponseField>

<ResponseField name="messageType" type="string" required>
  `text`, `image`, `audio`, `video`, `document`, `sticker`, `location`, `contacts`, `interactive`, `reaction`, `button`, `template` ou `unknown`.
</ResponseField>

<ResponseField name="origin" type="string | null">
  De onde veio uma mensagem enviada, quando registrado: `APP` — enviada pelo app WhatsApp Business no celular ou por outra ferramenta na mesma WABA; `CHATWOOT` — resposta de atendente vinda de uma inbox nativa WhatsApp Cloud do Chatwoot, enviada pela [camada Meta](/pt-BR/api/layer/meta); `LAYER` — enviada pela camada Meta por qualquer outro cliente. Uma mensagem que a própria Pilot Status enviou pode vir com `API` ou `null`. `null` em mensagens recebidas: leia `direction` para distinguir enviada de recebida. O conjunto cresce, então trate um valor que você não reconhece como mensagem enviada.
</ResponseField>

<ResponseField name="text" type="string | null">
  Texto ou legenda da mensagem quando disponível.
</ResponseField>

<ResponseField name="participantName" type="string | null">
  Nome de exibição do WhatsApp da contraparte/remetente quando disponível.
</ResponseField>

<ResponseField name="participantPhone" type="string | null">
  Telefone da contraparte/remetente quando disponível (num grupo, o membro que escreveu).
</ResponseField>

<ResponseField name="participantUserId" type="string | null">
  Business-Scoped User ID (BSUID) da Meta da contraparte/remetente, quando a Meta enviou um.
</ResponseField>

<ResponseField name="repliedToExternalId" type="string | null">
  `externalMessageId` da mensagem à qual esta responde, quando disponível.
</ResponseField>

<ResponseField name="media" type="object | null">
  Descritor de mídia `{ provider, id, url, mimeType, fileName }` quando a mensagem carrega mídia; `null` caso contrário.

  - `media.provider` — `"META"` em números da Meta Cloud API, `"WEB"` em números não oficiais (Pilot Status web).
  - `media.id` — ID de mídia da **Meta**. Definido em mídia recebida `META` — passe-o para [`GET /v1/media/{mediaId}`](/pt-BR/api/media-download) para baixar os bytes; `null` em `WEB`.
  - `media.url` — URL de download direto quando disponível. Mídia recebida da **META** é espelhada no armazenamento do Pilot Status (portanto mensagens META geralmente carregam tanto `id` **quanto** `url`); números web fornecem o próprio link. Melhor esforço — pode ser `null`.
  - `media.mimeType` — Tipo MIME da mídia quando conhecido (pode ser `null`).
  - `media.fileName` — Nome do arquivo de mídia quando conhecido (pode ser `null`).
</ResponseField>

<ResponseField name="sentAt" type="string | null">
  ISO 8601 — quando a mensagem foi enviada.
</ResponseField>

<ResponseField name="deliveredAt" type="string | null">
  ISO 8601 — quando a mensagem foi entregue.
</ResponseField>

<ResponseField name="readAt" type="string | null">
  ISO 8601 — quando a mensagem foi lida (apenas quando as confirmações de leitura estão habilitadas).
</ResponseField>

<ResponseField name="providerTimestamp" type="string" required>
  ISO 8601 — timestamp do provedor para a mensagem.
</ResponseField>

<ResponseField name="createdAt" type="string" required>
  ISO 8601 — quando o registro foi criado no Pilot Status.
</ResponseField>

<ResponseField name="referral" type="object | null">
  Origem de anúncio Click-to-WhatsApp da mensagem, quando ela veio de um anúncio (números oficiais) — o mesmo objeto descrito em [`GET /v1/referrals`](/pt-BR/api/referrals). `null` caso contrário.
</ResponseField>

<ResponseField name="redacted" type="boolean">
  Presente (`true`) só quando a linha fica fora da janela de retenção de PII do número (ou o número está em `RELAY_ONLY`). Linhas redigidas mantêm `id`, timestamps e metadados de entrega, mas `text`, `media`, `participantName`, `participantPhone` e `participantUserId` são `null`.
</ResponseField>

## Erros comuns

- `400 INVALID_DATE_RANGE` — `startDate` ou `endDate` não é uma string ISO 8601 válida, ou `startDate > endDate`.
- `400 INVALID_PAGINATION` — `page × pageSize` acima de `10000`; restrinja as datas em vez de paginar mais.
- `400 NUMBER_NOT_FOUND` — a credencial não indica nenhum número de WhatsApp.
- `401` — credencial ausente ou inválida (`{"error": "Invalid API key"}`).
- `403 TENANT_SCOPE_NOT_ALLOWED` — chave da conta sem `x-whatsapp-number-id`.
- `403 PERMISSION_DENIED` — token OAuth/MCP ou chave de conta cujo papel não tem `chat:read` (`ANALYST`).
