# Bloquear contato

`POST` bloqueia o contato, `DELETE` desbloqueia. Nenhum dos dois recebe corpo.

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wn_abc/contacts/%2B5511999990000/block" \
  -H "x-api-key: ps_seu_token"
```

```json
{
  "success": true,
  "numberId": "wn_abc",
  "provider": "qrcode",
  "phone": "+5511999990000",
  "jid": "5511999990000@s.whatsapp.net",
  "blocked": true,
  "occurredAt": "2026-11-24T10:00:00.000Z"
}
```

## Quais números

| Número | Bloquear / desbloquear |
| --- | --- |
| Número QR code | Sim |
| Número oficial (Meta) | Sim — só quem enviou mensagem ao número nas últimas 24 horas (senão `422 CONTACT_NOT_ELIGIBLE`) |
| Outros tipos de conexão | `422 FEATURE_NOT_SUPPORTED` |

## Webhook

Em caso de sucesso, seus webhooks recebem `contact.blocked` (ou `contact.unblocked`) com `data.source: "api"`. Num número QR code a mesma mudança também volta do celular; ela é entregue **uma vez só**.

## Permissão e limites

- Exige `contacts:manage` (Agente ou acima). Uma chave de número só atua no próprio número.
- 30 chamadas de bloqueio/arquivamento por minuto por número → `429 RATE_LIMITED`.

## Erros

Todo erro é `{ "error": "<English> | <Português>", "code": "..." }`.

| Status | Código | Significado |
| --- | --- | --- |
| 400 | `INVALID_PHONE` | `{phone}` não é um número E.164. |
| 400 | `CANNOT_BLOCK_SELF` | Um número não pode bloquear a si mesmo. |
| 401 | — | API key ausente ou inválida. |
| 403 | `PERMISSION_DENIED` | Seu papel não tem `contacts:manage`. |
| 404 | `NUMBER_NOT_FOUND` | Número não encontrado para esta credencial. |
| 409 | `WHATSAPP_INSTANCE_NOT_CONNECTED` | O número não está conectado. |
| 409 | `BLOCKLIST_FULL` | A lista de bloqueio está cheia (64.000 usuários). |
| 422 | `CONTACT_NOT_ELIGIBLE` | Número oficial: o usuário não enviou mensagem nas últimas 24 horas. |
| 422 | `FEATURE_NOT_SUPPORTED` | Não suportado para este tipo de conexão. |
| 429 | `RATE_LIMITED` | Chamadas demais, ou limite do próprio WhatsApp. |
| 502 | `PROVIDER_REJECTED` / `WHATSAPP_UPSTREAM_ERROR` | O WhatsApp recusou ou falhou; `details` traz a resposta dele. |
