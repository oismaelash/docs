# Arquivar conversa

`POST` arquiva a conversa, `DELETE` desarquiva. Nenhum dos dois recebe corpo. `{jid}` é um telefone E.164 ou um jid codificado na URL (`@s.whatsapp.net`, `@g.us`, `@lid`).

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wn_abc/chats/120363000000000000%40g.us/archive" \
  -H "x-api-key: ps_seu_token"
```

```json
{
  "success": true,
  "numberId": "wn_abc",
  "provider": "qrcode",
  "jid": "120363000000000000@g.us",
  "phone": null,
  "isGroup": true,
  "archived": true,
  "occurredAt": "2026-11-24T10:00:00.000Z"
}
```

## Quais números

| Número | Arquivar / desarquivar |
| --- | --- |
| Número QR code | Sim |
| Número oficial (Meta) | `422 NOT_AVAILABLE_FOR_OFFICIAL_NUMBERS` |
| Outros tipos de conexão | `422 FEATURE_NOT_SUPPORTED` |

## Webhook

Em caso de sucesso, seus webhooks recebem `chat.archived` (ou `chat.unarchived`) com `data.source: "api"`. O eco da mesma mudança vindo do celular é entregue uma vez só.

## Permissão e limites

- Exige `contacts:manage` (Agente ou acima).
- 30 chamadas de bloqueio/arquivamento por minuto por número → `429 RATE_LIMITED`.

## Erros

| Status | Código | Significado |
| --- | --- | --- |
| 400 | `INVALID_JID` | `{jid}` não é um telefone nem um jid suportado. |
| 401 | — | API key ausente ou inválida. |
| 403 | `PERMISSION_DENIED` | Seu papel não tem `contacts:manage`. |
| 404 | `NUMBER_NOT_FOUND` | Número não encontrado para esta credencial. |
| 409 | `WHATSAPP_INSTANCE_NOT_CONNECTED` | O número não está conectado. |
| 422 | `NOT_AVAILABLE_FOR_OFFICIAL_NUMBERS` | Números oficiais não arquivam pela API. |
| 422 | `FEATURE_NOT_SUPPORTED` | Não suportado para este tipo de conexão. |
| 429 | `RATE_LIMITED` | Chamadas demais. |
| 502 | `PROVIDER_REJECTED` / `WHATSAPP_UPSTREAM_ERROR` | O WhatsApp recusou ou falhou. |
