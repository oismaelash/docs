# Desconectar instância WhatsApp

`POST /v1/numbers/{id}/logout` desconecta uma instância WhatsApp (logout) sem removê-la do banco de dados. Isso é diferente de `DELETE /v1/numbers/{id}`, que exclui o número (soft delete de 30 dias).

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wa_abc/logout" \
  -H "x-api-key: ps_your_token_here"
```

Resposta:

```json
{
  "ok": true,
  "instances": [
    {
      "instanceId": "inst_123",
      "ok": true
    }
  ]
}
```

## Quando usar

- Quando você quer desconectar uma instância WhatsApp temporariamente sem deletá-la.
- Quando você precisa reconectar um número a um dispositivo diferente.
- Ao solucionar problemas de conexão e precisar redefinir o estado da conexão.

## Diferenças do DELETE

| Operação | O que faz |
| --- | --- |
| `POST /v1/numbers/{id}/logout` | Desconecta o WhatsApp (desvincula o dispositivo) mas mantém a instância no banco de dados. Você pode reconectar depois. |
| `DELETE /v1/numbers/{id}` | Desconecta E exclui o número — soft delete de 30 dias, desfeito com `POST /v1/numbers/{id}/restore`. |
| `DELETE /v1/numbers/{id}/purge` | Exclui o número de forma permanente, na hora. Não pode ser desfeito. |

## Parâmetros da requisição

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string | Sim | O ID da instância WhatsApp ou ID do número WhatsApp. |

## Resposta

### Sucesso (200)

```json
{
  "ok": true,
  "instances": [
    {
      "instanceId": "inst_123",
      "ok": true
    }
  ]
}
```

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `ok` | boolean | Status geral de sucesso. |
| `instances` | array | Array de resultados de logout para cada instância. |
| `instances[].instanceId` | string | O ID da instância. |
| `instances[].ok` | boolean | Se o logout foi bem-sucedido para esta instância. |
| `instances[].error` | string | Mensagem de erro se o logout falhar (só presente quando `ok` é false). |

### Erros

| Status | Corpo | Significado |
| --- | --- | --- |
| `401` | `{ "error": "…" }` | Chave de API inválida ou ausente. |
| `404` | `{ "error": "Number not found" }` | Nenhum número encontrado para esta chave de API. |
| `500` | `{ "error": "Internal server error" }` | Erro do servidor (verifique os logs). |

## Notas

- O `ok` de nível superior é **sempre `true`** quando o número é encontrado — confira cada `instances[].ok`. Quando o provedor recusa o logout de uma conexão (qualquer erro, inclusive "instance not found" ou um `401`), essa entrada volta `ok: false` com a mensagem do provedor em `error`, e o estado guardado dela **não** é alterado.
- Após um logout bem-sucedido, o estado da instância será `LOGOUT` no banco de dados.
- Um número Meta (Cloud API) não tem conexão para desconectar: a chamada responde `{ "ok": true, "instances": [] }`.
- `{id}` pode ser o id do número ou o id da instância. Por OAuth ou com uma chave de conta (`ps_account_`), exige `numbers:connect` (Admin ou Owner) — `403 PERMISSION_DENIED` caso contrário; um token OAuth com acesso a outros números recebe `403 NUMBER_NOT_IN_GRANT`.
- Você pode reconectar a instância depois usando `GET /v1/numbers/{id}/connect`.
