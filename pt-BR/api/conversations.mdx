Liste as conversas do número conectado, ordenadas pela atividade de mensagem mais recente (`lastMessageAt` decrescente; conversas sem ela por último).

## Endpoint

`GET https://pilotstatus.com.br/v1/conversations`

<Note>
  Atua sobre **um número**: use uma API key **com escopo de número** (`ps_*`) no cabeçalho `x-api-key` (ou `x-api-key-id`), ou uma chave da conta que indique o número no header [`x-whatsapp-number-id`](/pt-BR/api/authentication). Uma chave da conta sem esse header recebe `403 TENANT_SCOPE_NOT_ALLOWED`.

  **Tokens OAuth / MCP e chaves de conta** (`ps_account_`) também precisam da permissão `chat:read` (papéis `AGENT`, `ADMIN`, `OWNER`); o papel `ANALYST` é recusado com `403 PERMISSION_DENIED`. Uma chave `ps_` clássica não é afetada por papéis.
</Note>

## Parâmetros de consulta

<ParamField query="startDate" type="string">
  Datetime ISO 8601. Filtra conversas cuja última mensagem seja **igual ou posterior** a esta data.
</ParamField>

<ParamField query="endDate" type="string">
  Datetime ISO 8601. Filtra conversas cuja última mensagem seja **igual ou anterior** a esta data.
</ParamField>

<ParamField query="page" default="1" type="integer">
  Número da página (≥ 1).
</ParamField>

<ParamField query="pageSize" default="30" type="integer">
  Resultados por página (1–100).
</ParamField>

Tanto `startDate` quanto `endDate` são opcionais individualmente. Quando fornecidos, cada um deve ser uma string ISO 8601 válida e `startDate` não pode ser posterior a `endDate`; caso contrário, é retornado `400 INVALID_DATE_RANGE`.

## Efeito do modo PII

A resposta depende do **modo PII** configurado para o número — alterado no painel, na página API Keys (painel Privacidade & retenção) ou nas configurações do número em Números:

| Modo PII | Efeito |
| --- | --- |
| `STORE_INDEFINITE` (padrão) | Todas as conversas retornadas (sujeitas aos filtros de data). |
| `STORE_X_DAYS` | As conversas voltam na íntegra — a retenção é aplicada **por mensagem** nos endpoints de mensagens, não à linha da conversa, então o peer e o `lastMessagePreview` permanecem. |
| `RELAY_ONLY` | As conversas **são** retornadas (não uma lista vazia), mas toda linha é **redigida** (`redacted: true`, identidade do peer e prévia da última mensagem `null`). A resposta inclui um campo `notice: "PII_RELAY_ONLY"`. |

## Campos do objeto de conversa

<ResponseField name="id" type="string" required>
  ID da conversa no Pilot Status.
</ResponseField>

<ResponseField name="whatsappNumberId" type="string" required>
  O número ao qual a conversa pertence.
</ResponseField>

<ResponseField name="type" type="string" required>
  `"DIRECT"`, `"GROUP"` ou `"NEWSLETTER"`.
</ResponseField>

<ResponseField name="from" type="string | null">
  Telefone do contato em E.164 (com `+`) para pessoas; `null` para grupos/canais, para contatos sem telefone (só LID ou só username) e quando redigido.
</ResponseField>

<ResponseField name="fromName" type="string | null">
  Nome de exibição do contato ou do grupo, quando disponível.
</ResponseField>

<ResponseField name="peerLid" type="string | null">
  LID do WhatsApp do contato, quando conhecido.
</ResponseField>

<ResponseField name="userId" type="string | null">
  Business-Scoped User ID (BSUID) da Meta — a chave durável de um contato Meta. Presente mesmo quando `from` é `null` (contato que usa username), e aceito como `destinationNumber` em [`POST /v1/messages/send`](/pt-BR/api/messages/send).
</ResponseField>

<ResponseField name="username" type="string | null">
  O username de WhatsApp do contato, quando conhecido.
</ResponseField>

<ResponseField name="profilePicUrl" type="string | null">
  URL da foto de perfil, quando conhecida.
</ResponseField>

<ResponseField name="lastMessagePreview" type="string | null">
  Prévia curta da última mensagem.
</ResponseField>

<ResponseField name="lastDirection" type="string | null">
  `INBOUND` ou `OUTBOUND` — direção da última mensagem.
</ResponseField>

<ResponseField name="unreadCount" type="integer" required>
  Mensagens recebidas não lidas na conversa — o contador por trás de [`GET /v1/messages/unread`](/pt-BR/api/messages/unread).
</ResponseField>

<ResponseField name="lastMessageAt" type="string | null">
  ISO 8601 — última atividade de mensagem. Conversas sem ela vão para o fim.
</ResponseField>

<ResponseField name="lastInboundAt" type="string | null">
  ISO 8601 — última mensagem recebida do contato (de onde conta a janela de atendimento de 24 horas).
</ResponseField>

<ResponseField name="createdAt" type="string" required>
  ISO 8601 — quando a conversa foi criada.
</ResponseField>

<ResponseField name="updatedAt" type="string" required>
  ISO 8601 — última atualização do registro da conversa.
</ResponseField>

<ResponseField name="redacted" type="boolean">
  Presente (`true`) só numa conversa redigida: `from`, `fromName`, `peerLid`, `userId`, `username`, `profilePicUrl` e `lastMessagePreview` vêm `null`.
</ResponseField>

## Erros comuns

- `400 INVALID_DATE_RANGE` — `startDate` ou `endDate` não é uma string ISO 8601 válida, ou `startDate > endDate`.
- `400 INVALID_PAGINATION` — `page × pageSize` acima de `10000`.
- `400 NUMBER_NOT_FOUND` — a credencial não indica nenhum número de WhatsApp.
- `401` — credencial ausente ou inválida (`{"error": "Invalid API key"}`).
- `403 TENANT_SCOPE_NOT_ALLOWED` — chave da conta sem `x-whatsapp-number-id`.
- `403 PERMISSION_DENIED` — token OAuth/MCP ou chave de conta cujo papel não tem `chat:read` (`ANALYST`).
