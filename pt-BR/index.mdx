Boas-vindas ao Pilot Status — a plataforma de infraestrutura de WhatsApp feita para desenvolvedores e produtos SaaS. Conecte números de WhatsApp oficiais ou não oficiais, envie e receba mensagens por uma API REST simples e reaja a eventos de entrega por webhooks, sem mexer em servidor, proxy ou gerenciador de conexão.

## Comece em três passos

Seja para integrar o WhatsApp ao seu produto SaaS ou para construir um agente de IA, o Pilot Status leva você do zero às primeiras mensagens em minutos.

<Steps>
  <Step title="Conecte seu número">
    Adicione um número de WhatsApp ao seu projeto — leia um QR code para uma conexão não oficial, ou informe as credenciais do Meta Business para a Cloud API oficial ou o modo Coexistência. Sem VPS nem proxy para configurar.
  </Step>
  <Step title="Envie mensagens">
    Chame a API REST com sua API key e o ID do número para enviar texto, mídia, botões ou templates a qualquer usuário de WhatsApp. Toda requisição devolve um ID de mensagem que você pode acompanhar.
  </Step>
  <Step title="Receba eventos">
    Configure uma URL de webhook no painel e passe a receber, em tempo real, confirmações de entrega, notificações de leitura e mensagens recebidas — disparadas em milissegundos.
  </Step>
</Steps>
