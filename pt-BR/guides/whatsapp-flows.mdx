Um **WhatsApp Flow** é um formulário que abre dentro da conversa: uma tela de agendamento, um formulário de lead, uma pesquisa. O cliente toca num botão, preenche uma ou mais telas e envia. Este guia percorre o caminho inteiro, da criação do Flow à leitura das respostas.

<Warning>
  Flows estão disponíveis **apenas em números da API oficial (Meta Cloud API)**. Não estão disponíveis em números conectados por QR code. Um Flow pertence à conta do WhatsApp Business (WABA), então todo número Meta dessa WABA pode enviá-lo.
</Warning>

## Ciclo de vida

| Status | O que você pode fazer |
| --- | --- |
| `DRAFT` | Editar o JSON do Flow, pré-visualizar, enviar como teste com `mode: "draft"`, apagar. |
| `PUBLISHED` | Enviar para qualquer cliente. O JSON não muda mais. |
| `DEPRECATED` | Aposentado: não pode mais ser enviado. |

- **Publicar é irreversível.** Para mudar um Flow publicado, **clone-o** num novo rascunho, edite o clone e publique.
- **Só um `DRAFT` pode ser apagado.** Um Flow publicado só pode ser descontinuado (deprecate).

## Criar um Flow

<Tabs>
  <Tab title="Painel">
    Abra a tela **Flows**. Crie um rascunho, escreva o JSON no editor (ou **gere com IA** a partir de uma descrição), pré-visualize e publique. Veja [A tela de Flows](/pt-BR/dashboard/flows).
  </Tab>
  <Tab title="API">
    1. `POST /v1/flows` cria o rascunho ([criar](/pt-BR/playground/flows/create-flow)).
    2. `POST /v1/flows/{id}/json` envia o JSON do Flow ([enviar JSON](/pt-BR/playground/flows/upload-flow-json)).
    3. `POST /v1/flows/{id}/preview` devolve um link de pré-visualização ([pré-visualizar](/pt-BR/playground/flows/preview-flow)).
    4. `POST /v1/flows/{id}/publish` publica ([publicar](/pt-BR/playground/flows/publish-flow)).
    5. `POST /v1/flows/{id}/deprecate` aposenta depois ([descontinuar](/pt-BR/playground/flows/deprecate-flow)).

    Referência completa: [API de Flows](/pt-BR/api/flows).
  </Tab>
</Tabs>

### Categorias

Todo Flow tem uma ou mais categorias: `SIGN_UP`, `SIGN_IN`, `APPOINTMENT_BOOKING`, `LEAD_GENERATION`, `CONTACT_US`, `CUSTOMER_SUPPORT`, `SURVEY`, `OTHER`.

## Enviar um Flow

**Numa mensagem.** Adicione um bloco `flow` ao [`POST /v1/messages/send`](/pt-BR/playground/messages/send-message):

```json
{
  "destinationNumber": "+5511999999999",
  "text": "Agende sua visita",
  "flow": {
    "flowId": "2038526810137974",
    "cta": "Agendar",
    "action": "navigate",
    "screen": "WELCOME",
    "data": { "name": "Ana" }
  }
}
```

| Campo | Regra |
| --- | --- |
| `flowId` | O id do Flow na Meta. Obrigatório. |
| `cta` | Texto do botão, até **30 caracteres**. Obrigatório. |
| `action` | `navigate` ou `data_exchange`. |
| `screen`, `data` | Só com `navigate`. Com `data_exchange` o pedido é recusado com `FLOW_PAYLOAD_NOT_ALLOWED`. |
| `mode` | `draft` para enviar um Flow não publicado como teste. |

Exige a janela de 24 horas aberta. Detalhes: [Flows dinâmicos](/pt-BR/guides/send-flow-dynamic).

**Num template.** Adicione um **botão FLOW** a um template. O Flow fica fixo na criação do template e pode ser enviado fora da janela de 24 horas. Veja [Templates](/pt-BR/concepts/templates).

## Receber as respostas

Um Flow enviado pelo cliente dispara o evento de webhook **`flow.response_received`**, com as respostas como dados estruturados. Assine esse evento explicitamente. Você também pode listar as respostas guardadas com `GET /v1/flows/{id}/responses` ([listar respostas](/pt-BR/playground/flows/list-flow-responses)). Detalhes: [Respostas de Flow](/pt-BR/guides/flow-responses).

## Ligar sua API (data_exchange)

Um Flow `data_exchange` pede cada tela ao seu backend enquanto o cliente preenche.

- **Cada número tem sua própria chave de criptografia.** Gere ou importe na tela de Flows ou pela API ([gerar chave](/pt-BR/playground/numbers/generate-flow-endpoint-key)).
- **A Pilot Status é o endpoint que a Meta chama.** Ela descriptografa o pedido e encaminha JSON puro para a sua URL, assinado no cabeçalho `x-pilot-status-signature`. Confira a assinatura antes de confiar no corpo.
- **A URL do endpoint é uma credencial.** Trate-a como segredo e não a compartilhe.
- **Rotacionar a chave afeta todos os Flows `data_exchange` daquele número** de uma vez. Planeje a rotação.

Detalhes: [Ligue sua API a um Flow](/pt-BR/guides/flow-data-exchange) e [Flows com dados ao vivo](/pt-BR/guides/flow-live-data).

## Depurar com traces

`GET /v1/flows/{id}/traces` lista as chamadas recentes ao endpoint ([listar traces](/pt-BR/playground/flows/list-flow-traces)). Os traces ficam guardados por **24 horas**, e o corpo do pedido só é guardado **quando a chamada falhou**.
