This page covers what surrounds the dashboard screens: how you get in, how you join a workspace, how you approve an external app, and the parts of the shell (header, palette, chat, banners) that show on every screen.

## Sign in (`/login`)

**Sign in** — **Choose a method to continue**. Three methods, each with a keyboard shortcut when no field has focus:

| Method | Shortcut | What happens |
| --- | --- | --- |
| **Continue with WhatsApp** | `1` | Only shows while the platform's WhatsApp sign-in is available. Type your number and click **Send code**: **You'll receive a 6-digit code that expires in 5 minutes.** Type it and click **Sign in** (or `Ctrl`/`⌘` + `Enter`). |
| **Continue with Google** | `2` | Redirects to Google and back. |
| **Continue with GitHub** | `3` | Redirects to GitHub and back. |

`Esc` goes back to the home page. The method you used last time carries a **Last used** tag.

On the WhatsApp code step you also get **Resend code** (with a countdown, **Resend code in …s**) and **Change number**. Messages you may see:

- **This number is not on WhatsApp.** — the number cannot receive the code.
- **We already sent the code, check your WhatsApp.** — a code went out a moment ago; use it instead of asking again.
- **We could not deliver the code to this number. Check that it has WhatsApp.** — the code could not be delivered.
- **Too many code requests right now. Wait a few minutes and try again.** — too many codes were requested in a short time.
- **WhatsApp sign-in is unavailable right now. Use another sign-in method.** — sign in with Google or GitHub instead.
- **Invalid or expired code.** — type the latest code, or resend after 5 minutes.
- **Social login configuration error. Please try again later.** — the Google/GitHub return failed on our side.

There is no password. The account is the person: WhatsApp, Google and GitHub are just ways to sign in to it, and the extra ones are linked or unlinked in [Profile](/dashboard/profile). After signing in you land on the screen you were trying to open, or on the Dashboard.

### One-time access link from billing notices (`/a`)

Billing and plan-limit notices can carry an access link. It opens a page that says **Sign in as {email}** (or **Sign in as the account with WhatsApp {phone}**), **You will open the workspace {workspace}.** and **This link works only once.** Click **Continue** to sign in, or **Not you? Sign in with another account**.

If the link does not sign you in, you land on `/login` with the reason:

| Message | Meaning |
| --- | --- |
| **This link has already been used. Sign in to continue.** | Each link signs in once. |
| **This link has expired. Sign in to continue.** | The link is past its validity. |
| **We don't recognize this access link. Open the most recent link we sent or sign in to continue.** | The link is malformed or was replaced by a newer one. |
| **We couldn't sign you in with this link. Sign in to continue.** | The link could not be used now. |

**Too many attempts in a short time.** or **We couldn't open the link right now.** keep you on the page with **Try again**.

## Onboarding (`/onboarding`)

When onboarding is enabled for the platform, a workspace that has not finished it is sent here after sign-in. The screen says **Welcome to Pilot Status** — **Set up your WhatsApp to start sending messages.** (or **Update your WhatsApp** when you come from the profile after a number change).

- **Enter your WhatsApp number** — saved to your profile as a plain profile field. It does **not** verify the number: verification (with a code) is done in [Profile](/dashboard/profile) and is what lets billing notices reach you on WhatsApp.
- **Link your account** — link Google or GitHub (**Link** / **Relink**, status **Linked** / **Not linked**). **Link Google or GitHub to your WhatsApp before continuing.**
- **Go to Dashboard** — enabled once there is a number and at least one social login linked.

## Accepting an invite (`/invite/{token}`)

The invite e-mail (or the link an Owner/Admin copied — see [Members](/dashboard/members)) opens this page. If you are not signed in, you are sent to sign in first and brought back with the invite intact.

The page (Portuguese copy only, today) shows **Você foi convidado para {workspace}**, the role (by its internal name, such as **AGENT** or **ANALYST**) with a one-line explanation, **Convite enviado para {e-mail}** and the expiry date. Buttons:

- **Aceitar convite** — you join, the dashboard switches to that workspace and shows **Você entrou no workspace** with your role.
- **Recusar** → confirmation **Recusar apaga este convite. Para entrar depois, alguém do workspace precisa te convidar de novo.** → **Sim, recusar** (or **Voltar**). Declining burns the link for good: the page shows **Convite recusado** — *Não avisamos ninguém automaticamente. Se foi engano, peça um novo convite a quem te chamou.* — and whoever invited you sees the invitation as declined.

| Error | What to do |
| --- | --- |
| **Convite não encontrado** | The link does not exist, was replaced by a newer one (each **Resend** kills the previous link), was revoked, or was already declined. Ask for a new invite. |
| **Convite expirado** | Invites last **7 days**. Ask whoever invited you to resend it. |
| **Convite já usado** | Already accepted. If you are a member, just sign in. |
| **Convite é de outro e-mail** | An invite only works for the invited e-mail. Log out and sign in with that account. |
| **Link incompleto** | Open the full link from the e-mail. |
| **Não foi possível abrir o convite** | Something else went wrong (for example, too many attempts). Try again in a moment or ask for a new invite. |

## Approving an app (`/oauth/consent`)

When an external app connects to your account through OAuth — for example the Pilot Status MCP server added as a **Custom Connector** in Claude — you land on **Access authorization** — **Connect to your Pilot Status account**: *An app (e.g. Claude) is requesting access. Choose what it can access.* If you are not signed in, you sign in first and come back to this screen. If the app sent an incomplete request, the screen says **Invalid connection request** — *The authorization parameters are missing or invalid. Go back to the app and try connecting again.*

| Option | What the app gets |
| --- | --- |
| **Entire account** | *Access to all numbers and account operations, including billing. API keys only while you own the workspace.* Only an **Owner** or **Admin** can choose it. For an **Agent** or **Analyst** the option is greyed out with *Only the workspace owner or an admin can grant access to the entire account. Choose specific numbers.*, and the server refuses it too. |
| **Specific numbers only** | *Access only to the selected numbers. Account-level operations are blocked.* Tick the numbers in the list (**… selected**); you must tick at least one (**Select at least one number.**). You can only tick numbers you yourself can reach, and the shared test number is not listed. |

**Specific numbers only** is selected by default. When the workspace has no numbers, an Owner or Admin starts on **Entire account**; an Agent or Analyst sees **No numbers available in this account.** *Ask the owner or an admin to connect a number or to authorize this app.* and cannot authorize.

### Secrets and API keys

Below the options, the screen says what the app will be able to reach beyond messages and numbers. It depends on your role:

| Your role | What the screen shows |
| --- | --- |
| **Owner** | Warning **This app will be able to view secrets and create API keys** — *Because you own this workspace, the app will be able to reveal and create API keys (ps_…), view and rotate webhook secrets and view the Meta verify token on your behalf. Keys and secrets it obtains stay valid even if you revoke this access later — regenerate them to cut them off. Every creation or reveal is recorded in the audit log.* |
| **Admin** | Warning **This app will be able to view secrets** — *Because you are an admin of this workspace, the app will be able to view and rotate webhook secrets and view the Meta verify token on your behalf. API keys are only available to the workspace owner. Secrets it obtains stay valid even if you revoke this access later — rotate them to cut them off. Every creation or reveal is recorded in the audit log.* |
| **Agent**, **Analyst** | Note *Secrets are only available to this app for workspace admins and owners; API keys, only for the owner.* |

API key access is checked on every call, not only at consent time: if the Owner later stops being the owner, the app loses it.

**Authorize** completes the connection and sends you back to the app; **Cancel** returns the app an `access_denied`. The token never grants more than your own role allows: an Analyst's connector cannot read conversations or send messages, for instance, and a requested permission your role does not have is dropped.

The screen ends with *You can revoke this access anytime in settings.*, but the dashboard has no list of connected apps today. To cut an app off, remove the connector in the app (its token can also be revoked through the OAuth revoke endpoint), and regenerate any key or secret it obtained. Details: [MCP server](/integrations/mcp-server).

## The header

- **Workspace switcher** — only appears when you belong to **more than one** workspace. Each entry shows the workspace name, your role and the owner's e-mail. Picking one reloads the dashboard in that workspace. If you lose access to the active workspace, the dashboard says **You no longer have access to that workspace. We switched you back to your main workspace.** To create another workspace, use **Criar outro workspace** in [Profile → Members](/dashboard/members), or a personal account key (`ps_account_…`) with [`POST /v1/workspaces`](/api/workspaces) / the MCP tool `workspaces_create`.
- **Active number** — **Active number:** dropdown choosing which number the number-scoped screens show. The shared test number carries a **Test** tag.
- **Search…** (`Ctrl+K` / `⌘K`) — opens the command palette.
- **Theme** (`M`), **Feedback** (`F`), **Logout** (`Q`) and the language selector. **Logout** asks **Are you sure you want to log out of your account?** — **You will be disconnected.**

The sidebar shows a single-letter shortcut next to each item (for example `p` for Plans, `u` for Profile).

## Command palette (`Ctrl+K`)

**Search or ask AI...** — type to filter, `↑`/`↓` and `Enter` to open, `1`–`9`/`0` to pick a result, `Esc` to close. Groups:

- **Pages** — Dashboard, Analytics, Ads, Templates, Logs, API Keys (twice: the number keys and the workspace keys), Numbers, Labels, Webhooks, Plans, Documentation and Profile, filtered to what your role can open. Phone lines, Chat, Messages, Flows and Chatwoot are reached from the sidebar.
- **Quick Actions** — **Create Template** (`Ctrl+Shift+1`), **Regenerate API Key** (`Ctrl+Shift+3`), **Create Webhook** (`Ctrl+Shift+4`), **Connect Number** (`Ctrl+Shift+5`) and the dark/light mode toggle. Each shows only for roles that can do it.
- **Numbers**, **Templates**, **API Keys**, **Webhooks** — your own items, to jump straight to them.

**Ask AI** sends what you typed to the AI and streams the answer inside the palette, with **Copy AI answer**. This answer is knowledge only: it does not act on your account.

## AI agent chat

The round **Ask AI** button in the bottom-right corner (on every screen except an open chat conversation) opens the side chat. Signed in, it is the **Pilot Status agent** — **Agent — acts on your account**: it answers about the API and the product and can list your numbers, read metrics, send messages and more, through the same tools as the [MCP server](/integrations/mcp-server), limited by your role. Owner-only tools (such as the phone line holder verification) are never offered.

Anything that changes something (send, create, delete) stops first with **The AI will run this on your account. Nothing runs before you confirm.**, listing each action and its arguments, with **Confirm & run** and **Cancel**. **Clear** starts a new conversation. Next to it, the WhatsApp button (**WhatsApp Support**) opens a chat with the support team.

## Feedback

**Feedback** (header, or `F`) opens **Feedback** — **Ideas to improve this page...** and **Send**. It records the message with the screen you were on and confirms **Feedback sent successfully.** For help rather than suggestions, the same modal points to the docs (**Need help? see docs**).

## Banners at the top

| Banner | Who sees it | Action |
| --- | --- | --- |
| **New version available** — **Reload the page to use the latest version of Pilot Status.** | Everyone, after a deploy. | **Reload** |
| **Your renewal is due in … days** | When the plan renews within 2 days (not on Free, not when already suspended). Wallet billing shows the current balance; card billing says the card will be charged. | **Go to Plans** |
| **Get billing notices on WhatsApp** (Owner) / **Verify your WhatsApp number** (others) | Anyone whose own WhatsApp is not verified. It cannot be dismissed. | **Verify WhatsApp** — sends a code to your number |
| **Meta payment pending: templates blocked** | Owner and Admin, when Meta blocked a WhatsApp Business account of yours for a payment problem. Sending through Pilot Status is **not** paused. | **Open in Meta**, **Show numbers**, **Hide notice** (for the browser session) |
| **No connected numbers** — **Connect a WhatsApp number to start sending messages.** | Number-scoped screens, when the workspace has no number. Those screens show **Connect a number to continue**. | **Add Number** (only for roles that can connect numbers) |

None of these banners show on the full-screen chat.

## Do it via API / MCP

| Action | API / MCP |
| --- | --- |
| Sign in, onboarding, one-time notice link | Dashboard only. The API authenticates with keys, not sessions — see [Authentication](/api/authentication). |
| Accept or decline an invite | Dashboard only. Sending, resending and revoking invites: `POST /v1/workspace/members`, `workspace_members_invite`, `workspace_members_resend`, `workspace_members_remove` — see [Workspace](/api/workspace). |
| Approve an app (OAuth consent) | Interactive browser step by design; it cannot be scripted. |
| List or create workspaces | `GET`/`POST /v1/workspaces` with an account key; MCP `workspaces_list`, `workspaces_create`. See [Workspaces](/api/workspaces). |
| Ask the docs | MCP `docs_search`. |
| Command palette, feedback, banners | Dashboard only. |
