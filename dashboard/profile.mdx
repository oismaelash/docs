**Profile** is where you manage yourself — your name, your WhatsApp, the logins linked to your account and your personal API keys — and, for Owner and Admin, a few settings of the current workspace: currency, timezone, language, the connect page branding and the members.

## How to get there

Click **Profile** in the sidebar, right below **Plans** (keyboard shortcut: `u`), or search for **Profile** in the command palette (`Ctrl+K`). The address is `/profile`; each tab has its own link with `?tab=`:

| Tab | Link | Who sees it |
| --- | --- | --- |
| **Information** | `/profile` or `/profile?tab=info` | Everyone |
| **General** | `/profile?tab=geral` | Owner and Admin |
| **Connections** | `/profile?tab=connections` | Everyone |
| **API** | `/profile?tab=api` | Everyone |
| **Membros** (Members) | `/profile?tab=membros` | Owner and Admin — see [Members](/dashboard/members) |
| **Branding** | `/profile?tab=branding` | Owner and Admin |

A link to a tab your role does not cover opens **Information** instead. The old `/profile?tab=carteira` link (wallet) now goes to **Plans → Wallet** (`/plans?tab=wallet`).

## Information

Your own data. It is about **you**, not the workspace: it follows you into every workspace you belong to.

- **Name** — up to 100 characters.
- **Email** — the e-mail you sign in with. It is shown greyed out and cannot be changed here.
- **WhatsApp** — your phone number, with a country selector. Below it, a badge says **Verified: +55…** or **WhatsApp not verified**.
- **Save** — saves the name and the phone.

<Note>
  The WhatsApp field is free text, and saving it does not prove the number is yours. The **verified** number is a separate thing: it is the one that receives payment and limit notices by WhatsApp. If the WhatsApp field and **Save** are greyed out, editing the profile phone is turned off for your account; verifying a number (below) still works.
</Note>

### Verify your WhatsApp

**Verify** (or **Verify another number**, once you have one verified) opens the **Verify your WhatsApp** dialog:

1. Confirm or type the number and click **Send code**. Pilot Status sends a **6-digit code** to that number through its own WhatsApp.
2. Type the code and click **Verify**. **Resend code** sends a new one; **Change number** goes back to the first step.

When it works, the dashboard says **WhatsApp verified! You will also get notices there from now on.** Errors you may see: **Incorrect code.**, **There is no valid code for this number. Request a new one.**, **Too many incorrect attempts. Request a new code.**, **This WhatsApp number is already linked to another Pilot Status account. If it is yours, contact support.** and **Too many attempts right now. Wait a moment and try again.**

## General

The workspace's **currency**, **timezone** and **language** — they apply to the whole current workspace, not just to you.

- **Currency** — **BRL** or **USD**. Only the **Owner** can change it, and only **until the first wallet transaction**: after that the field is locked and says **Currency was locked after the first wallet transaction and can no longer be changed.** (Saving the currency is the workspace's billing preference.)
- **Timezone** — `America/Sao_Paulo`, `America/New_York`, `America/Los_Angeles`, `America/Mexico_City`, `America/Buenos_Aires`, `Europe/Lisbon`, `Europe/London`, `Europe/Madrid`, `Europe/Paris` or `UTC`.
- **Language** — Portuguese, English or Spanish.

**Save** saves all three. Owner and Admin can change timezone and language; an Admin sees the currency but cannot change it.

## Connections

**Connect your accounts** — link Google and/or GitHub to simplify login and account recovery. Each row shows **Linked** or **Not linked**:

- **WhatsApp** — your profile phone, marked **Always linked**.
- **Google** and **GitHub** — **Link** (or **Relink**) takes you to the provider to authorize and brings you back to this tab with **Google linked!** / **GitHub linked!**. **Unlink** asks *Are you sure you want to unlink your Google account?* (or GitHub) and removes that login method.

After unlinking, you can no longer sign in with that provider; sign in with another method you still have (for example, the WhatsApp or e-mail code on the [login screen](/dashboard/account-access)).

## API — your account keys

The **API** tab holds your **account keys** — **Account keys** on the screen. An account key is **yours, not a workspace's**: it manages your workspaces and acts inside any workspace you are an active member of. Each request picks the workspace with the `x-workspace-id` header and runs with **your role there**. The card shows **Scope: Everything in every workspace**.

- **Key name** + **Create key** — give the key a name (up to 60 characters, e.g. *CRM integration*). Any user can create one, whatever their role, up to **20** account keys per user.
- The list shows each key's name, its masked value (`ps_account_…` plus the last four characters), **Created …** and **Last used …** (or **Never used**).
- **Revoke** opens **Revoke the key "…"?** — *Every integration using this key stops working immediately. This cannot be undone.* — with **Revoke key**.

<Warning>
  **The full account key is shown only once.** Right after **Create key**, the dialog **Key "…" created** shows the whole `ps_account_…` value with **Copy key** and the warning *the full key is shown only this once*. Pilot Status stores only a hash, so neither the dashboard nor support can show it again. **Lost it? Create a new key, put it in your integration, and revoke the old one.** There is no "reveal" for account keys.
</Warning>

An account key is the most powerful credential you can hold: it reaches every workspace you belong to. Keep it on your server only, never in a browser or an app. Details, headers and errors: [API key types → Account keys](/api/key-types#account-keys).

Below it, Owner and Admin also see **Workspace keys** — *The primary key and the named keys of the current workspace live on their own screen.* — with **Open workspace keys**, which goes to `/workspace-api-keys` (see [API keys](/dashboard/api-keys)).

## Branding

**Branding** customizes the **connect page** your customers see when they connect a number through a link you send them (QR code or Meta signup). Owner and Admin can edit it.

| Field | What it does |
| --- | --- |
| **Logo** | **Upload logo** — PNG, JPG or WebP, up to 2 MB. The file is uploaded when you click **Save** (until then the screen says *New logo selected — it will be uploaded on save.*). **Remove** clears it. |
| **Primary color** / **Background color** | Color pickers; **Clear** returns to **Default**. |
| **Title** | Up to 60 characters (e.g. *My Company*). |
| **Subtitle** | Up to 120 characters (e.g. *Connect your WhatsApp*). |
| **Support link (optional)** | A link the page shows for help. |
| **Redirect after connecting (optional)** | Where the customer goes once the number is connected. |
| **Hide Pilot Status branding** | Removes the "Pilot Status" footer from the page (white-label). |

On the right, **Preview** shows the connect page with your changes as you type. **Open preview** opens it full-screen in a new tab (`/connect-preview`), also before you save. **Save** applies it — **Branding saved.**

More — per-link overrides and URL parameters — in [Connect page branding](/api/branding).
