# Send a media message

Direct media is one of the three mutually exclusive modes of the **single** send endpoint — there is no separate `/messages/media` endpoint:

```text
POST https://pilotstatus.com.br/v1/messages/send
```

## Request

Authenticate with your **number-scoped** API key in the `x-api-key` header. Send `media` \+ `mediaType` **without** `templateId` and **without** `text`.

<ParamField body="destinationNumber" type="string" required>
  Destination phone in **E.164** with a leading `+` (e.g., `+5511999999999`).
</ParamField>

<ParamField body="media" type="string" required>
  A **public http(s) URL** or a **base64 data URI** (e.g. `data:image/png;base64,...`). Base64 data URIs are accepted on **Meta Cloud API** and on **unofficial (Pilot Status web)** numbers. On unofficial numbers, Pilot Status uploads the decoded file to its own storage and sends the provider a URL; if that upload fails, the message fails with `MEDIA_REHOST_FAILED`. For stickers on unofficial numbers, use a public http(s) URL. Base64 goes up to **50 MiB** decoded for `document` and **16 MiB** for every other type; above that the request is refused with `400`, so send a larger file by URL.
</ParamField>

<ParamField body="mediaType" type="string" required>
  `image`, `video`, `document`, `audio`, `voice`, or `sticker`. `voice` arrives as a WhatsApp **voice note (PTT)** on every number. `audio` arrives as an **audio file** on official (Meta Cloud API) numbers and as a voice note on unofficial (Pilot Status web) numbers.
</ParamField>

<ParamField body="caption" type="string">
  Optional caption for `image`, `video`, and `document` — **not** supported for `audio`, `voice`, or `sticker`. With `audio` or `sticker`, a caption returns `400`. With `voice`, it is not rejected, but it is dropped on unofficial numbers and its rendering on official numbers is not guaranteed — don't send one.
</ParamField>

<CodeGroup>

```bash Image with caption
curl -X POST "https://pilotstatus.com.br/v1/messages/send" \
  -H "Content-Type: application/json" \
  -H "x-api-key: ps_your_key_here" \
  -d '{
    "destinationNumber": "+5511999999999",
    "media": "https://cdn.example.com/photo.jpg",
    "mediaType": "image",
    "caption": "Here is your receipt"
  }'
```

```bash Voice note (voice)
curl -X POST "https://pilotstatus.com.br/v1/messages/send" \
  -H "Content-Type: application/json" \
  -H "x-api-key: ps_your_key_here" \
  -d '{
    "destinationNumber": "+5511999999999",
    "media": "https://cdn.example.com/voice.ogg",
    "mediaType": "voice"
  }'
```

```bash Sticker
curl -X POST "https://pilotstatus.com.br/v1/messages/send" \
  -H "Content-Type: application/json" \
  -H "x-api-key: ps_your_key_here" \
  -d '{
    "destinationNumber": "+5511999999999",
    "media": "https://cdn.example.com/sticker.webp",
    "mediaType": "sticker"
  }'
```

</CodeGroup>

## Response (202)

```json
{
  "id": "msg_abc",
  "correlationId": "corr_123",
  "status": "QUEUED"
}
```

## Notes

- To send a WhatsApp **voice note (PTT)** on any number, use `voice`. Use `audio` only when you want an **audio file** on an official (Meta Cloud API) number — on unofficial (Pilot Status web) numbers `audio` also arrives as a voice note. See [Audio and voice notes](/guides/media-messages#audio-and-voice-notes).
- `sticker` must be **`image/webp`** and **exactly 512×512 pixels** — static up to **100 KB**, animated up to **500 KB**. Any other format or dimension is rejected by WhatsApp, not by this API, so the failure arrives in the `message.failed` webhook rather than in the 202 response. A sticker takes no `caption` and no `mediaFilename` (both return 400), and cannot be sent as template media.
- In this mode `buttons`, `header`, `footer`, and `variables` are **not allowed** — to combine media with buttons, use a template send (see [Send Interactive](/api/messages/send-interactive)).
- For formats, size limits, and provider differences, see the [Media messages guide](/guides/media-messages); for the full parameter list, see [Send a Message](/api/messages/send).
