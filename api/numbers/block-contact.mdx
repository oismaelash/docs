# Block contact

`POST` blocks the contact, `DELETE` unblocks it. Neither takes a request body.

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wn_abc/contacts/%2B5511999990000/block" \
  -H "x-api-key: ps_your_token_here"
```

```json
{
  "success": true,
  "numberId": "wn_abc",
  "provider": "qrcode",
  "phone": "+5511999990000",
  "jid": "5511999990000@s.whatsapp.net",
  "blocked": true,
  "occurredAt": "2026-11-24T10:00:00.000Z"
}
```

## Which numbers

| Number | Block / unblock |
| --- | --- |
| QR code number | Yes |
| Official (Meta) number | Yes — only a user who messaged the number in the last 24 hours (otherwise `422 CONTACT_NOT_ELIGIBLE`) |
| Other connection types | `422 FEATURE_NOT_SUPPORTED` |

## Webhook

On success your webhooks receive `contact.blocked` (or `contact.unblocked`) with `data.source: "api"`. On a QR code number the same change also comes back from the phone; it is delivered **once**, not twice.

## Permission and limits

- Requires `contacts:manage` (Agent and up). A number key only acts on its own number.
- 30 block/archive calls per minute per number → `429 RATE_LIMITED`.

## Errors

Every error is `{ "error": "<English> | <Português>", "code": "..." }`.

| Status | Code | Meaning |
| --- | --- | --- |
| 400 | `INVALID_PHONE` | `{phone}` is not an E.164 number. |
| 400 | `CANNOT_BLOCK_SELF` | A number cannot block itself. |
| 401 | — | Missing or invalid API key. |
| 403 | `PERMISSION_DENIED` | Your role lacks `contacts:manage`. |
| 404 | `NUMBER_NOT_FOUND` | No such number for this credential. |
| 409 | `WHATSAPP_INSTANCE_NOT_CONNECTED` | The number is not connected. |
| 409 | `BLOCKLIST_FULL` | The blocklist is full (64,000 users). |
| 422 | `CONTACT_NOT_ELIGIBLE` | Official number: the user has not messaged in the last 24 hours. |
| 422 | `FEATURE_NOT_SUPPORTED` | Not supported for this connection type. |
| 429 | `RATE_LIMITED` | Too many calls, or WhatsApp's own limit. |
| 502 | `PROVIDER_REJECTED` / `WHATSAPP_UPSTREAM_ERROR` | WhatsApp refused or failed the request; `details` carries its answer. |
