# Archive chat

`POST` archives the chat, `DELETE` unarchives it. Neither takes a request body. `{jid}` is an E.164 phone or a URL-encoded jid (`@s.whatsapp.net`, `@g.us`, `@lid`).

```bash
curl -X POST "https://pilotstatus.com.br/v1/numbers/wn_abc/chats/120363000000000000%40g.us/archive" \
  -H "x-api-key: ps_your_token_here"
```

```json
{
  "success": true,
  "numberId": "wn_abc",
  "provider": "qrcode",
  "jid": "120363000000000000@g.us",
  "phone": null,
  "isGroup": true,
  "archived": true,
  "occurredAt": "2026-11-24T10:00:00.000Z"
}
```

## Which numbers

| Number | Archive / unarchive |
| --- | --- |
| QR code number | Yes |
| Official (Meta) number | `422 NOT_AVAILABLE_FOR_OFFICIAL_NUMBERS` |
| Other connection types | `422 FEATURE_NOT_SUPPORTED` |

## Webhook

On success your webhooks receive `chat.archived` (or `chat.unarchived`) with `data.source: "api"`. The echo of the same change from the phone is delivered only once.

## Permission and limits

- Requires `contacts:manage` (Agent and up).
- 30 block/archive calls per minute per number → `429 RATE_LIMITED`.

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| 400 | `INVALID_JID` | `{jid}` is not a phone or a supported jid. |
| 401 | — | Missing or invalid API key. |
| 403 | `PERMISSION_DENIED` | Your role lacks `contacts:manage`. |
| 404 | `NUMBER_NOT_FOUND` | No such number for this credential. |
| 409 | `WHATSAPP_INSTANCE_NOT_CONNECTED` | The number is not connected. |
| 422 | `NOT_AVAILABLE_FOR_OFFICIAL_NUMBERS` | Official numbers cannot archive through the API. |
| 422 | `FEATURE_NOT_SUPPORTED` | Not supported for this connection type. |
| 429 | `RATE_LIMITED` | Too many calls. |
| 502 | `PROVIDER_REJECTED` / `WHATSAPP_UPSTREAM_ERROR` | WhatsApp refused or failed the request. |
